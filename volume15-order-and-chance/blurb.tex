The integers are deterministic, and yet the primes, the M\"obius function and the class group of a random quadratic field all invite a probabilistic description.
This volume asks when that description is a theorem and when it is only a model.\par\medskip
It begins with Cram\'er's model and the Erd\H os--Kac theorem, then random multiplicative functions, short intervals, sieves, class groups and ranks of elliptic curves.
It compares the zeros of the zeta function with random matrices, and it records where order defeats a random guess: biases, Maier's irregularities, and the Green--Tao theorem.\par\medskip
The last part is a workshop in reading, experimenting, conjecturing and writing, with complete arguments, and twelve appendices of conjectures still open.
