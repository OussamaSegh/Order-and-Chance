\chapter*{About the Cover}
\addcontentsline{toc}{chapter}{About the Cover}
\noindent The first stages of the Cantor function, rising from zero to one and flat across every interval that has been removed, with the Cantor set itself drawn in rows underneath. Georg Cantor introduced the set in 1883, and described the staircase associated with it in 1884. The function is constant on a set of full length and increases only on a set of length zero. Making sense of that is the work of this volume, from the chapter Sets, Choice and the Real Numbers to the chapter Measures. The drawing was computed by the book's own TikZ cover generator.
