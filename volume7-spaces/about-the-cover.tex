\chapter*{About the Cover}
\addcontentsline{toc}{chapter}{About the Cover}
\noindent Eight stages of the Cantor set lie in rows under the Cantor function. The function is drawn through its iterates. The last of them rises from zero to one and is flat on the removed intervals. Georg Cantor introduced the set in 1883, and he described the staircase in 1884. The function is constant on a set of full length, and it increases only on a set of length zero. That is why the picture belongs on this volume. The set is built with the real numbers, and its length is settled only when measure is defined, in the chapter Measures. The drawing was computed by the book's own TikZ cover generator.
