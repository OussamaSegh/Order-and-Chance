\chapter{Sets, Choice and the Real Numbers}\label{ch:sets}

\begin{center}\itshape
Can the rationals be paired with the integers? Can the reals? Does a square have more points than one side?
Before any of that: what is a real number?
\end{center}

On 24 November 1858, Richard Dedekind was teaching differential calculus at the Zurich Polytechnic for the first time, and he was stuck. He had just told the class that an increasing sequence, bounded above, must converge. The students accepted it. He did not. Every proof he knew leaned on a picture of the line, and a picture is not an argument. That day he saw what was missing. He waited fourteen years to publish it, in the booklet \emph{Continuity and Irrational Numbers} (1872).

\portrait{dedekind}{Richard Dedekind (1831--1916). Photograph, about 1870. Public domain, via Wikimedia Commons.}

A stranger question arrived in the same years. In November 1873 Georg Cantor wrote to Dedekind: can the natural numbers be paired off with the reals? Dedekind replied that he did not know, though the algebraic numbers, at least, could be listed. A week later Cantor had the answer, and it was no. There are more real numbers than integers. Infinity comes in sizes. Three years after that he proved that a square has no more points than one side, and he wrote to Dedekind, in French, ``je le vois, mais je ne le crois pas'': I see it, but I do not believe it.

\portrait{cantor}{Georg Cantor (1845--1918). Photograph, early twentieth century, author unknown. Public domain, via Wikimedia Commons.}

Both stories are the plan of the chapter. The numbers are built from sets and nothing else: first $\N$, then $\Z$ and $\Q$ as pairs, then $\R$ as classes of rational Cauchy sequences. Volume~1 took as an axiom that every non-empty set of reals bounded above has a least upper bound. That axiom becomes a theorem, and a second theorem says there is only one complete ordered field, so the construction is not a private choice. Counting comes next, by Cantor's diagonal argument. The same idea returns as Russell's paradox, as G\"odel's incompleteness theorem, and as Turing's halting problem. The chapter ends with the axiom of choice: it looks harmless, it is indispensable, and it produces some of the strangest objects in mathematics.

\section{Sets}

Sets are used the way everyone uses them. It is still worth knowing which rules are allowed. Careless rules produce contradictions.

\begin{think}
Could there be a set that has every set as a member? If $V$ were such a set, form $R=\{x\in V:x\notin x\}$. Does $R$ belong to $R$?
\end{think}

If $R\in R$, then $R$ meets its own defining condition, so $R\notin R$. If $R\notin R$, then $R$ meets that condition, so $R\in R$. Either way the assumption breaks. This is Russell's paradox (1901). The rule ``every property determines the set of all things with that property'' is contradictory. Zermelo's repair (1908) is to form new sets only out of sets you already have: you may select, from an existing set, the elements with a given property, but you may not collect ``all things'' with that property. The argument above then shows there is no set of all sets.

\paragraph{The axioms of Zermelo--Fraenkel.} Everything is a set. Two sets are equal when they have the same elements (\emph{extensionality}). The following sets exist. The empty set $\varnothing$. The pair $\{a,b\}$ of any two sets. The union $\bigcup A$ of the elements of a set $A$. The power set $\mathcal P(A)$, whose elements are the subsets of $A$. For a set $A$ and a property $P$, the subset $\{x\in A:P(x)\}$ (\emph{separation}). For a set $A$ and a rule $F$ that assigns a set $F(x)$ to each $x\in A$, the image $\{F(x):x\in A\}$ (\emph{replacement}). A set that contains $\varnothing$ and is stable under $x\mapsto x\cup\{x\}$ (\emph{infinity}). Finally, every non-empty set $A$ has an element disjoint from $A$ (\emph{foundation}; this forbids $x\in x$). These axioms are called ZF. The axiom of choice (AC, Section~\ref{sec:choice}) is added when it is needed, and ZFC means ZF together with choice. Ordinary mathematics works in ZFC. That is the one package this volume does not prove.

\paragraph{Pairs, products, functions.} The ordered pair is Kuratowski's set $(a,b)=\{\{a\},\{a,b\}\}$. It has one job: $(a,b)=(c,d)$ forces $a=c$ and $b=d$. If $a=b$, the pair is $\{\{a\}\}$, so $\{c\}=\{c,d\}=\{a\}$ and $c=d=a$. The case $c=d$ is the same with the sides swapped. Otherwise $\{a\}$ is the only one-element member on the left and $\{c\}$ the only one on the right, so $a=c$, and then $\{a,b\}=\{a,d\}$ with $b\ne a$ forces $b=d$. The product $A\times B$ is the set of such pairs. It sits inside $\mathcal P(\mathcal P(A\cup B))$, so separation provides it. A \emph{function} $f:A\to B$ is a subset of $A\times B$ that contains exactly one pair $(a,b)$ for each $a\in A$, and $B^A$ is the set of all functions from $A$ to $B$. An equivalence relation $\sim$ on $A$ has \emph{classes} $[a]=\{x\in A:x\sim a\}$. The classes partition $A$, and the \emph{quotient} $A/{\sim}$ is the set of them. The three number systems below, $\Z$, $\Q$ and $\R$, are quotients of this kind.

\section{The natural numbers}\label{sec:naturals}

Von Neumann's idea is to let each natural number be the set of the numbers before it: $0=\varnothing$, $1=\{0\}$, $2=\{0,1\}$, and in general $S(n)=n\cup\{n\}$, the \emph{successor} of $n$.

\begin{definition}
A set $I$ is \emph{inductive} when $\varnothing\in I$ and $x\cup\{x\}\in I$ whenever $x\in I$. The set $\N$ is the intersection of all inductive sets. The axiom of infinity supplies one inductive set $I_0$, and $\N=\{x\in I_0:x\text{ belongs to every inductive set}\}$.
\end{definition}

$\N$ is itself inductive, and it sits inside every inductive set. That is induction in its bare form: \emph{an inductive subset of $\N$ is all of $\N$}. In words, a property that holds for $0$ and passes from $n$ to $S(n)$ holds for every natural number.

\begin{theorem}[Peano's axioms]\label{thm:peano}
For every $n\in\N$ one has $0\ne S(n)$; the map $S$ is injective on $\N$; and every inductive subset of $\N$ equals $\N$.
\end{theorem}
\begin{proof}
The number $n$ is an element of $S(n)$, while $0$ has no element, so $S(n)\ne0$. For injectivity, call a set $x$ \emph{transitive} when $y\in x$ implies $y\subseteq x$. Every $n\in\N$ is transitive. The transitive members of $\N$ form an inductive set: $\varnothing$ is transitive, and if $n$ is, then $y\in S(n)$ means either $y\in n$, hence $y\subseteq n\subseteq S(n)$, or $y=n$, hence $y\subseteq S(n)$. Next, $n\notin n$ for every $n\in\N$. The set of such $n$ is inductive. Indeed $\varnothing\notin\varnothing$. If $n\notin n$ but $S(n)\in S(n)$, then either $S(n)=n$, which puts $n\in n$, or $S(n)\in n$, which by transitivity puts $n\in S(n)\subseteq n$. Both contradict $n\notin n$. Now suppose $S(m)=S(n)$ with $m\ne n$. Then $m\in S(n)$, so $m\in n$, and likewise $n\in m$. Transitivity gives $m\in m$, which is impossible.
\end{proof}

Induction proves properties. \emph{Recursion} defines sequences. The claim that ``$f(0)=a$ and $f(n+1)=g(f(n))$'' really names a function is a theorem, not a habit.

\begin{theorem}[recursion]\label{thm:recursion}
Let $A$ be a set, let $a\in A$, and let $g:A\to A$. Then exactly one function $f:\N\to A$ satisfies $f(0)=a$ and $f(S(n))=g(f(n))$ for every $n$.
\end{theorem}
\begin{proof}
Call a set $h\subseteq\N\times A$ \emph{admissible} when $(0,a)\in h$ and $(n,y)\in h$ implies $(S(n),g(y))\in h$. The whole product $\N\times A$ is admissible, and so is the intersection $f$ of all admissible sets. Let $D$ be the set of $n$ for which exactly one $y$ satisfies $(n,y)\in f$. Once $D$ is inductive, $f$ is a function on $\N$, and the two equations are the admissibility of $f$.

If $(0,b)\in f$ with $b\ne a$, then $f\setminus\{(0,b)\}$ is still admissible, because $0$ is not a successor. That contradicts the minimality of $f$, so $0\in D$. Take $n\in D$, with $(n,y)\in f$. Then $(S(n),g(y))\in f$. If also $(S(n),z)\in f$ with $z\ne g(y)$, the set $f'=f\setminus\{(S(n),z)\}$ is admissible: it contains $(0,a)$ because $S(n)\ne0$, and if $(m,w)\in f'$ then $(S(m),g(w))\in f$ and that pair is not $(S(n),z)$. Indeed $S(m)=S(n)$ forces $m=n$ by Theorem~\ref{thm:peano}, hence $w=y$ because $n\in D$, and $g(w)=g(y)\ne z$. Minimality fails again, so $S(n)\in D$.

If $f_1$ and $f_2$ both work, the set of $n$ with $f_1(n)=f_2(n)$ is inductive, so $f_1=f_2$.
\end{proof}

Addition is defined by recursion on the second variable: $m+0=m$ and $m+S(n)=S(m+n)$. Multiplication is $m\cdot0=0$ and $m\cdot S(n)=m\cdot n+m$. Writing $1=S(0)$ gives $S(n)=n+1$.

\begin{proposition}\label{prop:semiring}
On $\N$, addition and multiplication are associative and commutative, and multiplication distributes over addition. Addition cancels: $m+p=n+p$ forces $m=n$. A sum vanishes only in the trivial way: $m+n=0$ forces $m=n=0$.
\end{proposition}
\begin{proof}
Each claim is an induction on one variable, using only the recursive definitions.
(a) $0+n=n$: true for $n=0$, and $0+S(n)=S(0+n)=S(n)$. (b) $S(m)+n=S(m+n)$: true for $n=0$, and $S(m)+S(n)=S(S(m)+n)=S(S(m+n))=S(m+S(n))$. (c) Commutativity is an induction on $n$. The case $n=0$ is $m+0=m=0+m$, by (a). The step is $m+S(n)=S(m+n)=S(n+m)=S(n)+m$, by (b). (d) Associativity is an induction on $p$. The successor step reads $(m+n)+S(p)=S((m+n)+p)=S(m+(n+p))=m+(n+S(p))$. (e) Cancellation is an induction on $p$. From $m+S(p)=n+S(p)$ one gets $S(m+p)=S(n+p)$, and injectivity of $S$ gives $m+p=n+p$. (f) If $n\ne0$, then $n=S(k)$ for some $k$, because $\{0\}\cup S(\N)$ is inductive, and $m+n=S(m+k)\ne0$.

Multiplication is the same style of induction. (g) Distributivity $m(n+p)=mn+mp$ proceeds on $p$: $m(n+S(p))=m\,S(n+p)=m(n+p)+m=mn+mp+m=mn+m\,S(p)$. (h) The two rules $0\cdot n=0$ and $S(m)\,n=mn+n$ are inductions on $n$. The step for the second is $S(m)S(n)=S(m)n+S(m)=mn+n+m+1$, matching $m\,S(n)+S(n)=mn+m+n+1$. (i) Commutativity of multiplication is an induction on $n$. The base is $m\cdot0=0=0\cdot m$, and the step is $m\,S(n)=mn+m=nm+m=S(n)\,m$, using (h). (j) Associativity of multiplication is an induction on $p$. The step uses (g): $(mn)S(p)=(mn)p+mn=m(np)+mn=m(np+n)=m(n\,S(p))$.
\end{proof}

Order $\N$ by writing $m\le n$ when $n=m+k$ for some $k\in\N$, and $m<n$ when that $k$ is not $0$.

\begin{proposition}\label{prop:wellorder}
The relation $\le$ is a total order on $\N$, compatible with addition and with multiplication by any $p$, and every non-empty subset of $\N$ has a least element.
\end{proposition}
\begin{proof}
Reflexivity is $k=0$. Transitivity is $k+k'$. For antisymmetry, $n=m+k$ and $m=n+k'$ give $m=m+(k+k')$, so cancellation and Proposition~\ref{prop:semiring} force $k=k'=0$. Totality is an induction on $n$ for fixed $m$. If $n=0$, then $0\le m$. If $m<n$ or $m=n$, then $m<n+1$. If $n<m$, then $m=n+S(j)=(n+1)+j$, so $n+1\le m$. Compatibility is immediate: $n=m+k$ gives $n+p=(m+p)+k$ and $np=mp+kp$.

Suppose, for a contradiction, that $A\subseteq\N$ has no least element. Induction on $n$ shows that no $k\le n$ lies in $A$. For $n=0$, the only candidate is $k=0$, and $0\in A$ would be least. If no $k\le n$ lies in $A$ and $n+1\in A$, then $n+1$ is least in $A$: any $k<n+1$ can be written $n+1=k+S(j)$, so $n=k+j$ and $k\le n$. Thus $n+1\notin A$, and no $k\le n+1$ lies in $A$. Hence $A=\varnothing$.
\end{proof}

\section{Integers and rationals}

An integer is a formal difference $a-b$ of natural numbers. Two differences are the same integer when $a+d=b+c$.

\begin{proposition}\label{prop:integers}
On $\N\times\N$, declare $(a,b)\sim(c,d)$ when $a+d=b+c$. The relation is an equivalence, and the quotient $\Z=(\N\times\N)/{\sim}$, with the operations
\[
\begin{gathered}[(a,b)]+[(c,d)]=[(a+c,b+d)],\qq{}[(a,b)]\cdot[(c,d)]=[(ac+bd,ad+bc)]\end{gathered}
\]
is a commutative ring without zero divisors. The map $n\mapsto[(n,0)]$ embeds $\N$, and every integer is $n$ or $-n=[(0,n)]$ for some $n\in\N$. With the positive elements $\{[(a,b)]:b<a\}$, the ring $\Z$ is ordered.
\end{proposition}
\begin{proof}
Transitivity: $a+d=b+c$ and $c+f=d+e$ give $a+d+c+f=b+c+d+e$, so cancellation yields $a+f=b+e$. A change of representatives does not change the sum or the product. For the sum this is immediate. For the product, replace $(a,b)$ by $(a',b')$ with $a+b'=a'+b$. Then
\[
\begin{aligned}(ac+bd)+(a'd+b'c)&=c(a+b')+d(a'+b)\\&=c(a'+b)+d(a+b')\\&=(a'c+b'd)+(ad+bc),\end{aligned}
\]
which is the statement $[(ac+bd,ad+bc)]=[(a'c+b'd,a'd+b'c)]$. The second factor is the same argument with the sides swapped. Each ring axiom is now an identity in $\N$, and Proposition~\ref{prop:semiring} gives it. For instance $[(0,0)]$ is zero and $[(b,a)]$ is the opposite of $[(a,b)]$. By totality, $(a,b)$ has either $a=b+n$ or $b=a+n$, so $[(a,b)]$ is $[(n,0)]$ or $[(0,n)]$. If $x$ and $y$ are positive, write $x=[(m,0)]$ and $y=[(n,0)]$ with $m,n\ne0$. Then $x+y$ and $xy=[(mn,0)]$ are positive, because $mn\ne0$ by Proposition~\ref{prop:semiring}(f) and (h). Every non-zero integer is positive or has a positive opposite, so a product of non-zero integers is plus or minus a positive integer, hence not zero.
\end{proof}

The rationals are built from $\Z$ by the same quotient Volume~3, Chapter~6 uses for the field of fractions of any domain: $\Q=\{(a,b)\in\Z\times\Z:b\ne0\}/{\sim}$ with $(a,b)\sim(c,d)$ if and only if $ad=bc$, and with the usual operations on $\frac ab$. The checks are identities of the same kind as for $\Z$, and the result is a field containing $\Z$. Order it by declaring $\frac ab>0$ if and only if $ab>0$. The sign does not depend on the representative: if $\frac ab=\frac cd$, then $ab\,d^2=cd\,b^2$, and $b^2,d^2>0$. Positive rationals are stable under sum and product, so $\Q$ is an \emph{ordered field}. It is \emph{Archimedean}: if $\frac ab>0$ with $a,b>0$, the integer $n=a+1$ satisfies $n>\frac ab$, because $nb-a\ge a+1-a>0$.

\begin{definition}
An \emph{ordered field} is a field $F$ with a subset $F_{>0}$ of positive elements, stable under sums and products, such that each $x\in F$ lies in exactly one of $F_{>0}$, $\{0\}$ and $-F_{>0}$. One writes $x<y$ when $y-x\in F_{>0}$. The field is \emph{Archimedean} when for every $x\in F$ some $n\in\N$ satisfies $x<n\cdot1$. It has the \emph{least upper bound property} when every non-empty subset that is bounded above has a least upper bound.
\end{definition}

In an ordered field, $1=1^2>0$, so $n\cdot1>0$ for $n\ge1$. The map $\Z\to F$ is injective, and $F$ contains a copy of $\Q$. The inequality rules of Volume~1 hold in any ordered field, by the same proofs. What $\Q$ lacks is the least upper bound property: the set $\{q\in\Q:q^2<2\}$ has no least upper bound in $\Q$ (Exercise~\ref{ex:sqrt2}).

\section{The real numbers}\label{sec:reals}

How do you name a number that is not on the list? The rationals have holes. The sequence $1$, $1.4$, $1.41$, $1.414$, \ldots{} crowds together as if it were heading somewhere, and in $\Q$ there is nowhere to arrive. Dedekind's answer was to define $\sqrt2$ as the cut it makes, the pair of classes (those below, those above). Figure~\ref{fig:rwcut} is that cut. Cantor's answer, the one followed here, is to take the missing limit to be the sequence itself, or rather the whole family of sequences that crowd together in the same way.

Cantor (1872) and M\'eray (1869) defined a real number as whatever a Cauchy sequence of rationals ``converges to'', and they identified two sequences when their difference tends to $0$. In this section $\varepsilon$ and $\delta$ are positive rationals, and a sequence is a sequence of rationals unless the text says otherwise.

\begin{definition}
A sequence $(x_n)$ in $\Q$ is \emph{Cauchy} when for every $\varepsilon$ there is an $N$ such that $|x_n-x_m|<\varepsilon$ for all $n,m\ge N$. It is \emph{null} when for every $\varepsilon$ there is an $N$ such that $|x_n|<\varepsilon$ for all $n\ge N$. Let $\mathcal C$ be the set of Cauchy sequences and $\mathcal N$ the set of null sequences, and set $\R=\mathcal C/{\sim}$, where $x\sim y$ if and only if $x-y\in\mathcal N$. The class of $x$ is written $[x]$.
\end{definition}

\begin{figure}[ht]
\centering
\fig{ch01-rw-cauchy}
\caption{Two rational sequences that eventually lie in every tube of height $\varepsilon$. Their difference is null, so they name one real number. A sequence that stays out of some tube forever is not Cauchy.}
\label{fig:rwcauchy}
\end{figure}

\begin{lemma}\label{lem:cauchybasic}
\begin{enumerate}[label=(\alph*)]
\item A Cauchy sequence is bounded.
\item $\mathcal C$ is a commutative ring under termwise operations, and $\mathcal N$ is an ideal of it.
\item If $x\in\mathcal C\setminus\mathcal N$, there exist $\delta$ and $N$ such that either $x_n\ge\delta$ for all $n\ge N$, or $x_n\le-\delta$ for all $n\ge N$.
\end{enumerate}
\end{lemma}
\begin{proof}
(a) Take $\varepsilon=1$. Then $|x_n|\le|x_N|+1$ for $n\ge N$, and only finitely many terms come before $N$. (b) Sums are immediate. For products, if $|x_n|$ and $|y_n|$ are at most $M$ for every $n$, then $|x_ny_n-x_my_m|\le M|y_n-y_m|+M|x_n-x_m|$. The same estimate with $y$ null shows that a bounded sequence times a null sequence is null, so $\mathcal N$ is an ideal. (c) Since $x$ is not null, some $\varepsilon$ has $|x_n|\ge\varepsilon$ for infinitely many $n$. Set $\delta=\frac\varepsilon2$ and choose $N$ so that $|x_n-x_m|<\delta$ whenever $n,m\ge N$. Pick $m\ge N$ with $|x_m|\ge\varepsilon$. If $x_m\ge\varepsilon$, then $x_n>x_m-\delta\ge\delta$ for every $n\ge N$. If $x_m\le-\varepsilon$, then $x_n\le-\delta$ in the same way.
\end{proof}

Therefore $\R=\mathcal C/\mathcal N$ is a commutative ring. Constant sequences embed $\Q$ by $q\mapsto\iota(q)$. Call $[x]$ \emph{positive} when the first case of (c) occurs. The name does not depend on the representative: if $z$ is null and $|z_n|<\frac\delta2$ for large $n$, then $x_n+z_n\ge\frac\delta2$.

\begin{theorem}\label{thm:reals}
The set $\R$ is an Archimedean ordered field. The map $\iota:\Q\to\R$ is an injective morphism of ordered fields, and $\Q$ is dense in $\R$: between two reals $a<b$ there is a rational $q$ with $a<\iota(q)<b$. Every Cauchy sequence of reals converges in $\R$, and $\R$ has the least upper bound property.
\end{theorem}
\begin{proof}
\emph{Field.} Take $[x]\ne0$. Lemma~\ref{lem:cauchybasic}(c) supplies a $\delta>0$ and an index $N$ with $|x_n|\ge\delta$ for every $n\ge N$. Set $y_n=\frac1{x_n}$ for $n\ge N$ and $y_n=1$ before that index. Then $|y_n-y_m|=\frac{|x_m-x_n|}{|x_nx_m|}\le\frac{|x_m-x_n|}{\delta^2}$ for $n,m\ge N$, so $y\in\mathcal C$. Also $x_ny_n-1=0$ for $n\ge N$, hence $[x][y]=1$. And $1\ne0$, because the constant sequence $1$ is not null.

\emph{Order.} By Lemma~\ref{lem:cauchybasic}(c), each non-zero class $[x]$ is positive or has a positive opposite, and not both: $x_n\ge\delta$ and $x_n\le-\delta'$ cannot hold together for all large $n$. Sums and products of positive elements are positive, since $x_n+y_n\ge\delta+\delta'$ and $x_ny_n\ge\delta\delta'$. The map $\iota$ is a ring morphism. It is injective because a non-zero constant sequence is not null, and $q>0$ if and only if $\iota(q)>0$.

\emph{Archimedes.} If $|x_n|\le M$ for every $n$, by Lemma~\ref{lem:cauchybasic}(a), then $M+1-x_n\ge1$, so $[x]<\iota(M+1)$. Some natural number $n$ exceeds $M+1$.

\emph{Density.} Let $a=[x]<b=[y]$. Then some $\delta$ and $N_0$ have $y_n-x_n\ge\delta$ for $n\ge N_0$. Choose $N\ge N_0$ with $|x_n-x_m|$ and $|y_n-y_m|$ smaller than $\frac\delta4$ for $n,m\ge N$, and set $q=\frac{x_N+y_N}2$. For $n\ge N$,
$q-x_n\ge q-x_N-\frac\delta4=\frac{y_N-x_N}2-\frac\delta4\ge\frac\delta4$, so $\iota(q)>a$. The same estimate gives $\iota(q)<b$.

\emph{Rational approximations converge.} Take $x\in\mathcal C$. Given $\varepsilon$, choose $N$ with $|x_n-x_m|\le\frac\varepsilon2$ for $n,m\ge N$. For fixed $n\ge N$ the sequence $\bigl(\frac\varepsilon2-|x_m-x_n|\bigr)_m$ is non-negative for $m\ge N$, so $|[x]-\iota(x_n)|\le\iota\bigl(\frac\varepsilon2\bigr)<\iota(\varepsilon)$. Every real $e>0$ exceeds some $\iota(\varepsilon)$, by density, so $\iota(x_n)\to[x]$ in $\R$.

\emph{Completeness.} Start with a Cauchy sequence $(a_k)$ in $\R$. Density supplies rationals $q_k$ with $|a_k-\iota(q_k)|<\iota\bigl(\frac1{k+1}\bigr)$. Then $|q_k-q_l|\le|q_k-a_k|+|a_k-a_l|+|a_l-q_l|$, so $(q_k)$ is Cauchy in $\Q$: an inequality of rationals holds if and only if it holds after $\iota$. Set $a=[(q_k)]$. The previous paragraph gives $|a-a_k|\le|a-\iota(q_k)|+\frac1{k+1}\to0$.

\emph{Least upper bounds.} Let $A\ne\varnothing$ be bounded above by $u_0$, and let $l_0$ lie below some element of $A$. Bisect. With $m=\frac{l_k+u_k}2$, set $(l_{k+1},u_{k+1})=(l_k,m)$ when $m$ is an upper bound of $A$, and $(m,u_k)$ otherwise. At each stage $u_k$ is an upper bound of $A$ and $l_k$ is not, and the gap is $u_k-l_k=2^{-k}(u_0-l_0)$, which tends to $0$ by the Archimedean property. Both sequences are monotone, and $l_k\le l_j\le u_j\le u_k$ for $j\ge k$, so both are Cauchy and share a limit $s$. For $a\in A$ one has $a\le u_k$ for every $k$, hence $a\le s$: if $a>s$, then $u_k<a$ for large $k$. If $v<s$, some $k$ has $v<l_k$, and some $a\in A$ then exceeds $l_k$, hence exceeds $v$. So $v$ is not an upper bound. Thus $s=\sup A$.
\end{proof}

From here on, $q$ is identified with $\iota(q)$. The axiom of Volume~1 is now a theorem. It is the only one the later books need: every other property of $\R$ used in the series follows from it, and the next theorem says that the property determines $\R$.

\begin{theorem}[uniqueness of $\R$]\label{thm:uniqueR}
Let $F$ be an ordered field with the least upper bound property. Exactly one field isomorphism $\varphi:\R\to F$ exists, and that isomorphism preserves order.
\end{theorem}
\begin{proof}
\emph{$F$ is Archimedean.} Otherwise $\N\cdot1$ is bounded above. Let $s$ be its supremum. Then $s-1<n$ for some $n\in\N$, and $n+1>s$. \emph{$\Q$ is dense in $F$.} For $x<y$, take $n>\frac1{y-x}$. Choose $N\in\N$ with $N+nx>0$, by Archimedes, and let $m_0$ be the least natural number greater than $N+nx$ (Proposition~\ref{prop:wellorder}). In particular $m_0\ge1$. The integer $m=m_0-N$ then satisfies $m>nx$. Also $m_0-1\le N+nx$, so $m-1\le nx$ and $m\le nx+1$. Thus $nx<m\le nx+1<ny$, and $x<\frac mn<y$. The same argument works in $\R$.

For $x\in\R$ set $L(x)=\{q\in\Q:q<x\}$ and $\varphi(x)=\sup_F L(x)$. The supremum exists: $L(x)$ is non-empty and bounded above by any rational at least $x$. For $x\in\Q$, density in $F$ gives $\varphi(x)=x$. If $x<y$, two rationals $x<q<q'<y$ give $\varphi(x)\le q<q'\le\varphi(y)$, so $\varphi$ is strictly increasing. Moreover $\{q\in\Q:q<\varphi(x)\}=L(x)$. A rational $q<x$ has a rational $q<q'<x$, so $q<q'\le\varphi(x)$. A rational $q\ge x$ bounds $L(x)$, so $\varphi(x)\le q$. The map is onto: for $y\in F$, set $x=\sup_\R\{q\in\Q:q<y\}$. The same comparison shows $L(x)=\{q\in\Q:q<y\}$, so density in $F$ gives $\varphi(x)=\sup_F L(x)=y$.

\emph{Sums.} $L(x+y)=L(x)+L(y)$. If $q<x+y$, pick a rational $r$ with $q-y<r<x$; then $q=r+(q-r)$ with $q-r<y$. The other inclusion is immediate. In any ordered field the supremum of a sumset is the sum of the suprema: $a+b\le\sup A+\sup B$, and if $\sup A-\eta<a$ and $\sup B-\eta<b$ then $a+b>\sup A+\sup B-2\eta$. Hence $\varphi(x+y)=\varphi(x)+\varphi(y)$, and then $\varphi(-x)=-\varphi(x)$.
\emph{Products.} For $x,y>0$, the positive part of $L(xy)$ is $\{rs:r\in L(x),\,s\in L(y),\,r,s>0\}$, by the same argument with quotients, and suprema of products of positive sets multiply. Hence $\varphi(xy)=\varphi(x)\varphi(y)$ when $x$ and $y$ are positive, and the identity $\varphi(-x)=-\varphi(x)$ extends it to every sign.

\emph{Uniqueness.} Let $\psi:\R\to F$ be an arbitrary morphism of fields. It fixes $\Z$, hence $\Q$, and $\psi(0)=0$. Every $x>0$ in $\R$ is a square. Let $S=\{q\in\Q:q\ge0,\ q^2<x\}$. The set $S$ contains $0$ and is bounded above by Archimedes. Let $s=\sup S$. Suppose first that $s^2<x$. Set $\delta=\min\bigl(1,\frac{x-s^2}{2s+2}\bigr)>0$, and choose a rational $h$ with $0<h<\delta$. Then $h\le1$, so $(s+h)^2=s^2+2sh+h^2\le s^2+h(2s+1)<s^2+(x-s^2)=x$. Density of $\Q$ then yields a rational $q$ with $s<q<s+h$, so $q^2<x$ and $q>s$, contradicting the choice of $s$. Suppose instead that $s^2>x$. Then $s>0$, because $0\in S$, and $\delta=\min\bigl(s,\frac{s^2-x}{2s}\bigr)>0$. Any rational $h$ with $0<h<\delta$ satisfies $(s-h)^2=s^2-2sh+h^2>s^2-2sh\ge x$. Thus $s-h$ is a strictly smaller upper bound of $S$. Thus $s^2=x$. So $x\ge0$ gives $\psi(x)=\psi(\sqrt x)^2\ge0$: the morphism $\psi$ is increasing. Then for rationals $q<x<q'$ one has $q\le\psi(x)\le q'$, so density of $\Q$ in $F$ forces $\psi(x)=\varphi(x)$.
\end{proof}

Dedekind's cuts (1872) are a second road to $\R$: a real number is the set of rationals below it. Theorem~\ref{thm:uniqueR} says that road reaches the same field (Exercise~\ref{ex:cuts}). School decimals are a third road. They work, but the carries are painful.

\section{Countable and uncountable}

Picture a hotel with rooms numbered $0,1,2,\ldots$, every room full. One new guest arrives. The manager is calm: she asks the guest in room $n$ to move to room $n+1$, and room $0$ is free. A coach arrives with infinitely many new guests. She moves the guest in room $n$ to room $2n$, and the odd rooms are free. Hilbert told this story in his G\"ottingen lectures of the winter 1924--25, to show that ``as many as'' is a delicate phrase for infinite sets. Cantor's definition is the precise one: two sets have the same size when their elements can be paired off.

\begin{definition}
Two sets $A$ and $B$ are \emph{equipotent}, written $|A|=|B|$, when there is a bijection $A\to B$. One writes $|A|\le|B|$ when there is an injection $A\to B$. A set is \emph{finite} when it is equipotent to some $n=\{0,\dots,n-1\}$, \emph{infinite} when it is not finite, and \emph{countable} when $|A|\le|\N|$.
\end{definition}

\begin{think}
Does $\Q$ outnumber $\Z$? Any two integers have infinitely many rationals between them. Does $\R$ outnumber $\Q$, even though every real is a limit of rationals?
\end{think}

\begin{proposition}\label{prop:countable}
\begin{enumerate}[label=(\alph*)]
\item A subset of $\N$ is finite or equipotent to $\N$. So a countable set is finite or in bijection with $\N$.
\item The product $\N\times\N$ is countable, and so are $\Z$ and $\Q$.
\item (This part uses countable choice.) The union of countably many countable sets is countable.
\end{enumerate}
\end{proposition}
\begin{proof}
(a) Two facts come first. First, subsets of finite sets are finite. Induct on $n=\{0,\dots,n-1\}$. The empty set is finite. If $B\subseteq n$ and $n-1\notin B$, then $B\subseteq n-1$. If $n-1\in B$, then $B\setminus\{n-1\}$ is finite by the same induction, and adding one element produces a set equipotent to the successor. Every subset of $\{0,\dots,N\}$ is therefore finite. And $\N$ itself is not finite. The image of an injection $\{0,\dots,n-1\}\to\N$ is a non-empty finite subset of $\N$. Induction on the number of elements, using the total order of Proposition~\ref{prop:wellorder}, gives that set a greatest element $M$, and $M+1$ lies outside the image. Now let $A\subseteq\N$ be infinite. Then $A$ is non-empty, and so is $\{a\in A:a>a_k\}$: otherwise $A\subseteq\{0,\dots,a_k\}$, which is finite. By recursion, set $a_0=\min A$ and $a_{k+1}=\min\{a\in A:a>a_k\}$, using Proposition~\ref{prop:wellorder}. The map $k\mapsto a_k$ is strictly increasing, so $a_k\ge k$. Every $a\in A$ equals some $a_k$. If not, take the least $k$ with $a_k>a$. Then $k\ge1$, because $a_0\le a$, and $a_{k-1}<a<a_k$ contradicts the choice of $a_k$. (b) The map $(m,n)\mapsto2^m3^n$ is injective. By induction $3^t$ is odd for every $t$: $3^0=1$, and $3^{t+1}=3\cdot3^t$. Also $t\mapsto3^t$ is strictly increasing. If $2^m3^n=2^{m'}3^{n'}$ with $m\ge m'$, then $2^{m-m'}=3^{n'-n}$. The right side is odd, so the exponent of $2$ is $0$, hence $m=m'$ and $3^n=3^{n'}$, so $n=n'$. The integers inject into $\N\times\N$ by $n\mapsto(n,0)$ and $-n\mapsto(0,n)$. The rationals inject into $\Z\times\Z$ by writing each fraction in lowest terms with a positive denominator. (c) Let $A_0,A_1,\ldots$ be countable, and choose for each $k$ an injection $f_k:A_k\to\N$. For $a$ in the union, let $k(a)$ be the least $k$ with $a\in A_k$. Then $a\mapsto(k(a),f_{k(a)}(a))$ injects the union into $\N\times\N$.
\end{proof}

So $\Q$ can be listed as $q_0,q_1,q_2,\ldots$. The Calkin--Wilf tree of Figure~\ref{fig:calkinwilf} lists the positive rationals with no repetition, and even with a rule for the next term (Exercise~\ref{ex:calkinwilf}).

\begin{theorem}[Cantor, 1891]\label{thm:cantor}
For every set $A$ there is no surjection from $A$ onto $\mathcal P(A)$. In particular the inequality of cardinals is strict, $|A|<|\mathcal P(A)|$, and the power set $\mathcal P(\N)$ is uncountable.
\end{theorem}
\begin{proof}
Let $f:A\to\mathcal P(A)$ and set $D=\{a\in A:a\notin f(a)\}$. If $D=f(d)$, then $d\in D$ if and only if $d\notin f(d)=D$, which is absurd. So $D$ is not in the image. The map $a\mapsto\{a\}$ is an injection from $A$ to $\mathcal P(A)$.
\end{proof}

\centering

The sequence $d$ differs from $s_n$ in place $n$, so $d$ is missing from the list. Theorem~\ref{thm:cantor} is the same argument, with membership $a\in f(a)$ in place of the digit.}
\label{fig:diagonal}
\end{figure}

The same pattern is Russell's paradox, and it is Turing's proof that no program decides which programs halt. Comparing $\R$ with $\mathcal P(\N)$ needs a way to turn two injections into a bijection.

\begin{theorem}[Schr\"oder--Bernstein]\label{thm:sb}
If there are injections $f:A\to B$ and $g:B\to A$, then there is a bijection from $A$ to $B$.
\end{theorem}
\begin{proof}
Set $C_0=A\setminus g(B)$, $C_{n+1}=g(f(C_n))$ and $C=\bigcup_n C_n$. Define $h(a)=f(a)$ when $a\in C$, and $h(a)=g^{-1}(a)$ when $a\notin C$. The second clause makes sense: $a\notin C$ implies $a\notin C_0$, so $a\in g(B)$. \emph{Injective.} The map $h$ is injective on $C$ and on $A\setminus C$. A mixed collision $f(a)=g^{-1}(a')$, with $a\in C_n$ and $a'\notin C$, would put $a'=g(f(a))$ into $C_{n+1}$, which is absurd. \emph{Surjective.} Take $b\in B$. If $g(b)\notin C$, then $h(g(b))=b$. If $g(b)\in C$, then $g(b)\notin C_0$, so $g(b)\in C_{n+1}=g(f(C_n))$ for some $n$. Since $g$ is injective, $b=f(a)$ for some $a\in C_n$, and $h(a)=b$.
\end{proof}

\begin{theorem}\label{thm:continuum}
$|\R|=|[0,1]|=|\mathcal P(\N)|$. In particular no list exhausts $\R$, and the same is true of every interval that contains more than one point.
\end{theorem}
\begin{proof}
The map $x\mapsto L(x)=\{q\in\Q:q<x\}$ is an injection from $\R$ into $\mathcal P(\Q)$, by density of $\Q$. A bijection $\Q\to\N$ from Proposition~\ref{prop:countable} induces a bijection of power sets, so $|\mathcal P(\Q)|=|\mathcal P(\N)|$. In the other direction, $A\mapsto\sum_{n\in A}2\cdot3^{-n-1}$ injects $\mathcal P(\N)$ into $[0,1]$. If $A\ne B$ and $n$ is the least element of the symmetric difference, say $n\in A$, the two sums differ by at least $2\cdot3^{-n-1}-\sum_{k>n}2\cdot3^{-k-1}=3^{-n-1}>0$. Therefore
\[|\mathcal P(\N)|\le|[0,1]|\le|\R|\le|\mathcal P(\N)|,\]
and Schr\"oder--Bernstein gives the equalities. Any interval $[a,b]$ with $a<b$ is in bijection with $[0,1]$, by the affine map $t\mapsto a+(b-a)t$.
\end{proof}

A countable subset of $\R$ therefore leaves out most reals. The algebraic numbers are countable (Exercise~\ref{ex:algebraic}), so transcendental numbers exist, and the proof does not exhibit a single one. Cantor's paper of 1874 did exactly this. Is there a set of reals whose size sits strictly between $|\N|$ and $|\R|$? The \emph{continuum hypothesis} answers no. G\"odel (1938) and Cohen (1963) showed that ZFC can neither prove the hypothesis nor refute it.

\section{Choice, Zorn and well-ordering}\label{sec:choice}

In 1904 Ernst Zermelo proved that every set can be well-ordered, $\R$ included. The proof was two pages long, and it caused a storm. It rested on a principle mathematicians had been using without saying so: from any family of non-empty sets, one element can be chosen in each. Borel, Baire and Lebesgue objected that a choice nobody can describe is not a choice. Hadamard answered that existence and description are different things. A century later the verdict is settled. The axiom of choice cannot be proved from the other axioms, and it cannot be refuted from them (G\"odel 1938, Cohen 1963). Nearly all of mathematics uses it, and it has consequences that defy a picture. The most famous is the Banach--Tarski paradox (1924; quoted here, not proved): a ball can be cut into five pieces and reassembled into two balls of the same size. An anagram of ``Banach--Tarski'' is ``Banach--Tarski Banach--Tarski''.

\begin{definition}
The \emph{axiom of choice} (AC) says: for every set $\mathcal A$ of non-empty sets there is a function $c$ on $\mathcal A$ with $c(A)\in A$ for every $A\in\mathcal A$. The function $c$ is a \emph{choice function}.
\end{definition}

For finitely many sets, choice follows from the other axioms by induction. For the countably many enumerations in Proposition~\ref{prop:countable}(c), and for one point in each class of $\R/\Q$ (Vitali's set, Chapter~\ref{ch:measures}), it does not. The usual way to call on AC is through an equivalent statement about orders.

\begin{definition}
A \emph{partial order} on a set $P$ is reflexive, antisymmetric and transitive. A \emph{chain} is a subset on which the order is total. An \emph{upper bound} of $C\subseteq P$ is an element $u$ with $c\le u$ for every $c\in C$. A \emph{maximal} element is an $m$ with no $x>m$. A \emph{well-order} is a total order such that every non-empty subset has a least element.
\end{definition}

\begin{theorem}[Zorn's lemma]\label{thm:zorn}
Assume AC. If $P$ is a non-empty partially ordered set and every chain in $P$ has an upper bound, then $P$ has a maximal element.
\end{theorem}
\begin{proof}
Suppose $P$ has no maximal element. Then every chain $C$ has a \emph{strict} upper bound: some upper bound $u$ exists, $u$ is not maximal, and some $v>u$ bounds $C$ strictly. By AC, choose a strict upper bound $g(C)$ for every chain $C$, the empty chain included. Call $W\subseteq P$ a \emph{$g$-set} when the order of $P$ well-orders $W$ and $w=g(W_{<w})$ for every $w\in W$, where $W_{<w}=\{x\in W:x<w\}$. A subset $S\subseteq W$ is an \emph{initial segment} of $W$ when $s\in S$, $w\in W$ and $w<s$ together imply $w\in S$.

\emph{Any two $g$-sets are comparable: one is an initial segment of the other.} Let $W$ and $W'$ be $g$-sets, and let $D$ be the union of all sets that are initial segments of both. Then $D$ itself is one. Suppose $D\ne W$ and $D\ne W'$, and set $w=\min(W\setminus D)$ and $w'=\min(W'\setminus D)$. Then $W_{<w}=D$: elements of $W$ below $w$ lie in $D$ by minimality of $w$, and if some $d\in D$ had $d\ge w$ then $w\in D$, because $D$ is an initial segment. Likewise $W'_{<w'}=D$, so $w=g(D)=w'$. Then $D\cup\{w\}$ is an initial segment of both, which contradicts the definition of $D$.

\emph{The union $U$ of all $g$-sets is a $g$-set.} Two elements of $U$ lie in $g$-sets $W$ and $W'$, and one of those contains the other, so the two elements are comparable. Thus $U$ is totally ordered. Each $g$-set $W$ is an initial segment of $U$: if $w\in W$ and $u<w$ with $u$ in a $g$-set $W'$, then $u\in W$, whether $W'$ is an initial segment of $W$ or $W$ is an initial segment of $W'$. Hence a non-empty $S\subseteq U$ that meets some $W$ has, as its least element, the least element of $S\cap W$. For $u\in W$ one has $U_{<u}=W_{<u}$, so $g(U_{<u})=u$.

The union $U$ is a chain, so $g(U)$ exists, and the choice of $g$ forces $g(U)\notin U$. But $U\cup\{g(U)\}$ is a $g$-set, with $g(U)$ on top and $g(U)=g(U_{<g(U)})$, so this larger set is contained in $U$. That is a contradiction.
\end{proof}

\begin{theorem}\label{thm:wellordering}
In ZF the following are equivalent: AC; Zorn's lemma; every set can be well-ordered (Zermelo, 1904).
\end{theorem}
\begin{proof}
AC implies Zorn's lemma by Theorem~\ref{thm:zorn}. \emph{Zorn implies a well-ordering.} Given $X$, let $P$ be the set of pairs $(S,\preceq)$ where $S\subseteq X$ and $\preceq$ well-orders $S$. Order $P$ by declaring $(S,\preceq)\le(S',\preceq')$ when $S$ is an initial segment of $S'$ and $\preceq'$ extends $\preceq$. A chain has as an upper bound its union $S^*$ with the union order. That order is total. A non-empty $A\subseteq S^*$ meets some $S$ of the chain, and that $S$ is an initial segment of $S^*$, so the least element of $A\cap S$ is least in $A$. Let $(M,\preceq)$ be maximal. If some $x$ lies in $X\setminus M$, putting $x$ above $M$ gives a strictly larger element of $P$. So $M=X$. \emph{A well-ordering implies AC.} Well-order $\bigcup\mathcal A$, and let $c(A)$ be the least element of $A$.
\end{proof}

\begin{theorem}\label{thm:basis}
Assume AC. Every vector space $V$ over a field $K$ has a basis. Sharper: every linearly independent subset of $V$ extends to a basis.
\end{theorem}
\begin{proof}
Let $L_0$ be independent, and order by inclusion the independent sets that contain $L_0$. The union of a chain is independent: a linear relation uses finitely many vectors, and those vectors lie in one member of the chain. Zorn's lemma supplies a maximal independent set $B\supseteq L_0$. If $v$ is not in the span of $B$, then $B\cup\{v\}$ is independent, which contradicts maximality. So $B$ spans $V$.
\end{proof}

A basis of $\R$ as a vector space over $\Q$ is a \emph{Hamel basis} (1905). Nobody can write one down, and it produces strange functions (Exercise~\ref{ex:hamel}). The same pattern shows that every proper ideal of a commutative ring sits in a maximal ideal (Exercise~\ref{ex:krull}), that every field has an algebraic closure, and, in Chapter~\ref{ch:compact}, Tychonoff's theorem. Choice is independent of ZF: G\"odel (1938) showed that it cannot be refuted, and Cohen (1963) showed that it cannot be proved.

\begin{beauty}
Numbers, functions and spaces are sets, and a short list of axioms produces all of them. Building $\R$ from $\Q$ is the first \emph{completion}. Chapter~\ref{ch:metric} repeats the construction for an arbitrary metric space, and it finds the $p$-adic numbers as completions of $\Q$ for other distances. Volume~8 finds $L^2$ as the completion of the continuous functions. Cantor's diagonal is the argument that travels: it shows that $\R$ is uncountable, that there is no set of all sets, that some true sentences of arithmetic are unprovable (G\"odel), and that some problems have no program that solves them (Turing). Those are foundational results in mathematical logic. Choice is where a picture stops being a guide. It gives every vector space a basis, and it gives subsets of the line that have no reasonable length.
\end{beauty}

\section{What we proved, and what comes next}

The questions in the opening have answers. There are as many rationals as integers, because $\Q$ is countable (Proposition~\ref{prop:countable}). There are more reals than rationals, because no list contains every real (Theorems~\ref{thm:cantor} and~\ref{thm:continuum}). A square has exactly as many points as one side (Exercise~\ref{ex:square}). A real number, in the construction of this chapter, is a class of Cauchy sequences of rationals.

Three things the earlier volumes used on trust are now theorems. Induction is available on $\N$, and so is definition by recursion (Theorems~\ref{thm:peano} and~\ref{thm:recursion}). Every non-empty set of reals that is bounded above has a least upper bound, and every Cauchy sequence of reals converges (Theorem~\ref{thm:reals}). Only one field has these properties (Theorem~\ref{thm:uniqueR}), so nothing later depends on the particular construction of $\R$. Choice entered in three equivalent forms (Theorem~\ref{thm:wellordering}). Its two most visible uses in this volume are Tychonoff's theorem in Chapter~\ref{ch:compact} and the set with no length in Chapter~\ref{ch:measures}.

Building $\R$ used very little of the special character of $\Q$: only the distance $|x-y|$, and sequences that crowd together. What happens if the same construction is run on another set of points, or with another distance on $\Q$? Chapter~\ref{ch:metric} does both.

\section{Exercises}

\begin{exercise}[$\star$]\label{ex:sqrt2}
Prove that the set $A=\{q\in\Q:q>0,\ q^2<2\}$ has no least upper bound inside $\Q$. Use the map $q\mapsto\frac{2q+2}{q+2}$: it sends $A$ into $A$ and raises every element of $A$, and it sends each positive rational upper bound of $A$ to a smaller one.
\end{exercise}

\begin{exercise}[$\star$]\label{ex:algebraic}
A complex number is \emph{algebraic} when it is a root of some non-zero polynomial with integer coefficients. Prove that there are only countably many algebraic numbers. Deduce that the transcendental reals form an uncountable set.
\end{exercise}

\begin{exercise}[$\star$]\label{ex:cauchyfe}
Let $f:\R\to\R$ satisfy $f(x+y)=f(x)+f(y)$ for all real $x$ and $y$. Show that $f(q)=qf(1)$ for every rational $q$, and that $f(x)=xf(1)$ for every real $x$ whenever $f$ is continuous, or whenever $f$ is monotone.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:square}
Show that $|[0,1]\times[0,1]|=|[0,1]|$: a filled square has as many points as one of its sides. Deduce that $|\R^n|=|\R|$ for every $n\ge1$.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:hamel}
(a) Show that $\R$, as a vector space over $\Q$, has a basis $B$. (b) Fix $b_0\in B$, and let $f(x)$ be the coordinate of $x$ along $b_0$. Show that $f$ is additive, and that $f$ is not of the form $x\mapsto cx$. (c) Show that the graph of any additive $f:\R\to\R$ that is not of the form $x\mapsto cx$ is dense in $\R^2$. Conclude that any such $f$ is unbounded on every non-empty open interval.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:cuts}
A \emph{Dedekind cut} is a set $\alpha\subseteq\Q$ that is non-empty, not all of $\Q$, closed downwards ($q<a\in\alpha$ implies $q\in\alpha$), and without a largest element. (a) Prove that the set of all cuts, ordered by inclusion, has the least upper bound property. (b) Show that $x\mapsto\{q\in\Q:q<x\}$ is a strictly increasing bijection from $\R$ onto the set of cuts.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:krull}
Assume AC. Let $R$ be a commutative ring in which $1\ne0$. Prove that every ideal $I\ne R$ sits inside some maximal ideal.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:functions}
Show that the set $C(\R,\R)$ of continuous real functions has the cardinality of $\R$, while the set $\R^\R$ of all functions $\R\to\R$ has the cardinality of $\mathcal P(\R)$, which is strictly larger.
\end{exercise}

\begin{exercise}[$\star\star\star$]\label{ex:calkinwilf}
\emph{Recounting the rationals.} In the Calkin--Wilf tree (Figure~\ref{fig:calkinwilf}) the root is $\frac11$, and the children of $\frac ab$ are $\frac a{a+b}$ on the left and $\frac{a+b}b$ on the right. Number the nodes level by level, left to right: $q_1=\frac11$, $q_2=\frac12$, $q_3=\frac21$, $q_4=\frac13$, and so on, so that the children of $q_n$ are $q_{2n}$ and $q_{2n+1}$. (a) Show that every positive rational appears exactly once, and already in lowest terms. (b) Show Newman's formula $q_{n+1}=\dfrac1{2\lfloor q_n\rfloor+1-q_n}$, which lists every positive rational and never computes a gcd.
\end{exercise}

\begin{exercise}[$\star$]\label{ex:cwcompute}
\emph{A computation.} Keep the numbering of Exercise~\ref{ex:calkinwilf}. (a) Start from $q_1=1$ and compute $q_2,\dots,q_{10}$ from Newman's formula $q_{n+1}=\frac1{2\lfloor q_n\rfloor+1-q_n}$. (b) Find the index $n$ with $q_n=\frac{13}{5}$, without listing the terms that come before it.
\end{exercise}

\begin{exercise}[$\star$]\label{ex:v7c01a}
Show that the set of all finite subsets of $\N$ is countable. The argument must not call on the axiom of choice: each finite set has to be listed by a rule you can write down.
\end{exercise}

\begin{exercise}[$\star$]\label{ex:v7c01b}
Let $(a_n)$ and $(b_n)$ be rational sequences with $a_n\le a_{n+1}\le b_{n+1}\le b_n$ for every $n$, and with $b_n-a_n\to0$. Show that there is exactly one real number that lies in every interval $[a_n,b_n]$.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:v7c01c}
Show, without the axiom of choice, that any finite-dimensional vector subspace of $\R$ over $\Q$ is a countable set. Deduce that $\R$ is not finite-dimensional as a vector space over $\Q$.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:v7c01d}
Let $F$ be an ordered field in which every non-empty set that is bounded above has a least upper bound. Show directly that $F$ is Archimedean, and that between any $x<y$ in $F$ there is a rational. (This is the opening of the proof of Theorem~\ref{thm:uniqueR}, written out on its own.)
\end{exercise}

\section{Solutions}

\begin{solution}{ex:sqrt2}
\idea A least upper bound of $A$ inside $\Q$ would be a square root of $2$. Volume~1 already knows that $\sqrt2$ is irrational. To stay inside $\Q$, use a map that improves every lower guess and every upper guess, so no rational can be the best one.
\writeup Let $\phi(q)=\frac{2q+2}{q+2}$ for $q>0$. Then $\phi(q)-q=\frac{2-q^2}{q+2}$ and $\phi(q)^2-2=\frac{2(q^2-2)}{(q+2)^2}$. If $q\in A$, both identities say $\phi(q)>q$ and $\phi(q)^2<2$, so $\phi(q)$ is a strictly larger element of $A$. If $q>0$ is a rational upper bound of $A$, then $q^2\ge2$: otherwise $\phi(q)\in A$ would exceed $q$. No rational has square $2$, so $q^2>2$, and then $\phi(q)<q$ with $\phi(q)^2>2$. Every $a\in A$ satisfies $a^2<2<\phi(q)^2$, so $\phi(q)$ is a strictly smaller upper bound. An upper bound $s\in\Q$ is positive, because $1\in A$, and $\phi(s)$ is a smaller one. So $A$ has no least upper bound in $\Q$.
\end{solution}

\begin{solution}{ex:algebraic}
\idea A countable union of finite sets is countable, once each finite set comes with an order that lists it. Group the polynomials by a size that admits only finitely many polynomials of each size.
\writeup For $P=\sum_{i\le d}a_iX^i$ with $a_d\ne0$, set $h(P)=d+\sum|a_i|\in\N$. For each $n$ only finitely many polynomials have $h(P)=n$: the degree is at most $n$, and each coefficient lies in $[-n,n]$. Each such polynomial has at most $n$ roots. The algebraic numbers are therefore a countable union of finite sets. No choice is required, because the roots of one polynomial can be listed by increasing real part and, in a tie, by increasing imaginary part (Proposition~\ref{prop:countable}(c) is the model, but the listing here is explicit). If the transcendental reals $T$ were countable, then $\R=T\cup(\R\cap\text{algebraic})$ would be countable, contradicting Theorem~\ref{thm:continuum}.
\end{solution}

\begin{solution}{ex:cauchyfe}
\idea Additivity forces linearity over $\Q$. Continuity, or monotonicity, carries that linearity from the rationals to the reals by approximation.
\writeup The identity $f(0)=f(0)+f(0)$ gives $f(0)=0$, and $f(-x)=-f(x)$. Induction gives $f(nx)=nf(x)$ for $n\in\N$. For $q=\frac mn$ one has $nf(q)=f(m)=mf(1)$, so $f(q)=qf(1)$. If $f$ is continuous and $q_k\to x$ through rationals, then $f(x)=\lim q_kf(1)=xf(1)$. If $f$ is non-decreasing and $q<x<q'$ are rational, then $qf(1)\le f(x)\le q'f(1)$. Sending $q$ and $q'$ to $x$ gives $f(x)=xf(1)$. A non-increasing $f$ is the same argument with the inequalities reversed.
\end{solution}

\begin{solution}{ex:square}
\idea Both sets are as large as $\mathcal P(\N)$, or as $\mathcal P(\N)\times\mathcal P(\N)$, and two copies of $\N$ fit inside one. Schr\"oder--Bernstein turns the injections into a bijection.
\writeup Theorem~\ref{thm:continuum} supplies a bijection $\beta:[0,1]\to\mathcal P(\N)$. The map $(A,B)\mapsto\{2a:a\in A\}\cup\{2b+1:b\in B\}$ is a bijection from $\mathcal P(\N)^2$ to $\mathcal P(\N)$, because a subset of $\N$ is determined by its even members and its odd members. The composite $[0,1]^2\to\mathcal P(\N)^2\to\mathcal P(\N)\to[0,1]$ is a bijection. For higher dimension, $|\R|=|[0,1]|$, so $|\R^2|=|[0,1]^2|=|[0,1]|=|\R|$, and induction gives $|\R^n|=|\R^{n-1}\times\R|=|\R\times\R|=|\R|$. Cantor proved the square case in 1877 and wrote to Dedekind: ``I see it, but I do not believe it.'' No such bijection can be continuous (Exercise~\ref{ex:notR2}), though a continuous surjection from the interval onto the square does exist (Chapter~\ref{ch:compact}).
\end{solution}

\begin{solution}{ex:hamel}
\idea Zorn's lemma produces the basis. A coordinate function is linear over $\Q$ and not linear over $\R$. Density comes from two vectors in the plane that are independent over $\R$: their combinations with rational coefficients are dense.
\writeup (a) Apply Theorem~\ref{thm:basis} with $K=\Q$ and $V=\R$. (b) Every $x$ is uniquely a finite sum $\sum_{b\in B}c_b(x)\,b$ with rational coefficients $c_b(x)$, and uniqueness gives $c_b(x+y)=c_b(x)+c_b(y)$. So $f=c_{b_0}$ is additive. If $f(x)=cx$ for every $x$, then $c=f(b_0)/b_0=1/b_0\ne0$. The basis $B$ is infinite: $\R$ is uncountable, and a finite-dimensional vector space over $\Q$ is countable (Exercise~\ref{ex:v7c01c}). So some $b_1$ lies in $B\setminus\{b_0\}$, and $f(b_1)=0\ne cb_1$. (c) Let $f$ be additive, hence $\Q$-linear by Exercise~\ref{ex:cauchyfe}, and not of the form $cx$. Then $\frac{f(x)}{x}$ is not constant on $x\ne0$. Pick $x_1$ and $x_2$ with $\frac{f(x_1)}{x_1}\ne\frac{f(x_2)}{x_2}$. The vectors $v_i=(x_i,f(x_i))$ are linearly independent over $\R$, because their determinant $x_1f(x_2)-x_2f(x_1)$ is not zero. The map $(s,t)\mapsto sv_1+tv_2$ is a linear bijection of $\R^2$, continuous, with a continuous inverse, and it carries the dense set $\Q^2$ onto a dense set. But $q_1v_1+q_2v_2=(q_1x_1+q_2x_2,f(q_1x_1+q_2x_2))$ lies on the graph of $f$. The graph is therefore dense. Over any interval $I$ it contains points $(x,f(x))$ with $x\in I$ and with $f(x)$ as large as one likes.
\end{solution}

\begin{solution}{ex:cuts}
\idea A cut is the set of rationals below a real. The union of cuts bounded by one cut is the cut of a supremum, and the supremum of a cut is the real that cut describes.
\writeup (a) Let $(\alpha_i)$ be a non-empty family of cuts, all contained in one cut $\gamma$, and set $\alpha=\bigcup\alpha_i$. Then $\alpha$ is non-empty, $\alpha\subseteq\gamma\ne\Q$, closed downwards because each $\alpha_i$ is, and without a largest element: an element of $\alpha$ lies in some $\alpha_i$, which contains a larger rational. So $\alpha$ is a cut. It contains every $\alpha_i$, and any cut that contains every $\alpha_i$ contains $\alpha$. It is the least upper bound. (b) For $x\in\R$, the set $L(x)=\{q:q<x\}$ is non-empty and not all of $\Q$, by Archimedes. It is closed downwards, and density says it has no largest element. If $x<y$, a rational between them lies in $L(y)\setminus L(x)$, so the map is strictly increasing, hence injective. For surjectivity, take a cut $\alpha$ and a rational $r\notin\alpha$. Every $a\in\alpha$ satisfies $a<r$: otherwise $r\le a$ would put $r$ in $\alpha$. So $\alpha$ is bounded. Let $x=\sup\alpha$. When $q\in\alpha$, the cut $\alpha$ contains some $q'>q$, and then $q<q'\le x$. If $q<x$, then $q$ is not an upper bound of $\alpha$, so $q<a$ for some $a\in\alpha$, and $q\in\alpha$. Thus $\alpha=L(x)$.
\end{solution}

\begin{solution}{ex:krull}
\idea A maximal ideal is a maximal element of a partially ordered set, so Zorn's lemma applies once every chain has an upper bound. The element $1$ is what keeps a union of proper ideals proper.
\writeup Let $P$ be the set of ideals $J\supseteq I$ with $J\ne R$, that is, with $1\notin J$, ordered by inclusion. Then $I\in P$. If $(J_k)$ is a non-empty chain in $P$, the union $J$ is an ideal: any two elements lie in a common $J_k$, so their sum does, and so does any multiple. The union contains $I$ and does not contain $1$, so it is an upper bound in $P$. Zorn's lemma gives a maximal element $M$ of $P$. If $M\subsetneq J\ne R$ for an ideal $J$, then $J\in P$, which contradicts maximality. So $M$ is a maximal ideal of $R$.
\end{solution}

\begin{solution}{ex:functions}
\idea Continuous functions are cheap to specify: the values on $\Q$ decide them. Arbitrary functions are expensive: the indicator of a subset of $\R$ is a function, and there are more subsets than reals.
\writeup Write $\mathfrak c=|\R|=|\mathcal P(\N)|$. Restriction to $\Q$ is injective on $C(\R,\R)$, by density of $\Q$ and continuity. So $|C(\R,\R)|\le|\R^\Q|=|\R^\N|$. Now $|\R^\N|=|\mathcal P(\N)^\N|$, and a sequence $(A_k)$ of subsets of $\N$ is the same datum as the subset $\{(k,a):a\in A_k\}$ of $\N\times\N$. Hence $|\mathcal P(\N)^\N|=|\mathcal P(\N\times\N)|=|\mathcal P(\N)|=\mathfrak c$. Constant functions give $\mathfrak c\le|C(\R,\R)|$, and Schr\"oder--Bernstein finishes the continuous case. For all functions, $A\mapsto\mathbf 1_A$ injects $\mathcal P(\R)$ into $\R^\R$. A function is a subset of $\R\times\R$, so $|\R^\R|\le|\mathcal P(\R\times\R)|=|\mathcal P(\R)|$ by Exercise~\ref{ex:square}. Cantor's theorem gives $|\mathcal P(\R)|>|\R|$.
\end{solution}

\begin{solution}{ex:calkinwilf}
\idea Climbing the tree is Euclid's subtractive algorithm, and it ends at $\frac11$. That one climb gives existence and uniqueness together. For (b), the next node is the sibling of a left child, or the left child of the successor of the parent of a right child. The formula only has to be checked in those two cases.
\writeup (a) Since $\gcd(a,a+b)=\gcd(a+b,b)=\gcd(a,b)$, every node is in lowest terms, by induction from the root $\frac11$. A left child $\frac a{a+b}$ is less than $1$, a right child $\frac{a+b}b$ is greater than $1$, and the root equals $1$. So the value of a node says whether the node is the root, a left child, or a right child, and it says the parent's value: $\frac a{b-a}$ when $a<b$, and $\frac{a-b}b$ when $a>b$. Induct on $a+b$ to show that each fraction $\frac ab$ in lowest terms occurs exactly once. When $a+b=2$ the fraction is $\frac11$, and it occurs only at the root, because every other node is different from $1$. When $a+b>2$ one has $a\ne b$, by lowest terms. The parent is in lowest terms and has a smaller sum of numerator and denominator, so it occurs exactly once, and $\frac ab$ is its left or right child. Two occurrences would share the parent value, hence the parent node, and they would lie on the same side, so they would be the same node.

(b) Let $s(x)=\frac1{2\lfloor x\rfloor+1-x}$. The claim $q_{n+1}=s(q_n)$ is proved by induction on $n\ge1$. For $n=1$, $s(1)=\frac12=q_2$. Take $n\ge2$. If $n=2m$, then $q_n=\frac a{a+b}<1$ is the left child of $q_m=\frac ab$, and $q_{n+1}=\frac{a+b}b$ is its sibling. Indeed $s(q_n)=\frac1{1-q_n}=\frac{a+b}b$. If $n=2m+1$, then $q_n=x+1$ with $x=q_m$, and $q_{n+1}=q_{2(m+1)}$ is the left child of $q_{m+1}$. That left child is $\frac y{y+1}$ for $y=q_{m+1}$: the left child of $\frac cd$ is $\frac c{c+d}=\frac{c/d}{c/d+1}$. The inductive hypothesis applies to $m+1\le n$, so $y=s(x)=\frac1{2k+1-x}$ with $k=\lfloor x\rfloor$, and $q_{n+1}=\frac1{1+1/y}=\frac1{2k+2-x}$. On the other side, $s(q_n)=\frac1{2(k+1)+1-(x+1)}=\frac1{2k+2-x}$. Both cases give $q_{n+1}=s(q_n)$.
\end{solution}

\begin{solution}{ex:cwcompute}
\idea Newman's formula asks only for the integer part of the term you already have. For (b), the path from the root, read as a string of left and right steps, is the index in binary.
\writeup (a) The integer part of $q_1$ is $1$, so the formula returns $q_2=\frac1{2\cdot1+1-1}=\frac12$. Then $\lfloor q_2\rfloor=0$ and $q_3=\frac1{0+1-\frac12}=2$. The same step continues:
\[q_4=\tfrac1{4+1-2}=\tfrac13,\quad q_5=\tfrac1{1-\frac13}=\tfrac32,\quad q_6=\tfrac1{2+1-\frac32}=\tfrac23,\quad q_7=\tfrac1{1-\frac23}=3,\]
\[q_8=\tfrac1{6+1-3}=\tfrac14,\quad q_9=\tfrac1{1-\frac14}=\tfrac43,\quad q_{10}=\tfrac1{2+1-\frac43}=\tfrac35.\]
These are the first ten nodes of Figure~\ref{fig:calkinwilf}, read left to right. A tree of four complete levels has fifteen nodes.

(b) Climb from $\frac{13}5$. A value above $1$ is a right child, with parent $\frac{a-b}b$. A value below $1$ is a left child, with parent $\frac a{b-a}$. So
\[\tfrac{13}5\ \xrightarrow{R}\ \tfrac85\ \xrightarrow{R}\ \tfrac35\ \xrightarrow{L}\ \tfrac32\ \xrightarrow{R}\ \tfrac12\ \xrightarrow{L}\ \tfrac11.\]
Read downwards from the root: $L,R,L,R,R$. The root has index $1$. A left step sends $m$ to $2m$, and a right step sends $m$ to $2m+1$: $1\to2\to5\to10\to21\to43$. Thus $q_{43}=\frac{13}5$. In binary, $43=101011$. After the leading $1$, a digit $0$ is a left step and a digit $1$ is a right step. The upward steps $R,R,L,R,L$ are the subtractions in Euclid's algorithm for $13$ and $5$.
\end{solution}

\begin{solution}{ex:v7c01a}
\idea Binary place value turns a finite set of natural numbers into a single natural number, and different sets land on different numbers. The rule is explicit, so no choice is used.
\writeup If $A=\{a_1<\cdots<a_k\}$ is a finite subset of $\N$, set $\nu(A)=2^{a_1}+\cdots+2^{a_k}$, and set $\nu(\varnothing)=0$. Binary expansion says $\nu$ is injective: the powers of $2$ in the sum are exactly the elements of $A$. The image lies in $\N$, so the set of finite subsets injects into $\N$ and is countable.
\end{solution}

\begin{solution}{ex:v7c01b}
\idea The left endpoints are an increasing sequence, bounded above by $b_0$. Their supremum is the only point that can sit in every interval, and the shrinking lengths leave room for only one.
\writeup Let $s=\sup\{a_n:n\in\N\}$, which exists by Theorem~\ref{thm:reals}. Then $a_n\le s$ for every $n$. Also $s\le b_n$ for every $n$: the number $b_n$ is an upper bound of the whole set $\{a_m\}$, because $a_m\le a_n\le b_n$ when $m\le n$, and $a_m\le b_m\le b_n$ when $m\ge n$. So $s\in[a_n,b_n]$ for every $n$. If $t$ is another such point and $t\ne s$, then $|t-s|>0$. For large $n$ one has $b_n-a_n<|t-s|$, so $[a_n,b_n]$ cannot contain both. The point is unique.
\end{solution}

\begin{solution}{ex:v7c01c}
\idea A finite list of real coordinates with rational coefficients is a countable amount of data. An uncountable space cannot be spanned by finitely many vectors over $\Q$.
\writeup Let $V\subset\R$ have a basis $v_1,\ldots,v_d$ over $\Q$. Every element of $V$ is $q_1v_1+\cdots+q_dv_d$ for a unique $(q_1,\ldots,q_d)\in\Q^d$. Proposition~\ref{prop:countable} says $\Q$ is countable, and a finite product of countable sets is countable by induction from part (b) of that proposition. So $V$ is countable. The field $\R$ is uncountable by Theorem~\ref{thm:continuum}, so it is not equal to any such $V$.
\end{solution}

\begin{solution}{ex:v7c01d}
\idea If the positive integers were bounded, their least upper bound would be exceeded by adding $1$. Once the integers are unbounded, a gap $y-x$ can be scaled until it contains an integer, and the least such integer is a rational between $x$ and $y$.
\writeup Suppose some $x\in F$ satisfies $n\cdot1\le x$ for every $n\in\N$. The set $\N\cdot1$ is non-empty and bounded above, so it has a supremum $s$. Then $s-1$ is not an upper bound, so $s-1<n$ for some $n$, and $n+1>s$, a contradiction. Thus $F$ is Archimedean. Now take $x<y$. Choose an integer $n>\frac1{y-x}$, which exists because $\frac1{y-x}$ is some element of $F$ and the integers are unbounded. Choose $N\in\N$ with $N+nx>0$, again by Archimedes, and let $m_0$ be the least natural number strictly above $N+nx$ (Proposition~\ref{prop:wellorder}, carried into $F$ along the copy of $\N$). Then $m_0\ge1$. Set $m=m_0-N$. The inequalities $m>nx$ and $m-1\le nx$ give $nx<m\le nx+1<ny$, so $x<\frac mn<y$.
\end{solution}
