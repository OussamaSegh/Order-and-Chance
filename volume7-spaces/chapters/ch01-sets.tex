\chapter{Sets, Choice and the Real Numbers}\label{ch:sets}

\begin{center}\itshape
How many integers are there, and how many fractions? How many points lie on a line, and how many lie in a square?
Before any of those counts: what is a point on the line?
\end{center}

Order is the part this chapter can settle. Which numbers come first, which sets can be listed, and which descriptions of the line are really the same line. Chance will use that line later, once a length has been defined.

On 24 November 1858, Richard Dedekind was teaching differential calculus at the Zurich Polytechnic for the first time. He had told the class that an increasing sequence with an upper bound must converge. The students believed the statement. He did not. Every argument he knew leaned on a drawing of the line, and a drawing does not finish a proof. He saw the missing piece that day. He published it fourteen years later, in the booklet \emph{Continuity and Irrational Numbers} (1872).

\portrait{dedekind}{Richard Dedekind (1831--1916). Photograph, about 1870. Public domain, via Wikimedia Commons.}

A second story starts in the same correspondence. In November 1873, Georg Cantor asked Dedekind whether the natural numbers can be paired, one for one, with the real numbers. The question is easy to ask. Dedekind answered that he did not know. He did know that the algebraic numbers can be listed. A week later Cantor had the answer, and the answer was no. There are more real numbers than integers. An infinite set can be strictly larger than another infinite set. Three years after that, he showed that a square has no more points than one of its sides. He wrote to Dedekind, in French, ``je le vois, mais je ne le crois pas''. He could see the pairing, and he still could not believe it. The letter is dated 29 June 1877.

\portrait{cantor}{Georg Cantor (1845--1918). Photograph, early twentieth century, author unknown. Public domain, via Wikimedia Commons.}

Both stories are built here, out of sets and nothing else. The natural numbers come first, as the smallest inductive set, with addition and multiplication fixed by recursion. Differences of natural numbers give the integers, and fractions of integers give the rationals. A real number is then a class of rational sequences that crowd together. Volume~1 took as an axiom that every nonempty set of reals bounded above has a least upper bound. That statement becomes a theorem. A second theorem says there is only one ordered field with this property, so a later argument never has to ask which construction of $\R$ was used. Counting comes next. Cantor's diagonal shows that the power set of any set $A$ is strictly larger than $A$. The same shape of argument is Russell's paradox, which is proved below, and it is the shape behind G\"odel's incompleteness theorem and Turing's halting problem, which are named here and not proved. The chapter ends with the axiom of choice. The axiom is short to state. It is the reason every vector space has a basis, and the reason some subsets of the line have no sensible length.

\section{Sets}

Sets are used in the ordinary way. The rules still matter, because a rule that is too generous contradicts itself.

\begin{think}
Suppose $V$ were a set whose elements were all sets. Form $R=\{x\in V:x\notin x\}$. Is $R$ an element of $R$?
\end{think}

Assume $R\in R$. Then $R$ meets the condition that defines $R$, so $R\notin R$. Assume instead $R\notin R$. Then $R$ meets that same condition, so $R\in R$. Either reading contradicts the other. This is Russell's paradox, found in 1901 and sent to Frege in a letter of 16 June 1902. The rule ``for every property there is the set of all things having it'' cannot stand. Zermelo's repair, in 1908, builds new sets only out of sets already in hand. From a set you already have, you may keep the elements with a given property. You may not first gather ``all things'' and only afterwards impose the property. The argument above then says something sharper: there is no set of all sets.

\paragraph{The Zermelo--Fraenkel rules.}
Every object is a set. Two sets are the same set when they have the same elements. This is extensionality. The following sets are granted. There is an empty set $\varnothing$. Any two sets $a$ and $b$ have a pair $\{a,b\}$. Any set $A$ has a union $\bigcup A$, whose elements are the elements of the elements of $A$. Any set $A$ has a power set $\mathcal P(A)$, whose elements are the subsets of $A$. Given a set $A$ and a property $P$, separation supplies $\{x\in A:P(x)\}$. Given a set $A$ and a rule $F$ that assigns a set $F(x)$ to each $x\in A$, replacement supplies the image $\{F(x):x\in A\}$. Infinity supplies a set that contains $\varnothing$ and is stable under $x\mapsto x\cup\{x\}$. Foundation says that every nonempty set $A$ has an element disjoint from $A$, and in particular it rules out $x\in x$. These rules are called ZF. The axiom of choice, AC, is the extra rule in Section~\ref{sec:choice}. ZFC means ZF together with choice. Ordinary mathematics works in ZFC. It is the one package this volume does not derive.

\paragraph{Pairs, products and functions.}
Kuratowski's ordered pair is $(a,b)=\{\{a\},\{a,b\}\}$. Check it on a small case. The pair $(1,2)$ is $\{\{1\},\{1,2\}\}$. The only singleton member is $\{1\}$, so the first coordinate is $1$. The other member is $\{1,2\}$, so the second coordinate is $2$. In general the only property we need is this: $(a,b)=(c,d)$ forces $a=c$ and $b=d$. If $a=b$, the pair is $\{\{a\}\}$, so $\{c\}=\{c,d\}=\{a\}$ and $c=d=a$. The case $c=d$ is the same with the names swapped. If neither equality holds, then $\{a\}$ is the only singleton in the left pair and $\{c\}$ is the only singleton in the right pair, so $a=c$. The remaining members satisfy $\{a,b\}=\{a,d\}$. Since $b\ne a$, this forces $b=d$. The product $A\times B$ is the set of all such pairs. It sits inside $\mathcal P(\mathcal P(A\cup B))$, so separation provides it. A function $f:A\to B$ is a subset of $A\times B$ that contains exactly one pair $(a,b)$ for each $a\in A$. The set of all functions from $A$ to $B$ is written $B^A$. An equivalence relation $\sim$ on $A$ has classes $[a]=\{x\in A:x\sim a\}$. The classes partition $A$. The quotient $A/{\sim}$ is the set of those classes. The integers, the rationals and the reals below are all quotients.

\section{The natural numbers}\label{sec:naturals}

Von Neumann's natural numbers are earlier numbers, gathered into a set. Set $0=\varnothing$, $1=\{0\}$, $2=\{0,1\}$, and in general $S(n)=n\cup\{n\}$. The set $S(n)$ is the successor of $n$.

\begin{definition}
A set $I$ is inductive when $\varnothing\in I$ and $x\cup\{x\}\in I$ whenever $x\in I$. Infinity gives at least one inductive set $I_0$. The natural numbers are the common part of every inductive set:
\[
\N=\{x\in I_0:x\text{ belongs to every inductive set}\}.
\]
\end{definition}

The set $\N$ is itself inductive, and no inductive set is smaller. That is induction in its bare form. An inductive subset of $\N$ equals $\N$. Equivalently, a property that holds for $0$, and that holds for $S(n)$ whenever it holds for $n$, holds for every natural number.

\begin{theorem}[Peano's axioms]\label{thm:peano}
No successor equals $0$. The successor map is injective on $\N$. Induction holds, in the form just stated.
\end{theorem}
\begin{proof}
The set $S(n)=n\cup\{n\}$ contains $n$. The empty set $0$ contains nothing. So $S(n)\ne 0$.

Two further facts are proved by noticing that the numbers which satisfy them form an inductive set. Call a set $x$ transitive when $y\in x$ implies $y\subseteq x$. The empty set is transitive, because it has no element that could fail. If $n$ is transitive and $y\in S(n)$, then either $y\in n$, hence $y\subseteq n\subseteq S(n)$, or else $y=n$, hence $y\subseteq S(n)$. So $S(n)$ is transitive. Every natural number is therefore transitive.

No natural number belongs to itself. The empty set does not belong to itself. Suppose $n\notin n$, but $S(n)\in S(n)$. Membership in $S(n)$ means $S(n)=n$ or $S(n)\in n$. The first alternative gives $n\in n$. The second, together with transitivity of $n$, gives $n\in S(n)\subseteq n$, so again $n\in n$. Both alternatives contradict $n\notin n$. Hence $S(n)\notin S(n)$, and $n\notin n$ for every $n\in\N$.

Now suppose $S(m)=S(n)$ with $m\ne n$. Then $m\in S(n)$, and $m\ne n$ forces $m\in n$. The same reading with the names exchanged gives $n\in m$. Transitivity of $n$ turns $m\in n$ into $m\subseteq n$. Combined with $n\in m$, this yields $n\in n$, which has just been ruled out.
\end{proof}

For a first check, $S(0)=\{0\}=1$ and $S(1)=\{0,1\}=2$. Neither equals $0$, and they are not equal to each other.

Induction proves statements. Recursion builds sequences. The instruction ``put $f(0)=a$, and put $f(n+1)=g(f(n))$'' names a function only after the next theorem.

\begin{theorem}[recursion]\label{thm:recursion}
Let $A$ be a set, let $a\in A$, and let $g:A\to A$. There is exactly one function $f:\N\to A$ such that $f(0)=a$ and $f(S(n))=g(f(n))$ for every $n$.
\end{theorem}
\begin{proof}
Call a subset $h\subseteq\N\times A$ admissible when $(0,a)\in h$ and $(n,y)\in h$ implies $(S(n),g(y))\in h$. The whole product $\N\times A$ is admissible. Let $f$ be the intersection of every admissible set. Then $f$ is admissible, and it is the smallest one.

Let $D$ be the set of $n\in\N$ for which there is exactly one $y$ with $(n,y)\in f$. Once $D$ is all of $\N$, the set $f$ is a function $\N\to A$, and the two required equations are the admissibility of $f$.

The number $0$ lies in $D$. Indeed, $(0,a)\in f$. If some $(0,b)$ also lay in $f$ with $b\ne a$, the smaller set $f\setminus\{(0,b)\}$ would still be admissible, because $0$ is not a successor. That would contradict the minimality of $f$.

Suppose $n\in D$, and let $y$ be the unique second coordinate with $(n,y)\in f$. Admissibility puts $(S(n),g(y))$ into $f$. If $(S(n),z)$ were also in $f$ for some $z\ne g(y)$, delete that pair and call the result $f'$. The pair $(0,a)$ survives, because $S(n)\ne 0$ by Theorem~\ref{thm:peano}. If $(m,w)\in f'$, admissibility of $f$ puts $(S(m),g(w))$ into $f$. That pair is not $(S(n),z)$: if $S(m)=S(n)$, injectivity of $S$ forces $m=n$, then $w=y$ because $n\in D$, and then $g(w)=g(y)\ne z$. So $f'$ is admissible, against minimality. Hence $S(n)\in D$.

Induction gives $D=\N$. If $f_1$ and $f_2$ both satisfy the two equations, the set of $n$ with $f_1(n)=f_2(n)$ contains $0$ and is closed under $S$, so it is $\N$.
\end{proof}

Addition is recursion in the second variable. Fix $m$, set $m+0=m$, and set $m+S(n)=S(m+n)$. Multiplication is the recursion $m\cdot 0=0$ and $m\cdot S(n)=m\cdot n+m$. With the abbreviation $1=S(0)$, the successor is addition of one: $S(n)=n+1$.

\begin{proposition}\label{prop:semiring}
On $\N$, addition and multiplication are associative and commutative, and multiplication distributes over addition. If $m+p=n+p$, then $m=n$. If $m+n=0$, then $m=n=0$.
\end{proposition}
\begin{proof}
Each claim is an induction on one variable, using only the recursive clauses.

(a) The sum $0+n$ equals $n$. It holds for $n=0$, and $0+S(n)=S(0+n)=S(n)$.

(b) The sum $S(m)+n$ equals $S(m+n)$. It holds for $n=0$. The inductive step is
\[
S(m)+S(n)=S(S(m)+n)=S(S(m+n))=S(m+S(n)).
\]

(c) Addition commutes. Fix $m$ and induct on $n$. The start is $m+0=m=0+m$, by (a). Then $m+S(n)=S(m+n)=S(n+m)=S(n)+m$, where the last step is (b).

(d) Addition associates. Induct on $p$: $(m+n)+0=m+n$, and
\[
(m+n)+S(p)=S((m+n)+p)=S(m+(n+p))=m+(n+S(p)).
\]

(e) Addition cancels. Induct on $p$. The case $p=0$ is immediate. If $m+S(p)=n+S(p)$, the definition of addition gives $S(m+p)=S(n+p)$, so $m+p=n+p$ by Theorem~\ref{thm:peano}, and the inductive hypothesis gives $m=n$.

(f) A sum is $0$ only when both terms are $0$. The set $\{0\}\cup S(\N)$ is inductive, so every nonzero natural number is some successor $S(k)$. If $n=S(k)$, then $m+n=S(m+k)\ne 0$. Thus $m+n=0$ forces $n=0$, and then $m+0=m=0$.
% MATHFIX: the original argument stopped once a nonzero summand was shown to make the sum a successor; the zero summand is then the sum itself.

(g) Multiplication distributes: $m(n+p)=mn+mp$. Induct on $p$. The step uses $m(n+S(p))=m\,S(n+p)=m(n+p)+m$, and the inductive hypothesis replaces $m(n+p)$ by $mn+mp$, which is $mn+m\,S(p)$.

(h) One has $0\cdot n=0$, and $S(m)\,n=mn+n$. Both are inductions on $n$. The second starts from $S(m)\cdot 0=0$. For the step, the definition and the inductive hypothesis give
\[
S(m)\,S(n)=S(m)\,n+S(m)=(mn+n)+(m+1),
\]
while $m\,S(n)+S(n)=(mn+m)+(n+1)$. The two right-hand sides agree by the addition rules already proved.

(i) Multiplication commutes. Induct on $n$. The start is $m\cdot 0=0=0\cdot m$. Then $m\,S(n)=mn+m=nm+m=S(n)\,m$, by (h).

(j) Multiplication associates. Induct on $p$. Using (g) at the last step,
\[
(mn)\,S(p)=(mn)p+mn=m(np)+mn=m(np+n)=m(n\,S(p)).
\]
\end{proof}

Declare $m\le n$ when $n=m+k$ for some $k\in\N$, and declare $m<n$ when that $k$ is not $0$.

\begin{proposition}\label{prop:wellorder}
The relation $\le$ is a total order on $\N$. It is compatible with addition, and with multiplication by any fixed $p$. Every nonempty subset of $\N$ has a least element.
\end{proposition}
\begin{proof}
The relation is reflexive because $n=n+0$. It is transitive because $(m+k)+k'=m+(k+k')$. It is antisymmetric: $n=m+k$ and $m=n+k'$ give $m=m+(k+k')$, so cancellation forces $k+k'=0$, and (f) of Proposition~\ref{prop:semiring} forces $k=k'=0$.

The order is total. Fix $m$, and induct on $n$. If $n=0$, then $0\le m$. Assume $m$ and $n$ are comparable. If $m<n$ or $m=n$, then $m<n+1$. If $n<m$, write $m=n+S(j)=(n+1)+j$, so $n+1\le m$.

Compatibility is the same rewriting. If $n=m+k$, then $n+p=(m+p)+k$ and $np=mp+kp$.

It remains to find least elements. Let $A\subseteq\N$ have none. Induct on $n$ to show that no $k\le n$ lies in $A$. For $n=0$, the only candidate is $k=0$, and a member $0\in A$ would be least. Suppose no $k\le n$ lies in $A$. If $n+1$ were in $A$, it would be the least member: any smaller $k$ satisfies $k\le n$, because $n+1=k+S(j)$ rearranges to $n=k+j$. So $n+1\notin A$, and no $k\le n+1$ lies in $A$. Therefore $A$ is empty.
\end{proof}

The least element of $\{3,5,8\}$ is $3$, and the least element of the nonempty set of successors is $1$. The empty set is the one subset with nothing to be least.

\section{Integers and rationals}

Subtraction on $\N$ stops at $0$. There is no natural number $n$ with $1+n=0$. The integers are formal differences, forced into existence so that subtraction always has an answer.

\begin{proposition}\label{prop:integers}
On $\N\times\N$, declare $(a,b)\sim(c,d)$ when $a+d=b+c$. This is an equivalence relation. The quotient $\Z=(\N\times\N)/{\sim}$, with the operations
\[
\begin{gathered}[(a,b)]+[(c,d)]=[(a+c,b+d)],\qq{}[(a,b)]\cdot[(c,d)]=[(ac+bd,ad+bc)]\end{gathered}
\]
is a commutative ring with no zero divisors. The map $n\mapsto[(n,0)]$ embeds $\N$ into $\Z$, and every integer equals $n$ or $-n=[(0,n)]$ for some $n\in\N$. Taking the positive elements to be $\{[(a,b)]:b<a\}$, the ring $\Z$ is an ordered ring.
\end{proposition}
\begin{proof}
The relation is reflexive and symmetric because addition on $\N$ is. For transitivity, $a+d=b+c$ and $c+f=d+e$ add to $a+d+c+f=b+c+d+e$, and cancellation of $c+d$ leaves $a+f=b+e$.

The operations do not depend on the chosen pairs. For the sum this is immediate from the clauses. For the product, replace $(a,b)$ by $(a',b')$ with $a+b'=a'+b$. Then
\[
\begin{aligned}(ac+bd)+(a'd+b'c)&=c(a+b')+d(a'+b)\\&=c(a'+b)+d(a+b')\\&=(a'c+b'd)+(ad+bc),\end{aligned}
\]
so $[(ac+bd,ad+bc)]=[(a'c+b'd,a'd+b'c)]$. The second factor of a product is handled by the same calculation with the names exchanged.

Each ring identity is now an identity already proved in $\N$, by Proposition~\ref{prop:semiring}. The zero element is $[(0,0)]$. The opposite of $[(a,b)]$ is $[(b,a)]$. By totality of the order on $\N$, either $a=b+n$ or $b=a+n$, so $[(a,b)]$ equals $[(n,0)]$ or $[(0,n)]$. The natural number in that normal form is the only one that works. If $[(n,0)]=[(m,0)]$, then $n=m$. If $[(n,0)]=[(0,m)]$, then $n+m=0$, so $n=m=0$.

If $x$ and $y$ are positive, write $x=[(m,0)]$ and $y=[(n,0)]$ with $m,n\ne 0$. Then $x+y=[(m+n,0)]$ is positive, and $xy=[(mn,0)]$ is positive because $mn\ne 0$. The last claim uses (h) and (f) of Proposition~\ref{prop:semiring}: a nonzero factor is a successor $S(k)$, and $S(k)n=kn+n$, which is $0$ only if $n=0$. Every nonzero integer is positive or has positive opposite. A product of nonzero integers is therefore, up to sign, a positive integer, hence not zero.
\end{proof}

The rational numbers are the field of fractions of $\Z$, built by the same pattern as the field of fractions of a domain in Volume~3, Chapter~6. Explicitly,
\[
\Q=\{(a,b)\in\Z\times\Z:b\ne 0\}/{\sim},\qquad (a,b)\sim(c,d)\iff ad=bc,
\]
with the usual sum and product of fractions $a/b$. The checks are identities of the same kind as those for $\Z$, and the outcome is a field containing $\Z$.

Order the field by declaring $a/b>0$ when $ab>0$. The sign does not depend on the representative. If $a/b=c/d$, then $ab\,d^2=cd\,b^2$. The squares $b^2$ and $d^2$ are positive, so $ab$ and $cd$ are positive together. Positive rationals are closed under addition and multiplication, and $\Q$ is an ordered field in the sense of the next definition. It is Archimedean. If $a/b>0$ with $a,b>0$, the natural number $n=a+1$ satisfies $n>a/b$, because
\[
nb-a=(a+1)b-a=a(b-1)+b\ge b\ge 1>0.
\]

\begin{definition}
An ordered field is a field $F$ together with a subset $F_{>0}$ that is closed under addition and multiplication, such that every $x\in F$ lies in exactly one of the three sets $F_{>0}$, $\{0\}$ and $-F_{>0}$. Write $x<y$ to mean $y-x\in F_{>0}$. The field is Archimedean when, for every $x\in F$, some $n\in\N$ satisfies $x<n\cdot 1$. It has the least-upper-bound property when every nonempty subset that is bounded above has a least upper bound.
\end{definition}

In any ordered field, $1=1^2>0$, so $n\cdot 1>0$ for every $n\ge 1$. The copy of $\Z$ inside $F$ is therefore faithful, and $F$ contains a copy of $\Q$. The inequality rules from Volume~1 hold in every ordered field, by the same proofs. What $\Q$ does not have is the least-upper-bound property. The set $\{q\in\Q:q^2<2\}$ has no least upper bound in $\Q$, which is Exercise~\ref{ex:sqrt2}.

\section{The real numbers}\label{sec:reals}

A sequence of rationals can crowd together and still have nowhere to land. The truncations $1$, $1.4$, $1.41$, $1.414$, and so on, huddle as if a limit were waiting. Inside $\Q$, nothing is waiting: no rational squares to $2$.

Dedekind's repair was to name the missing number by the split it makes. One piece holds the rationals below the gap, and the other holds the rationals above it. Figure~\ref{fig:rw-cut} is that split for a square root of $2$.

\begin{figure}[ht]
\centering
\fig{ch01-rw-cut}
\caption{A Dedekind cut at the missing square root of $2$. Charcoal marks rationals whose square is less than $2$, and coral marks rationals whose square is greater than $2$. Every charcoal point is smaller than every coral point, and the charcoal piece has no largest element. The real is the split itself.}
\label{fig:rw-cut}
\end{figure}

Cantor's repair, which is the one carried out here, does not describe the two pieces. It takes the crowding sequence itself to be the missing limit, up to sequences that crowd in the same way.

Cantor (1872) and M\'eray (1869) defined a real number to be whatever a Cauchy sequence of rationals ``converges to'', after identifying sequences whose difference tends to $0$. Throughout this section, $\varepsilon$ and $\delta$ are positive rationals. A sequence is a sequence of rationals, unless the text says otherwise.

\begin{definition}
A sequence $(x_n)$ in $\Q$ is Cauchy when, for every $\varepsilon$, some $N$ has $|x_n-x_m|<\varepsilon$ for all $n,m\ge N$. It is null when, for every $\varepsilon$, some $N$ has $|x_n|<\varepsilon$ for all $n\ge N$. Let $\mathcal C$ be the set of Cauchy sequences and $\mathcal N$ the set of null sequences. Set $\R=\mathcal C/{\sim}$, where $x\sim y$ means $x-y\in\mathcal N$. The class of a sequence $x$ is written $[x]$.
\end{definition}

\begin{lemma}\label{lem:cauchybasic}
\begin{enumerate}[label=(\alph*)]
\item Every Cauchy sequence is bounded.
\item Termwise addition and multiplication make $\mathcal C$ a commutative ring, and $\mathcal N$ is an ideal of that ring.
\item If $x\in\mathcal C\setminus\mathcal N$, some $\delta$ and some $N$ have either $x_n\ge\delta$ for every $n\ge N$, or $x_n\le-\delta$ for every $n\ge N$.
\end{enumerate}
\end{lemma}
\begin{proof}
(a) Take $\varepsilon=1$. Then $|x_n|\le |x_N|+1$ for every $n\ge N$, and only finitely many terms come earlier. The largest of those finitely many absolute values, and $|x_N|+1$, bound the whole sequence.

(b) The sum of Cauchy sequences is Cauchy, because the tolerances add. For products, take a bound $|x_n|,|y_n|\le M$. Then
\[
|x_ny_n-x_my_m|\le M|y_n-y_m|+M|x_n-x_m|.
\]
The same estimate, with $y$ null and $x$ merely bounded, shows that a bounded sequence times a null sequence is null. Thus $\mathcal N$ is an ideal.

(c) Since $x$ is not null, some $\varepsilon>0$ has $|x_n|\ge\varepsilon$ for infinitely many $n$. Set $\delta=\varepsilon/2$, and choose $N$ so that $|x_n-x_m|<\delta$ whenever $n,m\ge N$. Pick one $m\ge N$ with $|x_m|\ge\varepsilon$. If $x_m\ge\varepsilon$, then $x_n>x_m-\delta\ge\delta$ for every $n\ge N$. If $x_m\le-\varepsilon$, the same subtraction gives $x_n\le-\delta$.
\end{proof}

The quotient $\R=\mathcal C/\mathcal N$ is therefore a commutative ring. A rational $q$ sits inside it as the class $\iota(q)$ of the constant sequence with value $q$. Call a class $[x]$ positive when the first alternative in (c) holds. The label does not depend on the representative. If $z$ is null and $|z_n|<\delta/2$ for large $n$, then $x_n+z_n\ge\delta/2$ whenever $x_n\ge\delta$.

\begin{theorem}\label{thm:reals}
The ring $\R$ is an Archimedean ordered field. The map $\iota:\Q\to\R$ is an injective morphism of ordered fields, and $\Q$ is dense in $\R$: if $a<b$ are real, some rational $q$ has $a<\iota(q)<b$. Every Cauchy sequence in $\R$ converges to a point of $\R$, and $\R$ has the least-upper-bound property.
\end{theorem}
\begin{proof}
\emph{Inverses.} Suppose $[x]\ne 0$. Lemma~\ref{lem:cauchybasic}(c) gives $|x_n|\ge\delta$ for $n\ge N$. Define $y_n=1/x_n$ for $n\ge N$, and $y_n=1$ before that index. For $n,m\ge N$,
\[
|y_n-y_m|=\frac{|x_m-x_n|}{|x_nx_m|}\le\frac{|x_m-x_n|}{\delta^2},
\]
so $y$ is Cauchy. Also $x_ny_n-1=0$ for $n\ge N$, hence $[x][y]=1$. The constant sequence $1$ is not null, so $1\ne 0$ in $\R$.

\emph{Order.} Lemma~\ref{lem:cauchybasic}(c) puts every nonzero class on exactly one side of $0$. It cannot be both positive and negative, because $x_n\ge\delta$ and $x_n\le-\delta'$ cannot hold together for all large $n$. A sum of positive classes is positive, since $x_n+y_n\ge\delta+\delta'$. A product of positive classes is positive, since $x_ny_n\ge\delta\delta'$. The map $\iota$ preserves sums and products. It is injective because a nonzero constant sequence is not null, and $q>0$ if and only if $\iota(q)>0$.

\emph{Archimedes.} Lemma~\ref{lem:cauchybasic}(a) bounds $|x_n|$ by some natural number $M$. Then $M+1-x_n\ge 1$, so $[x]<\iota(M+1)$. Some natural number $n$ exceeds $M+1$, and $[x]<n\cdot 1$.

\emph{Density.} Let $a=[x]<b=[y]$. Some $\delta$ and some $N_0$ have $y_n-x_n\ge\delta$ for $n\ge N_0$. Choose $N\ge N_0$ with $|x_n-x_m|$ and $|y_n-y_m|$ both smaller than $\delta/4$ for $n,m\ge N$. Set $q=(x_N+y_N)/2$. For $n\ge N$,
\[
q-x_n\ge q-x_N-\frac{\delta}{4}=\frac{y_N-x_N}{2}-\frac{\delta}{4}\ge\frac{\delta}{4},
\]
so $\iota(q)>a$. The symmetric estimate gives $\iota(q)<b$.

\emph{Rational terms approach their class.} Let $x\in\mathcal C$, and let $\varepsilon>0$ be rational. Choose $N$ with $|x_n-x_m|\le\varepsilon/2$ for $n,m\ge N$. For this fixed $n\ge N$ and for every $m\ge N$, the rational $\varepsilon/2-|x_m-x_n|$ is at least $0$. Passing to classes, $|[x]-\iota(x_n)|\le\iota(\varepsilon/2)<\iota(\varepsilon)$. Every positive real is larger than $\iota(\varepsilon)$ for some positive rational $\varepsilon$, by the density just proved. Therefore $\iota(x_n)\to[x]$ in $\R$.

\emph{Cauchy sequences of reals converge.} Let $(a_k)$ be Cauchy in $\R$. Density supplies rationals $q_k$ with $|a_k-\iota(q_k)|<\iota\bigl(1/(k+1)\bigr)$. The triangle inequality
\[
|q_k-q_l|\le|q_k-a_k|+|a_k-a_l|+|a_l-q_l|
\]
shows that $(q_k)$ is Cauchy in $\Q$. An inequality between rationals holds exactly when the same inequality holds after $\iota$. Let $a=[(q_k)]$. The previous paragraph gives $|a-\iota(q_k)|\to 0$, so
\[
|a-a_k|\le|a-\iota(q_k)|+\frac{1}{k+1}\to 0.
\]

\emph{Least upper bounds.} Let $A\subseteq\R$ be nonempty and bounded above by $u_0$, and choose $l_0$ strictly below some element of $A$. Bisect the interval. At stage $k$, let $m=(l_k+u_k)/2$. If $m$ is an upper bound of $A$, set $(l_{k+1},u_{k+1})=(l_k,m)$. If it is not, set $(l_{k+1},u_{k+1})=(m,u_k)$. Then each $u_k$ bounds $A$ above, each $l_k$ does not, and
\[
u_k-l_k=2^{-k}(u_0-l_0).
\]
Archimedes makes the right-hand side tend to $0$. The lower sequence is increasing, the upper sequence is decreasing, and $l_k\le l_j\le u_j\le u_k$ whenever $j\ge k$. Both sequences are therefore Cauchy, and they share a limit $s$.

Every $a\in A$ satisfies $a\le u_k$ for every $k$, so $a\le s$. If some $a$ exceeded $s$, then $u_k<a$ for large $k$, and $u_k$ would not be an upper bound. If $v<s$, then $v<l_k$ for some $k$. Since $l_k$ is not an upper bound, some $a\in A$ exceeds $l_k$, hence exceeds $v$. So $v$ is not an upper bound, and $s=\sup A$.
\end{proof}

From here on, a rational $q$ is identified with $\iota(q)$. The least-upper-bound axiom of Volume~1 is now a theorem. It is the property the rest of the series uses. The next theorem says that the property pins the field down.

\begin{theorem}[uniqueness of $\R$]\label{thm:uniqueR}
Let $F$ be an ordered field with the least-upper-bound property. There is exactly one field isomorphism $\varphi:\R\to F$, and it preserves order.
\end{theorem}
\begin{proof}
The field $F$ is Archimedean. If the set $\N\cdot 1$ were bounded above, it would have a supremum $s$. Then $s-1$ would not be an upper bound, so $s-1<n$ for some $n\in\N$, and $n+1>s$, which is impossible.

The copy of $\Q$ is dense in $F$. Let $x<y$ in $F$, and choose a natural number $n>1/(y-x)$. Archimedes supplies $N\in\N$ with $N+nx>0$. Let $m_0$ be the least natural number strictly larger than $N+nx$, which exists by Proposition~\ref{prop:wellorder}. Then $m_0\ge 1$. The integer $m=m_0-N$ satisfies $m>nx$. Also $m_0-1\le N+nx$, so $m-1\le nx$ and $m\le nx+1$. The choice of $n$ gives $nx+1<ny$. Combining these,
\[
nx<m\le nx+1<ny,
\]
and dividing by the positive element $n$ yields $x<m/n<y$. The same argument, read inside $\R$, shows that $\Q$ is dense in $\R$. That density was already proved directly in Theorem~\ref{thm:reals}; the point here is that any ordered field with least upper bounds has it.

For $x\in\R$, let $L(x)=\{q\in\Q:q<x\}$ and set $\varphi(x)=\sup_F L(x)$. The set $L(x)$ is nonempty and bounded above in $F$, for instance by any rational at least $x$, so the supremum exists. If $x$ itself is rational, density in $F$ forces $\varphi(x)=x$. If $x<y$, density supplies rationals $x<q<q'<y$, and then $\varphi(x)\le q<q'\le\varphi(y)$. So $\varphi$ is strictly increasing.

The cut is recovered from the image: $\{q\in\Q:q<\varphi(x)\}=L(x)$. A rational $q<x$ has a rational $q'$ with $q<q'<x$, so $q<q'\le\varphi(x)$. A rational $q\ge x$ is an upper bound of $L(x)$, so $\varphi(x)\le q$. The map is onto. For $y\in F$, set $x=\sup_\R\{q\in\Q:q<y\}$. The same comparison shows $L(x)=\{q\in\Q:q<y\}$, and density in $F$ gives $\varphi(x)=\sup_F L(x)=y$.

Sums are respected. First, $L(x+y)=L(x)+L(y)$. If $q<x+y$, density supplies a rational $r$ with $q-y<r<x$, and then $q=r+(q-r)$ with $q-r<y$. The opposite inclusion is the sum of the two strict inequalities. In any ordered field, the supremum of a sumset is the sum of the suprema. Indeed $a+b\le\sup A+\sup B$ whenever $a\in A$ and $b\in B$. In the other direction, for every $\eta>0$ some $a$ and $b$ satisfy $\sup A-\eta<a$ and $\sup B-\eta<b$, so $a+b>\sup A+\sup B-2\eta$. Therefore $\varphi(x+y)=\varphi(x)+\varphi(y)$, and $\varphi(-x)=-\varphi(x)$.

Products of positive elements are respected as well. If $x,y>0$, the positive rationals in $L(xy)$ are exactly the products $rs$ with $r\in L(x)$, $s\in L(y)$ and $r,s>0$. One inclusion multiplies the two inequalities. For the other, take $0<q<xy$. Density supplies a positive rational $r$ with $q/y<r<x$, and then $0<q/r<y$.
% MATHFIX: the original text invoked ``the same argument with quotients'' and asserted that suprema of positive products multiply; the quotient step and the $\varepsilon$ estimate are written here.
Let $A$ be the positive part of $L(x)$, let $B$ be the positive part of $L(y)$, and let $P=\{ab:a\in A,\,b\in B\}$. Density puts a positive rational in $L(x)$, and $\varphi(x)>\varphi(0)=0$, so $\alpha=\sup A$ equals $\varphi(x)$. The same holds for $\beta=\sup B=\varphi(y)$. Every product satisfies $ab\le\alpha\beta$, so $\sup P\le\alpha\beta$. For the reverse, fix $\eta>0$ and choose $\varepsilon>0$ smaller than $\alpha$, smaller than $\beta$, and smaller than $\eta/(\alpha+\beta)$. Some $a\in A$ and $b\in B$ then satisfy $a>\alpha-\varepsilon$ and $b>\beta-\varepsilon$, hence
\[
ab>(\alpha-\varepsilon)(\beta-\varepsilon)=\alpha\beta-\varepsilon(\alpha+\beta)+\varepsilon^2>\alpha\beta-\varepsilon(\alpha+\beta)>\alpha\beta-\eta.
\]
So $\sup P=\alpha\beta$. The positive part of $L(xy)$ is $P$ and $\varphi(xy)>0$, so $\varphi(xy)=\sup P=\varphi(x)\varphi(y)$. The rule $\varphi(-x)=-\varphi(x)$ extends the identity to the remaining signs.

It remains to see that no other field map exists. Let $\psi:\R\to F$ be any morphism of fields. It fixes $1$, hence fixes $\Z$, hence fixes $\Q$, and $\psi(0)=0$. Every positive $x\in\R$ is a square. Let $S=\{q\in\Q:q\ge 0,\ q^2<x\}$. This set contains $0$ and is bounded above, by Archimedes. Let $s=\sup S$. The square $s^2$ cannot be strictly below $x$, and it cannot be strictly above $x$.

If $s^2<x$, set $\delta=\min\bigl(1,(x-s^2)/(2s+2)\bigr)>0$ and pick a rational $h$ with $0<h<\delta$. Then $0<h<1$, so $h^2\le h$, and
\[
(s+h)^2=s^2+2sh+h^2\le s^2+h(2s+1).
\]
The bound on $h$ gives $h(2s+2)<x-s^2$. Since $2s+1<2s+2$,
\[
h(2s+1)<h(2s+2)<x-s^2,
\]
and therefore $(s+h)^2<x$.
Density puts a rational $q$ in the interval $s<q<s+h$. Then $q^2<x$ and $q>s$, contradicting the choice of $s$.

If $s^2>x$, then $s>0$ because $0\in S$. Set $\delta=\min\bigl(s,(s^2-x)/(2s)\bigr)>0$. A rational $h$ with $0<h<\delta$ satisfies
\[
(s-h)^2=s^2-2sh+h^2>s^2-2sh\ge x,
\]
so $s-h$ is a smaller upper bound of $S$. The only remaining possibility is $s^2=x$.

Thus $x\ge 0$ gives $\psi(x)=\psi(\sqrt{x})^2\ge 0$, because a square in an ordered field is nonnegative. So $\psi$ is increasing. For rationals $q<x<q'$ one has $q\le\psi(x)\le q'$. Density of $\Q$ in $F$ forces $\psi(x)=\varphi(x)$.
\end{proof}

Dedekind's cuts, from the 1872 booklet, take the real to be the set of rationals below it. Theorem~\ref{thm:uniqueR} says this produces the same ordered field. The details are Exercise~\ref{ex:cuts}. School decimals give a third construction. They work, but the carrying rules are unpleasant to check. Figure~\ref{fig:rw-reals} uses decimals only as a picture of the diagonal, not as the official definition.

\section{Countable and uncountable}

Picture a hotel with rooms numbered $0,1,2,\ldots$, every room taken. One new guest arrives. The manager asks the guest in room $n$ to move to room $n+1$. Room $0$ is free. A coach then arrives, carrying infinitely many new guests. The manager sends the guest in room $n$ to room $2n$. The odd rooms are free. Hilbert told this story in his G\"ottingen lectures of the winter of 1924--25, to show that matching infinite sets is a delicate idea. Cantor's definition is the one that makes the idea precise. Two sets have the same size when their elements can be paired with nothing left over.

\begin{definition}
Sets $A$ and $B$ are equipotent, written $|A|=|B|$, when some bijection runs from $A$ to $B$. Write $|A|\le|B|$ when some injection runs from $A$ to $B$. A set is finite when it is equipotent to $n=\{0,\ldots,n-1\}$ for some $n\in\N$, and infinite otherwise. A set $A$ is countable when $|A|\le|\N|$.
\end{definition}

\begin{think}
Between any two integers sit infinitely many rationals. Does that mean there are more rationals than integers? Every real is a limit of rationals. Does that mean there are no more reals than rationals?
\end{think}

\begin{proposition}\label{prop:countable}
\begin{enumerate}[label=(\alph*)]
\item A subset of $\N$ is finite or equipotent to $\N$. A countable set is therefore finite, or in bijection with $\N$.
\item The product $\N\times\N$ is countable, and so are $\Z$ and $\Q$.
\item With countable choice: a countable union of countable sets is countable.
\end{enumerate}
\end{proposition}
\begin{proof}
(a) A subset of a finite set is finite. Induct on $n=\{0,\ldots,n-1\}$. The empty set is finite. If $B\subseteq n$ and $n-1\notin B$, then $B$ is a subset of $n-1$. If $n-1\in B$, the inductive hypothesis makes $B\setminus\{n-1\}$ finite, and adjoining one fresh element produces a set equipotent to the successor: a bijection from $k$ onto the smaller piece extends by sending $k$ to the new element, and $S(k)=k\cup\{k\}$. Every subset of $\{0,\ldots,N\}$ is therefore finite.

The set $\N$ itself is not finite. It is not equipotent to $0$, because $0=\varnothing$ and $\N$ contains $0$.
% MATHFIX: the empty initial segment had to be separated off, since the greatest-element argument below assumes a nonempty image.
If an injection $\{0,\ldots,n-1\}\to\N$ exists with $n\ge 1$, its image is a nonempty finite subset of $\N$. Such a subset has a greatest element. This is an induction on the number of elements, using the total order from Proposition~\ref{prop:wellorder}: remove one element, take the greatest of what remains, and keep the larger of that element and the one that was removed. If $M$ is greatest in the image, then $M+1$ is missed. So no such injection is a bijection onto $\N$.

Now let $A\subseteq\N$ be infinite. Then $A$ is nonempty. The tail $\{a\in A:a>a_k\}$ is nonempty as well: otherwise $A\subseteq\{0,\ldots,a_k\}$, which is finite. Recursion and Proposition~\ref{prop:wellorder} supply $a_0=\min A$ and $a_{k+1}=\min\{a\in A:a>a_k\}$. The map $k\mapsto a_k$ is strictly increasing, so $a_{k+1}\ge a_k+1$ and $a_k\ge k$. Every $a\in A$ equals some $a_k$. If not, let $k$ be least with $a_k>a$. Then $k\ge 1$, because $a_0=\min A\le a$, and $a_{k-1}<a<a_k$ contradicts the choice of $a_k$.

(b) Powers are the recursion $2^0=1$, $2^{S(t)}=2\cdot 2^t$, and the same clauses with $3$ in place of $2$. The map $(m,n)\mapsto 2^m 3^n$ is injective. First, $3^t$ is odd for every $t$, in the sense $3^t=2s+1$ for some $s$. This holds for $t=0$. If $3^t=2s+1$, then $3^{t+1}=3(2s+1)=2(3s+1)+1$. Also $t\mapsto 3^t$ is strictly increasing, because $3^{t+1}=3\cdot 3^t>3^t$.

Cancellation is available in $\N$: if $xz=yz$ and $z\ne 0$, then $x=y$. Indeed the order is total, so it is enough to rule out $x<y$. That would mean $y=x+k$ with $k\ne 0$. Then $k$ and $z$ are both successors, and (h) together with (f) of Proposition~\ref{prop:semiring} forces $kz\ne 0$. Hence $yz=xz+kz>xz$.

Suppose $2^m 3^n=2^{m'}3^{n'}$ with $m\ge m'$. Cancel $2^{m'}$ to get $2^{m-m'}3^n=3^{n'}$. If $n>n'$, cancel $3^{n'}$ as well and obtain $2^{m-m'}3^{n-n'}=1$. A product $2^a 3^b$ equals $1$ only when $a=b=0$: if $a\ge 1$ the left side is at least $2$, and if $b\ge 1$ it is at least $3$. The exponent $n-n'$ is positive, so this case is impossible. Thus $n'\ge n$. Cancel $3^n$ and obtain $2^{m-m'}=3^{n'-n}$. The right side is odd. If the exponent $m-m'$ were at least $1$, the left side would be $2\cdot 2^{m-m'-1}$. A number of the form $2s$ cannot equal a number of the form $2s'+1$, because the difference would be $1$, while $2\cdot 0=0$ and $2k\ge 2$ for every $k\ge 1$. The exponent of $2$ is therefore $0$, so $m=m'$ and $3^n=3^{n'}$. The strictly increasing map $t\mapsto 3^t$ forces $n=n'$.
% MATHFIX: parity of the two prime powers, and cancellation in $\N$, were left implicit in the original comparison $2^{m-m'}=3^{n'-n}$.

A small check: the six pairs $(0,0)$, $(1,0)$, $(0,1)$, $(2,0)$, $(1,1)$, $(0,2)$ are sent to $1$, $2$, $3$, $4$, $6$, $9$, all different.

The integers inject into $\N\times\N$ by $n\mapsto(n,0)$ and $-n\mapsto(0,n)$ for $n>0$. The rationals inject into $\Z\times\Z$ by writing each fraction in lowest terms with positive denominator. A subset of a countable set is countable, so $\Z$ and $\Q$ are countable.

(c) Let $A_0,A_1,\ldots$ be countable, and choose an injection $f_k:A_k\to\N$ for each $k$. For $a$ in the union, let $k(a)$ be the least $k$ with $a\in A_k$. Then $a\mapsto\bigl(k(a),f_{k(a)}(a)\bigr)$ injects the union into $\N\times\N$.
\end{proof}

So the rationals may be written as a single list $q_0,q_1,q_2,\ldots$. The Calkin--Wilf tree in Figure~\ref{fig:calkinwilf} lists the positive ones with no repetition, and Exercise~\ref{ex:calkinwilf} gives a formula for the next term that never needs a greatest common divisor.

\begin{theorem}[Cantor, 1891]\label{thm:cantor}
No function from a set $A$ onto $\mathcal P(A)$ exists. Equivalently $|A|<|\mathcal P(A)|$, and the power set of $\N$ is uncountable.
\end{theorem}
\begin{proof}
Let $f:A\to\mathcal P(A)$, and set $D=\{a\in A:a\notin f(a)\}$. If $D=f(d)$ for some $d$, then $d\in D$ if and only if $d\notin f(d)=D$. That is absurd, so $D$ is not a value of $f$. The map $a\mapsto\{a\}$ injects $A$ into $\mathcal P(A)$, which is why the failure of a surjection is written $|A|<|\mathcal P(A)|$.
\end{proof}

The set $D$ in the proof is Russell's paradoxical set, stopped from being a contradiction because separation builds it inside $A$ rather than out of everything. Turing's proof that no program decides which programs halt is the same flip, applied to a list of programs. To match $\R$ with $\mathcal P(\N)$, injections in both directions have to be promoted to a bijection.

\begin{theorem}[Schr\"oder--Bernstein]\label{thm:sb}
If there is an injection $f:A\to B$ and an injection $g:B\to A$, then there is a bijection from $A$ to $B$.
\end{theorem}
\begin{proof}
Set $C_0=A\setminus g(B)$, then $C_{n+1}=g(f(C_n))$, and $C=\bigcup_n C_n$. Define $h(a)=f(a)$ when $a\in C$, and $h(a)=g^{-1}(a)$ when $a\notin C$. The second clause makes sense: if $a\notin C$, then $a\notin C_0$, so $a$ lies in the image of $g$.

The map $h$ is injective on $C$ and injective on $A\setminus C$, because $f$ and $g^{-1}$ are. Suppose $f(a)=g^{-1}(a')$ with $a\in C_n$ and $a'\notin C$. Then $a'=g(f(a))\in C_{n+1}\subseteq C$, a contradiction. So no value is hit from both pieces, and $h$ is injective on $A$.

For surjectivity, take $b\in B$. If $g(b)\notin C$, then $h(g(b))=b$. If $g(b)\in C$, then $g(b)\notin C_0$, so $g(b)\in C_{n+1}=g(f(C_n))$ for some $n$. Injectivity of $g$ gives $b=f(a)$ for some $a\in C_n$, and then $h(a)=b$.
\end{proof}

\begin{theorem}\label{thm:continuum}
One has $|\R|=|[0,1]|=|\mathcal P(\N)|$. In particular $\R$ is uncountable, and so is every interval that contains more than one point.
\end{theorem}
\begin{proof}
The cut map $x\mapsto L(x)=\{q\in\Q:q<x\}$ injects $\R$ into $\mathcal P(\Q)$, because between two reals there is a rational. A bijection $\Q\to\N$, from Proposition~\ref{prop:countable}, pushes forward to a bijection $\mathcal P(\Q)\to\mathcal P(\N)$. In the other direction, send $A\subseteq\N$ to $\sum_{n\in A}2\cdot 3^{-n-1}$, which lands in $[0,1]$. If $A\ne B$ and $n$ is the least element of the symmetric difference, say $n\in A\setminus B$, the two sums differ by at least
\[
2\cdot 3^{-n-1}-\sum_{k>n}2\cdot 3^{-k-1}=3^{-n-1}>0.
\]
The tail of the geometric series is exactly $3^{-n-1}$, which is why the leading $2$ leaves a positive gap. Thus
\[|\mathcal P(\N)|\le|[0,1]|\le|\R|\le|\mathcal P(\N)|,\]
and Theorem~\ref{thm:sb} turns the chain of inequalities into equalities.

An interval $I$ that contains two points $u<v$ contains the whole segment between them, so $[u,v]\subseteq I$. The rule $x\mapsto (x-u)/(v-u)$ is a bijection from $[u,v]$ onto $[0,1]$. Therefore $|\R|=|[0,1]|\le|I|\le|\R|$.
% MATHFIX: the original proof named a bijection only for a closed bounded interval; any two points of a convex set span such an interval, and the straight map is the bijection.
\end{proof}

Every countable subset of $\R$ therefore leaves most reals out. The algebraic numbers are countable, by Exercise~\ref{ex:algebraic}, so transcendental reals exist even though this argument never writes a single one down. That is what Cantor's 1874 paper did. Is there a set of reals strictly larger than $\N$ and strictly smaller than $\R$? The continuum hypothesis says there is not. G\"odel in 1938 and Cohen in 1963 showed that ZFC neither proves the hypothesis nor refutes it.

\section{Choice, Zorn and well-ordering}\label{sec:choice}

In 1904, Ernst Zermelo proved that every set can be well-ordered. The theorem includes $\R$. The argument took two pages, and it started a dispute. It depends on a principle mathematicians had already been using without a name: from any family of nonempty sets, one element can be chosen in each. Borel, Baire and Lebesgue objected, in the \emph{Cinq lettres} of 1905, that a choice which nobody can describe is not a choice. Hadamard answered that existence and description are different. The later verdict is precise. The axiom of choice cannot be proved from the other axioms, and it cannot be refuted from them either (G\"odel in 1938, Cohen in 1963). It is the tool that produces bases and maximal ideals in this volume. It also produces objects that fight intuition. The Banach--Tarski paradox of 1924, quoted here and not proved, cuts a ball into finitely many pieces and reassembles the pieces into two balls of the same size. Robinson, in 1947, showed that five pieces suffice and that four do not. The doubling is easy to remember as an anagram. Question: what is an anagram of ``Banach--Tarski''? Answer: ``Banach--Tarski Banach--Tarski''.

\begin{definition}
The axiom of choice says that for every set $\mathcal A$ of nonempty sets, some function $c$ defined on $\mathcal A$ satisfies $c(A)\in A$ for every $A\in\mathcal A$. The function $c$ is a choice function.
\end{definition}

When $\mathcal A$ is finite, the other axioms already produce a choice function, by induction on the number of sets. The countably many enumerations in Proposition~\ref{prop:countable}(c) are another matter, and so is the choice of one point from each class of $\R/\Q$. That second choice builds Vitali's set in Chapter~\ref{ch:measures}. In practice the axiom is usually called through an equivalent statement about orders.

\begin{definition}
A partial order on a set $P$ is a relation that is reflexive, antisymmetric and transitive. A chain in $P$ is a subset that is totally ordered by the relation. An upper bound of $C\subseteq P$ is an element $u$ with $c\le u$ for every $c\in C$. A maximal element is an $m\in P$ for which no $x$ satisfies $x>m$. A well-order is a total order in which every nonempty subset has a least element.
\end{definition}

\begin{theorem}[Zorn's lemma]\label{thm:zorn}
Assume the axiom of choice. If $P$ is a nonempty partially ordered set, and every chain in $P$ has an upper bound, then $P$ has a maximal element.
\end{theorem}
\begin{proof}
Suppose $P$ has no maximal element. Then every chain $C$ has a strict upper bound. Some upper bound $u$ exists by hypothesis, $u$ is not maximal, and some $v>u$ is then a strict upper bound of $C$. The empty chain is included: its upper bounds are simply the elements of $P$, and $P$ is nonempty and has no maximal element, so a strict upper bound of the empty chain exists as well. Choice selects one strict upper bound $g(C)$ for every chain $C$.

Call $W\subseteq P$ a $g$-set when the order of $P$ well-orders $W$, and $w=g(W_{<w})$ for every $w\in W$, where $W_{<w}=\{x\in W:x<w\}$. A subset $S\subseteq W$ is an initial segment of $W$ when $s\in S$, $w\in W$ and $w<s$ together imply $w\in S$.

Any two $g$-sets are comparable: one is an initial segment of the other. Let $W$ and $W'$ be $g$-sets, and let $D$ be the union of all sets that are initial segments of both. Then $D$ itself is an initial segment of both. Suppose $D\ne W$ and $D\ne W'$. Let $w=\min(W\setminus D)$ and $w'=\min(W'\setminus D)$. The predecessors of $w$ in $W$ are exactly $D$. Anything below $w$ lies in $D$ by minimality of $w$. If some $d\in D$ satisfied $d\ge w$, then $w\in D$ because $D$ is an initial segment. The same reading gives $W'_{<w'}=D$. Therefore $w=g(D)=w'$. The set $D\cup\{w\}$ is then an initial segment of both $W$ and $W'$, which contradicts the way $D$ was built. So one of $W$ and $W'$ equals $D$, and that one is an initial segment of the other.

The union $U$ of all $g$-sets is again a $g$-set. Two elements of $U$ lie in some $g$-sets $W$ and $W'$, and one of those contains the other, so the two elements are comparable. Thus $U$ is totally ordered. Each $g$-set $W$ is an initial segment of $U$. If $w\in W$ and $u<w$ with $u$ belonging to a $g$-set $W'$, comparability puts $u$ in $W$ whether $W'$ is an initial segment of $W$ or $W$ is an initial segment of $W'$. A nonempty $S\subseteq U$ meets some $W$, and the least element of $S\cap W$ is the least element of $S$, again because $W$ is an initial segment of $U$. For $u\in W$ one has $U_{<u}=W_{<u}$, so $g(U_{<u})=u$.

The union $U$ is a chain, so $g(U)$ is defined, and $g(U)\notin U$ because $g(U)$ strictly exceeds every element of $U$. But $U\cup\{g(U)\}$ is a $g$-set: the new element sits at the top, and it equals $g$ of its predecessors. A $g$-set is contained in $U$. That is a contradiction.
\end{proof}

\begin{theorem}\label{thm:wellordering}
In ZF, the following three statements are equivalent. The axiom of choice. Zorn's lemma. Every set admits a well-ordering. The last of these is Zermelo's theorem of 1904.
\end{theorem}
\begin{proof}
The axiom of choice yields Zorn's lemma by Theorem~\ref{thm:zorn}.

Zorn's lemma yields a well-ordering. Let $X$ be any set, and let $P$ be the set of pairs $(S,\preceq)$ in which $S\subseteq X$ and $\preceq$ well-orders $S$. Declare $(S,\preceq)\le(S',\preceq')$ when $S$ is an initial segment of $S'$ and $\preceq'$ extends $\preceq$. A chain in $P$ has an upper bound: take the union $S^*$ of the underlying sets, ordered by the union of the orders. The union order is total, because any two elements lie in some common member of the chain or in two comparable members. A nonempty $A\subseteq S^*$ meets some $S$ from the chain, and that $S$ is an initial segment of $S^*$, so the least element of $A\cap S$ is least in $A$. Zorn's lemma supplies a maximal pair $(M,\preceq)$. If some $x$ lay in $X\setminus M$, placing $x$ strictly above every element of $M$ would give a larger element of $P$. The enlarged order is still a well-order: a nonempty subset either avoids $x$ and has a least element in $M$, or contains $x$, in which case the least element of the rest of the subset (or $x$ itself, if the rest is empty) is least.
% MATHFIX: adjoining a new top element preserves well-ordering; the original text named the larger pair without this check.
Thus $M=X$.

A well-ordering yields the axiom of choice. Well-order $\bigcup\mathcal A$, and let $c(A)$ be the least element of $A$.
\end{proof}

\begin{theorem}\label{thm:basis}
Assume the axiom of choice. Every vector space $V$ over a field $K$ has a basis. More precisely, every linearly independent subset of $V$ is contained in some basis.
\end{theorem}
\begin{proof}
Let $L_0$ be linearly independent. Order by inclusion the independent sets that contain $L_0$. The union of a chain is independent: a linear relation uses only finitely many vectors, and those vectors lie together in one member of the chain. Zorn's lemma supplies a maximal independent set $B\supseteq L_0$. This $B$ spans $V$. If some $v$ lay outside the span, then $B\cup\{v\}$ would be independent. A linear relation $a v+\sum a_b b=0$ with $a\ne 0$ would solve for $v$ and put $v$ in the span, while $a=0$ would be a linear relation among elements of $B$.
% MATHFIX: the one-vector extension is independent only after the coefficient of the new vector is split off; that case was left tacit.
Maximality forbids the extension, so no such $v$ exists.
\end{proof}

A basis of $\R$ as a vector space over $\Q$ is a Hamel basis, introduced in 1905. No one can write the general element of such a basis down. Exercise~\ref{ex:hamel} turns a coordinate of the basis into an additive function that is not multiplication by a constant. The same maximality pattern shows that every proper ideal of a commutative ring sits inside a maximal ideal, which is Exercise~\ref{ex:krull}, and that every field has an algebraic closure. Chapter~\ref{ch:compact} uses it again for Tychonoff's theorem. Choice is independent of ZF in the sense already quoted: G\"odel in 1938 showed that a refutation is impossible, and Cohen in 1963 showed that a proof from the other axioms is impossible.

\begin{beauty}
Numbers, functions and spaces are sets, and a short list of rules produces them. The passage from $\Q$ to $\R$ is the first completion in the series. Chapter~\ref{ch:metric} runs the same construction for an arbitrary metric space, and finds the $p$-adic numbers by completing $\Q$ for a different distance. Volume~8 meets $L^2$ as the completion of the continuous functions. Cantor's diagonal travels further than any of those constructions. It shows that $\R$ is uncountable, that there is no set of all sets, that some true sentences of arithmetic have no proof (G\"odel), and that some problems are solved by no program (Turing). Those last two belong to logic; the diagonal itself is already in Theorem~\ref{thm:cantor}. The axiom of choice marks the edge of naive pictures. It gives every vector space a basis, and it gives subsets of the line for which no reasonable length exists.
\end{beauty}

\section{Answers to the opening questions}

The four questions from the first page now have answers. There are as many rationals as integers, because $\Q$ is countable (Proposition~\ref{prop:countable}). There are more reals than rationals, because no list contains every real (Theorems~\ref{thm:cantor} and~\ref{thm:continuum}). A square has exactly as many points as one side (Exercise~\ref{ex:square}). A real number is an equivalence class of Cauchy sequences of rationals.

Three tools that earlier volumes used on trust are theorems here. Induction, and definition by recursion, hold for $\N$ (Theorems~\ref{thm:peano} and~\ref{thm:recursion}). Every nonempty set of reals that is bounded above has a least upper bound, and every Cauchy sequence of reals converges (Theorem~\ref{thm:reals}). Only one ordered field has the least-upper-bound property (Theorem~\ref{thm:uniqueR}), so nothing later depends on the particular construction of $\R$. Choice entered in three equivalent forms (Theorem~\ref{thm:wellordering}). Its two most visible uses in this volume are Tychonoff's theorem in Chapter~\ref{ch:compact} and the set with no length in Chapter~\ref{ch:measures}.

The construction of $\R$ used very little about $\Q$: a distance $|x-y|$, and the sequences that huddle. The same huddling can be run on another set of points, or with another distance on $\Q$. Chapter~\ref{ch:metric} does both.

\section{Exercises}

\begin{exercise}[$\star$]\label{ex:sqrt2}
Let $A=\{q\in\Q:q>0,\ q^2<2\}$. Show that $A$ has no least upper bound in $\Q$. Use the map $\phi(q)=(2q+2)/(q+2)$ for $q>0$. Show that $\phi$ sends $A$ into $A$ and raises every element of $A$, and that $\phi$ sends each positive rational upper bound of $A$ to a strictly smaller upper bound.
\end{exercise}

\begin{exercise}[$\star$]\label{ex:algebraic}
Call a complex number algebraic when it is a root of some non-zero polynomial with integer coefficients. Prove that only countably many complex numbers are algebraic. Deduce that uncountably many reals are transcendental.
\end{exercise}

\begin{exercise}[$\star$]\label{ex:cauchyfe}
Suppose $f:\R\to\R$ satisfies $f(x+y)=f(x)+f(y)$ for all real $x$ and $y$. Show that $f(q)=qf(1)$ for every rational $q$. Then show that $f(x)=xf(1)$ for every real $x$, provided $f$ is continuous, or provided $f$ is monotone.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:square}
Show that $|[0,1]\times[0,1]|=|[0,1]|$. A square therefore has as many points as one of its sides. Deduce that $|\R^n|=|\R|$ for every integer $n\ge 1$.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:hamel}
(a) Show that $\R$, as a vector space over $\Q$, has a basis $B$. (b) Fix $b_0\in B$, and let $f(x)$ be the coefficient of $b_0$ in the expansion of $x$. Show that $f$ is additive, and that $f$ is not of the form $x\mapsto cx$. (c) Let $f:\R\to\R$ be additive and not of the form $x\mapsto cx$. Show that the graph of $f$ is dense in $\R^2$. Conclude that $f$ is unbounded on every nonempty open interval.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:cuts}
A Dedekind cut is a set $\alpha\subseteq\Q$ which is nonempty, not equal to $\Q$, closed downwards ($q<a\in\alpha$ implies $q\in\alpha$), and without a greatest element. (a) Show that the set of all cuts, ordered by inclusion, has the least-upper-bound property. (b) Show that $x\mapsto\{q\in\Q:q<x\}$ is an order-preserving bijection from $\R$ onto the set of cuts.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:krull}
Assume the axiom of choice. Let $R$ be a commutative ring with $1\ne 0$. Show that every ideal $I\ne R$ is contained in some maximal ideal.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:functions}
Let $C(\R,\R)$ be the set of continuous functions from $\R$ to $\R$, and let $\R^\R$ be the set of all functions from $\R$ to $\R$. Show that $C(\R,\R)$ has the same cardinality as $\R$, while $\R^\R$ has the same cardinality as $\mathcal P(\R)$, which is strictly larger.
\end{exercise}

\begin{exercise}[$\star\star\star$]\label{ex:calkinwilf}
\emph{The Calkin--Wilf listing.} In the tree of Figure~\ref{fig:calkinwilf}, the root is $1/1$, and the children of $a/b$ are $a/(a+b)$ on the left and $(a+b)/b$ on the right. Number the nodes level by level, from left to right, so that $q_1=1/1$, $q_2=1/2$, $q_3=2/1$, $q_4=1/3$, and so on. The children of $q_n$ are then $q_{2n}$ and $q_{2n+1}$. (a) Show that every positive rational appears exactly once, and already in lowest terms. (b) Show Newman's formula
\[
q_{n+1}=\dfrac{1}{2\lfloor q_n\rfloor +1-q_n},
\]
which produces the next positive rational without a greatest common divisor.
\end{exercise}

\begin{exercise}[$\star$]\label{ex:cwcompute}
\emph{Ten terms, then one index.} Use the numbering of Exercise~\ref{ex:calkinwilf}. (a) Start from $q_1=1$ and compute $q_2,\ldots,q_{10}$ from Newman's formula $q_{n+1}=1/(2\lfloor q_n\rfloor+1-q_n)$. (b) Find the index $n$ for which $q_n=13/5$, without writing the earlier terms of the list.
\end{exercise}

\begin{exercise}[$\star$]\label{ex:v7c01a}
Show that $n<S(n)$ for every $n\in\N$. Then show that no natural number $m$ satisfies $n<m<S(n)$.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:v7c01b}
Let $\mathcal F$ be the set of all finite subsets of $\N$. Show that $\mathcal F$ is countable. The injections in the proof can be written down from the well-ordering of $\N$ and from the map $(m,n)\mapsto 2^m 3^n$, so countable choice is not required.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:v7c01c}
Show that every real $x>0$ has a unique positive square root: there is exactly one real $s>0$ with $s^2=x$.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:v7c01d}
Let $(a_n)$ and $(b_n)$ be sequences of reals such that $a_n\le a_{n+1}\le b_{n+1}\le b_n$ for every $n$, and such that $b_n-a_n$ tends to $0$: for every real $\varepsilon>0$ there exists $N$ with $b_n-a_n<\varepsilon$ whenever $n\ge N$. Show that there is exactly one real $s$ satisfying $a_n\le s\le b_n$ for every $n$.
\end{exercise}

\begin{solution}{ex:sqrt2}
\idea A least upper bound of $A$ inside $\Q$ would square to $2$. Volume~1 already shows that no rational does that. To see the obstruction without leaving $\Q$, use one fractional linear map that improves a lower approximation and also improves an upper approximation.
\writeup Let $\phi(q)=(2q+2)/(q+2)$ for $q>0$. Then
\[
\phi(q)-q=\frac{2-q^2}{q+2},\qquad \phi(q)^2-2=\frac{2(q^2-2)}{(q+2)^2}.
\]
If $q\in A$, then $q^2<2$. The numerator $2-q^2$ is positive, so $\phi(q)>q$. The numerator $q^2-2$ is negative, so $\phi(q)^2<2$. Thus $\phi(q)$ is a strictly larger element of $A$. If $q>0$ is a rational upper bound of $A$, then $q^2\ge 2$. Indeed, $q^2<2$ would put $\phi(q)$ in $A$ and above $q$. No rational squares to $2$, so $q^2>2$, and the two displays give $\phi(q)<q$ together with $\phi(q)^2>2$. Every $a\in A$ is positive and satisfies $a^2<2<\phi(q)^2$. The map $t\mapsto t^2$ is increasing on the positive rationals, so $a<\phi(q)$. The value $\phi(q)$ is a strictly smaller positive upper bound. Therefore no rational is a least upper bound. Any upper bound $s\in\Q$ is positive, because $1\in A$, and $\phi(s)$ undercuts it.
\end{solution}

\begin{solution}{ex:algebraic}
\idea Group the polynomials by one natural number that leaves only finitely many polynomials, and only finitely many roots, in each group. A countable union of those finite lists is still countable.
\writeup For $P=\sum_{i\le d}a_i X^i$ with $a_d\ne 0$, set $h(P)=d+\sum|a_i|\in\N$. For each fixed $n$, only finitely many such polynomials have $h(P)=n$: the degree is at most $n$, and each coefficient lies in $\{-n,\ldots,n\}$. Each of them has at most $n$ complex roots. The algebraic numbers are the union, over $n$, of these finite root sets. A finite set of complex numbers can be listed without choice, by increasing real part and, within a tie, by increasing imaginary part. Proposition~\ref{prop:countable}(c) is therefore not even needed in its choosing form: the union of an explicit countable family of explicit finite lists is countable. If the set $T$ of transcendental reals were countable, then $\R=T\cup(\R\cap\{\text{algebraic numbers}\})$ would be a union of two countable sets, contradicting Theorem~\ref{thm:continuum}.
\end{solution}

\begin{solution}{ex:cauchyfe}
\idea Additivity alone produces linearity over $\Q$. Continuity, or monotonicity, lets a real be approached by rationals closely enough to keep the same coefficient.
\writeup The equation $f(0)=f(0)+f(0)$ forces $f(0)=0$, and then $f(x)+f(-x)=f(0)$ forces $f(-x)=-f(x)$. Induction gives $f(nx)=nf(x)$ for $n\in\N$. If $q=m/n$ in lowest terms, or in any terms, $nf(q)=f(nq)=f(m)=mf(1)$, so $f(q)=qf(1)$.

Suppose $f$ is continuous, and let $q_k\to x$ through rationals, which density allows. Then $f(x)=\lim f(q_k)=\lim q_k f(1)=xf(1)$. Suppose instead that $f$ is non-decreasing, and let $q<x<q'$ be rational. Then $qf(1)\le f(x)\le q'f(1)$. Let $q$ and $q'$ both tend to $x$. The squeeze gives $f(x)=xf(1)$. If $f$ is non-increasing, the same trap holds with the inequalities reversed.
\end{solution}

\begin{solution}{ex:square}
\idea Both sets are as large as a power set of $\N$, or as a product of two such power sets. Two copies of $\N$ fit inside one copy, by evens and odds. Schr\"oder--Bernstein turns the resulting injections into a bijection.
\writeup Theorem~\ref{thm:continuum} provides a bijection $\beta:[0,1]\to\mathcal P(\N)$. The rule
\[
(A,B)\mapsto\{2a:a\in A\}\cup\{2b+1:b\in B\}
\]
is a bijection from $\mathcal P(\N)\times\mathcal P(\N)$ onto $\mathcal P(\N)$, because a subset of $\N$ is exactly the union of its even part and its odd part. Composing
\[
[0,1]^2\to\mathcal P(\N)^2\to\mathcal P(\N)\to[0,1]
\]
gives a bijection. For the Euclidean spaces, $|\R|=|[0,1]|$, so $|\R^2|=|[0,1]^2|=|[0,1]|=|\R|$. If $|\R^{n-1}|=|\R|$, then $|\R^n|=|\R^{n-1}\times\R|=|\R\times\R|=|\R|$.

Cantor proved the square has as many points as the side in 1877, and wrote to Dedekind: ``I see it, but I do not believe it.'' A bijection of this kind cannot be continuous (Exercise~\ref{ex:notR2}). A continuous surjection from the segment onto the square does exist, and it waits until Chapter~\ref{ch:compact}.
\end{solution}

\begin{solution}{ex:hamel}
\idea Zorn's lemma supplies the basis. A coordinate relative to that basis is linear over $\Q$ and fails to be linear over $\R$. Density of the graph comes from two vectors in the plane that are independent over $\R$: their rational combinations are dense, and additivity puts those combinations on the graph.
\writeup (a) Apply Theorem~\ref{thm:basis} with $K=\Q$ and $V=\R$.

(b) Every real $x$ has a unique expression as a finite sum $\sum_{b\in B}c_b(x)\,b$ with rational coefficients $c_b(x)$. Uniqueness forces $c_b(x+y)=c_b(x)+c_b(y)$, so $f=c_{b_0}$ is additive. Suppose $f(x)=cx$ for every $x$. Then $c=f(b_0)/b_0=1/b_0\ne 0$. The basis $B$ is infinite: $\R$ is uncountable, while a finite-dimensional vector space over $\Q$ is a finite union of copies of $\Q^d$ and is therefore countable. Pick $b_1\in B\setminus\{b_0\}$. Then $f(b_1)=0$, while $cb_1\ne 0$.

(c) Let $f$ be additive, hence $\Q$-linear by Exercise~\ref{ex:cauchyfe}, and suppose $f$ is not multiplication by a constant. Then the ratio $f(x)/x$ is not constant for $x\ne 0$. Choose $x_1$ and $x_2$ with $f(x_1)/x_1\ne f(x_2)/x_2$. The vectors $v_i=(x_i,f(x_i))$ are linearly independent over $\R$, because the determinant $x_1 f(x_2)-x_2 f(x_1)$ is nonzero. The map $(s,t)\mapsto s v_1+t v_2$ is a linear bijection of $\R^2$, continuous, and with continuous inverse. It carries the dense set $\Q^2$ onto a dense set. A point $q_1 v_1+q_2 v_2$ equals
\[
(q_1 x_1+q_2 x_2,\ f(q_1 x_1+q_2 x_2)),
\]
which lies on the graph. The graph is therefore dense in $\R^2$. Over any nonempty open interval $I$, density supplies points $(x,f(x))$ with $x\in I$ and with $f(x)$ larger than any prescribed bound.
\end{solution}

\begin{solution}{ex:cuts}
\idea A cut is the set of rationals strictly below some real, once the real exists. Going the other way, the least upper bound of a cut is the real it was describing. Before that identification, the union of a bounded family of cuts is their least upper bound in the set of cuts.
\writeup (a) Let $(\alpha_i)$ be a nonempty family of cuts, all contained in one cut $\gamma$, and set $\alpha=\bigcup_i\alpha_i$. Then $\alpha$ is nonempty, and $\alpha\subseteq\gamma\ne\Q$. It is closed downwards because each $\alpha_i$ is. It has no greatest element: any element of $\alpha$ lies in some $\alpha_i$, and that cut contains something larger. So $\alpha$ is a cut. It contains every $\alpha_i$, and any cut that contains every $\alpha_i$ contains the union. Thus $\alpha$ is the least upper bound.

(b) For $x\in\R$, the set $L(x)=\{q:q<x\}$ is nonempty and is not all of $\Q$, by Archimedes. It is closed downwards, and density says it has no greatest element. If $x<y$, some rational lies in $L(y)\setminus L(x)$, so the map is strictly increasing, hence injective. For surjectivity, let $\alpha$ be a cut and pick $r\notin\alpha$. Every $a\in\alpha$ satisfies $a<r$: otherwise $r\le a$ would pull $r$ down into $\alpha$. So $\alpha$ is bounded above. Let $x=\sup\alpha$. If $q\in\alpha$, some $q'\in\alpha$ exceeds $q$, and $q<q'\le x$, so $q\in L(x)$. If $q<x$, then $q$ is not an upper bound of $\alpha$, so $q<a$ for some $a\in\alpha$, and downward closure gives $q\in\alpha$. Therefore $\alpha=L(x)$.
\end{solution}

\begin{solution}{ex:krull}
\idea A maximal ideal is a maximal element of a partially ordered set. Zorn's lemma applies once every chain in that set has an upper bound still in the set. Keeping $1$ out of the union is what keeps the union proper.
\writeup Let $P$ be the collection of ideals $J\supseteq I$ with $J\ne R$, equivalently $1\notin J$, ordered by inclusion. Then $I\in P$, so $P$ is nonempty. If $(J_k)$ is a nonempty chain in $P$, the union $J=\bigcup J_k$ is an ideal: any two elements lie in a common $J_k$ because the family is a chain, so their sum does too, and a multiple of an element stays in the ideal that contained it. The union contains $I$ and does not contain $1$, so it is an upper bound in $P$. Zorn's lemma supplies a maximal element $M$ of $P$. If an ideal $J$ satisfied $M\subsetneq J\ne R$, then $J$ would be a strictly larger element of $P$. So $M$ is a maximal ideal of $R$.
\end{solution}

\begin{solution}{ex:functions}
\idea Continuous functions are determined by countably much data, namely their values on $\Q$. Arbitrary functions are as numerous as subsets, because an indicator is a function, and because a function is itself a set of pairs.
\writeup Write $\mathfrak c=|\R|=|\mathcal P(\N)|$. Restriction of a continuous function to $\Q$ is injective: if two continuous functions agree on $\Q$, density and continuity make them agree on $\R$. Hence $|C(\R,\R)|\le|\R^\Q|$. A function $\Q\to\R$ is, after a bijection $\Q\to\N$, a function $\N\to\R$, so $|\R^\Q|=|\R^\N|$. Since $|\R|=|\mathcal P(\N)|$, one has $|\R^\N|=|\mathcal P(\N)^\N|$. A sequence $(A_k)$ of subsets of $\N$ is the same datum as the subset $\{(k,a):a\in A_k\}$ of $\N\times\N$. Therefore
\[
|\mathcal P(\N)^\N|=|\mathcal P(\N\times\N)|=|\mathcal P(\N)|=\mathfrak c,
\]
The middle step uses Proposition~\ref{prop:countable}: part (b) injects $\N\times\N$ into $\N$, and part (a) turns that injection into a bijection because the product is infinite. A bijection of the underlying sets matches their power sets. Constant functions inject $\R$ into $C(\R,\R)$, so $\mathfrak c\le|C(\R,\R)|$. Theorem~\ref{thm:sb} gives $|C(\R,\R)|=\mathfrak c$.

For all functions, $A\mapsto\mathbf 1_A$ injects $\mathcal P(\R)$ into $\R^\R$. A function $\R\to\R$ is a subset of $\R\times\R$, so $|\R^\R|\le|\mathcal P(\R\times\R)|$. Exercise~\ref{ex:square} gives $|\R\times\R|=|\R|$, and a bijection of the underlying sets induces a bijection of their power sets, so $|\mathcal P(\R\times\R)|=|\mathcal P(\R)|$. Thus $|\R^\R|=|\mathcal P(\R)|$. Theorem~\ref{thm:cantor} says this cardinal is strictly larger than $|\R|$.
\end{solution}

\begin{solution}{ex:calkinwilf}
\idea Climbing the tree is the subtractive form of Euclid's algorithm, and it ends at $1/1$. That single climb gives both existence and uniqueness. For the successor formula, a node is followed either by its sibling, when it is a left child, or by the left child of the next node after its parent, when it is a right child. Those are the only two shapes to check.
\writeup (a) The identities $\gcd(a,a+b)=\gcd(a+b,b)=\gcd(a,b)$ show, by induction up from $1/1$, that every node is written in lowest terms. A left child $a/(a+b)$ is strictly less than $1$, a right child $(a+b)/b$ is strictly greater than $1$, and the root equals $1$. The value of a node therefore tells you whether the node is the root, a left child, or a right child, and it tells you the parent's value: $a/(b-a)$ when $a<b$, and $(a-b)/b$ when $a>b$.

Proceed by induction on $a+b$. Each fraction $a/b$ in lowest terms occurs exactly once. If $a+b=2$, the fraction is $1/1$, and it occurs only at the root, because every other node is different from $1$. If $a+b>2$, then $a\ne b$ by lowest terms. The parent fraction is in lowest terms and has a smaller sum of numerator and denominator, so the inductive hypothesis says the parent occurs exactly once. The fraction $a/b$ is the left or the right child of that parent, so it occurs. Two occurrences would share the parent's value, hence would share the parent's node, and they would lie on the same side of that parent. They would be the same node.

(b) Let $s(x)=1/(2\lfloor x\rfloor+1-x)$. The claim $q_{n+1}=s(q_n)$ is an induction on $n\ge 1$. For $n=1$, $s(1)=1/2=q_2$. Take $n\ge 2$. If $n=2m$, then $q_n=a/(a+b)<1$ is the left child of $q_m=a/b$, and the next node $q_{n+1}=(a+b)/b$ is the sibling. And $s(q_n)=1/(1-q_n)=(a+b)/b$. If $n=2m+1$, then $q_n=x+1$ with $x=q_m$. The next node $q_{n+1}=q_{2(m+1)}$ is the left child of $q_{m+1}$. The left child of a fraction $c/d$ is $c/(c+d)=(c/d)/((c/d)+1)$, so if $y=q_{m+1}$ then the left child is $y/(y+1)$. The inductive hypothesis applies to $m$, because $m+1\le n$, and gives $y=s(x)=1/(2k+1-x)$ with $k=\lfloor x\rfloor$. Therefore
\[
q_{n+1}=\frac{1}{1+1/y}=\frac{1}{2k+2-x}.
\]
The formula at $q_n$ produces the same value: $s(q_n)=1/(2(k+1)+1-(x+1))=1/(2k+2-x)$. In both cases, $q_{n+1}=s(q_n)$.
\end{solution}

\begin{solution}{ex:cwcompute}
\idea The successor formula reads only the integer part of the current term, then one subtraction and one reciprocal. For the index of $13/5$, the path from the root is a binary word: left is a zero bit after the leading one, and right is a one bit.
\writeup (a) Since $\lfloor q_1\rfloor=1$, the formula gives $q_2=1/(2\cdot 1+1-1)=1/2$. Then $\lfloor q_2\rfloor=0$, so $q_3=1/(0+1-1/2)=2$. The same substitution, term by term, produces
\[q_4=\tfrac1{4+1-2}=\tfrac13,\quad q_5=\tfrac1{1-\frac13}=\tfrac32,\quad q_6=\tfrac1{2+1-\frac32}=\tfrac23,\quad q_7=\tfrac1{1-\frac23}=3,\]
\[q_8=\tfrac1{6+1-3}=\tfrac14,\quad q_9=\tfrac1{1-\frac14}=\tfrac43,\quad q_{10}=\tfrac1{2+1-\frac43}=\tfrac35.\]
These are the first ten nodes of Figure~\ref{fig:calkinwilf}, read across the levels. Four complete levels would contain fifteen nodes.

(b) Climb from $13/5$ toward the root. A value greater than $1$ is a right child, and its parent is $(a-b)/b$. A value less than $1$ is a left child, and its parent is $a/(b-a)$. The climb is
\[\tfrac{13}5\ \xrightarrow{R}\ \tfrac85\ \xrightarrow{R}\ \tfrac35\ \xrightarrow{L}\ \tfrac32\ \xrightarrow{R}\ \tfrac12\ \xrightarrow{L}\ \tfrac11.\]
Reading downward from the root, the steps are $L,R,L,R,R$. The root has index $1$. A left step sends $m$ to $2m$, and a right step sends $m$ to $2m+1$:
\[
1\to 2\to 5\to 10\to 21\to 43.
\]
So $q_{43}=13/5$. In binary, $43=101011$. After the leading $1$, a digit $0$ is a left step and a digit $1$ is a right step. The upward steps $R,R,L,R,L$ are the subtractions in Euclid's algorithm applied to $13$ and $5$.
\end{solution}

\begin{solution}{ex:v7c01a}
\idea The order on $\N$ was defined from addition, and the successor is the sum with $1$. A natural number strictly between $n$ and $n+1$ would require a positive increment strictly smaller than $1$. The least positive natural number is $1$.
\writeup By definition $S(n)=n+1$ with $1=S(0)\ne 0$, so $n<S(n)$. The first few cases are $0<1<2<3$. Suppose $n<m<S(n)$. Then $m=n+k$ for some $k\ne 0$. Part (f) of the proof of Proposition~\ref{prop:semiring} records that $\{0\}\cup S(\N)$ is inductive, so $k=S(j)$ for some $j$. The recursion for addition gives $m=n+S(j)=S(n+j)$. Part (b) of that same proof gives $S(n)+j=S(n+j)$. Hence $m=S(n)+j$, so $S(n)\le m$. This contradicts $m<S(n)$. There is no natural number strictly between $4$ and $5$, and the same one-step gap sits above every $n$.
\end{solution}

\begin{solution}{ex:v7c01b}
\idea Sort each finite set. A $k$-element set becomes a strictly increasing $k$-tuple, and tuples of a fixed length inject into $\N$ once pairs do. The passage from $k$ to $k+1$ is one more use of $(m,n)\mapsto 2^m 3^n$.
\writeup For each $k\in\N$, let $\mathcal F_k$ be the set of subsets of $\N$ with exactly $k$ elements, in the sense of equipotence with $\{0,\ldots,k-1\}$. Then $\mathcal F_0=\{\varnothing\}$, which injects into $\N$.

Take $k\ge 1$ and $A\in\mathcal F_k$. Well-ordering supplies a strictly increasing enumeration: $a_0=\min A$, and $a_{i+1}=\min(A\setminus\{a_0,\ldots,a_i\})$. Recursion is legitimate because each remaining piece is a nonempty subset of $\N$ until $k$ elements have been chosen. The resulting map $A\mapsto(a_0,\ldots,a_{k-1})$ injects $\mathcal F_k$ into $\N^k$, and the set $A$ is recovered as the set of coordinates.

The product $\N^k$ injects into $\N$, by induction on $k$. For $k=1$ the identity map is an injection. If $g:\N^k\to\N$ is injective, then
\[
(a_0,\ldots,a_k)\mapsto\bigl(g(a_0,\ldots,a_{k-1}),a_k\bigr)
\]
injects $\N^{k+1}$ into $\N\times\N$, and $(m,n)\mapsto 2^m 3^n$ injects $\N\times\N$ into $\N$ by Proposition~\ref{prop:countable}(b). The composite injections $\psi_k:\mathcal F_k\to\N$ are therefore defined for every $k$, with no choice of enumerations.

Every finite subset lies in exactly one $\mathcal F_k$. Send $A\in\mathcal F_k$ to $\bigl(k,\psi_k(A)\bigr)$. This injects $\mathcal F=\bigcup_k\mathcal F_k$ into $\N\times\N$, which injects into $\N$. So $\mathcal F$ is countable. The family $(\psi_k)$ was built by recursion from a single explicit pairing, which is why countable choice was not used.
\end{solution}

\begin{solution}{ex:v7c01c}
\idea The uniqueness proof for $\R$ already shows that every positive element of an ordered field with least upper bounds is a square, provided the rationals are dense. Here the field is $\R$ itself. Run that construction as the main argument, then compare two positive roots by factoring a difference of squares.
\writeup Let $x>0$, and let $S=\{q\in\Q:q\ge 0,\ q^2<x\}$. Then $0\in S$. The set is bounded above. Archimedes supplies a natural number $n>x$ with $n\ge 1$. Any rational $q\ge n$ satisfies $q\ge 1$, so $q^2\ge q\ge n>x$, and $q\notin S$. Theorem~\ref{thm:reals} supplies $s=\sup S$. The same two shifts used for Theorem~\ref{thm:uniqueR} show $s^2=x$.

If $s^2<x$, put $\delta=\min\bigl(1,(x-s^2)/(2s+2)\bigr)>0$ and choose a rational $h$ with $0<h<\delta$. Then $0<h<1$, so $h^2\le h$, and
\[
(s+h)^2=s^2+2sh+h^2\le s^2+h(2s+1).
\]
The bound on $h$ gives $h(2s+2)<x-s^2$. Since $2s+1<2s+2$, one has $h(2s+1)<x-s^2$, and therefore $(s+h)^2<x$.
Density of $\Q$ yields a rational $q$ with $s<q<s+h$, so $q^2<x$ and $q>s$, contradicting the definition of $s$.

If $s^2>x$, then $s>0$ because $0\in S$. Put $\delta=\min\bigl(s,(s^2-x)/(2s)\bigr)>0$ and choose a rational $h$ with $0<h<\delta$. Then
\[
(s-h)^2=s^2-2sh+h^2>s^2-2sh\ge x,
\]
so $s-h$ is a smaller upper bound of $S$. Both strict inequalities are impossible, and $s^2=x$.

The root just found satisfies $s^2=x>0$, so $s\ne 0$. It is not negative either: $s=\sup S$ and $0\in S$, hence $s\ge 0$. Together, $s>0$. Suppose $0<s<t$ and $t^2=s^2$. Then
\[
t^2-s^2=(t-s)(t+s)>0,
\]
because both factors are positive in an ordered field. This contradicts $t^2=s^2$. The positive square root is unique.
\end{solution}

\begin{solution}{ex:v7c01d}
\idea The lower endpoints climb and stay below $b_0$, so they have a supremum. That supremum cannot slip out of a later segment, because every later lower endpoint is still at most every earlier upper endpoint. Two distinct common points would leave a gap that the lengths are no longer allowed to cross.
\writeup Let $A=\{a_n:n\in\N\}$. The set $A$ is nonempty and bounded above by $b_0$. Theorem~\ref{thm:reals} supplies $s=\sup A$. Then $a_n\le s$ for every $n$. Also $s\le b_k$ for every $k$. Indeed every $a_n$ is at most $b_k$: if $n\le k$ then $a_n\le a_k\le b_k$, and if $n>k$ then $a_n\le b_n\le b_k$. So $a_n\le s\le b_n$ for every $n$.

Suppose $s<t$ were another real lying in every segment. Then $b_n-a_n\ge t-s>0$ for every $n$. Taking $\varepsilon=t-s$ contradicts the hypothesis that the lengths tend to $0$. So the common point is unique.

A check: $a_n=-1/(n+1)$ and $b_n=1/(n+1)$ satisfy the nesting, the lengths tend to $0$, and the only common point is $0$.
\end{solution}
