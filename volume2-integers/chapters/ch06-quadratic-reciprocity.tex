\chapter{Quadratic Residues and Reciprocity}\label{ch:reciprocity}

\begin{center}\itshape
Is $219$ a square modulo the prime $383$? A direct search might square $191$ numbers.\\
Quadratic reciprocity gives the answer (yes) in four lines. Gauss called it the \emph{golden theorem} and returned to it again and again.
\end{center}


Square the nonzero residues modulo $7$. The results are $1,2,4$. Every other nonzero class fails to be a square. That short list is easy to check. The difficult question comes when the modulus is a large odd prime: must we try half its nonzero classes, or can we decide without finding the square root itself?

A remarkable connection compares two different primes. Modulo $7$, the number $11$ is the class $4$, hence a square. Modulo $11$, the number $7$ is \emph{not} a square: the nonzero squares there are $1,3,4,5,9$. The two answers disagree. Both primes are $3$ modulo $4$, and quadratic reciprocity explains why their signs must be opposite. If at least one prime is $1$ modulo $4$, the signs instead agree.

The theorem does not say that the primes are interchangeable. It gives a precise sign rule, with an exception controlled by their remainders modulo $4$. We will first encode the yes-or-no question using the Legendre symbol, then prove the rule by counting lattice points. After that we will calculate symbols without listing all possible squares.

One distinction remains important throughout: deciding that a square root exists modulo $p$ is not the same task as producing the root. A symbol answers the first question. A separate algorithm may be needed for the second.


\portrait{gauss}{Carl Friedrich Gauss (1777--1855). Portrait by Christian Albrecht Jensen, 1840. Public domain, via Wikimedia Commons.}

\begin{reminder}[Three questions, in the right order]
First: is a non-zero class a square? Euler's criterion answers by a modular
power. Second: how can we decide faster, or see the pattern as the prime
changes? Reciprocity replaces one prime by a smaller remainder. Third: if a
square root exists, how do we find it? That is a separate problem; a Legendre
symbol answers yes or no and does not hand over the root. We will keep these
questions apart, then connect them in a worked example.

The first count is a bridge from Volume~1's pairing arguments and
polynomial root bound. For an odd prime $p$, pair each nonzero class $x$
with $-x$: the two classes are distinct and have equal squares.
Conversely, $x^2\equiv y^2\pmod p$ forces
$(x-y)(x+y)\equiv0\pmod p$, hence $y\equiv\pm x$.
There are therefore exactly $(p-1)/2$ nonzero squares.
The modular arithmetic was established earlier in this volume;
reciprocity is not needed for the count.
\end{reminder}

\noindent\emph{What carries forward.} Primitive roots give a coordinate for the nonzero residues modulo an odd prime: every unit is a power of one generator. Its exponent shows immediately whether the unit is a square. Here we compress that information into the Legendre symbol, then prove the surprising rule that compares the symbols for two different primes.

\section{Quadratic residues and Euler's criterion}

% t1-pass2 motive 40c9ee6d
Start with the squares modulo $11$. Squaring $1,2,3,4,5$ gives $1,4,9,5,3$; the negatives give no new squares. So exactly five nonzero classes are squares. Euler's criterion turns that short list into a test that works for any odd prime $p$: one modular exponent tells us whether a nonzero class is a square. Before using it, pair the nonzero inputs $x$ and $-x$ and check why the two members have the same square.

Let $p$ be an odd prime. An integer $a$ with $p\nmid a$ is a \emph{quadratic residue} modulo $p$ if $x^2\equiv a\pmod p$ has a solution, and a \emph{non-residue} otherwise.

\begin{definition}
The \emph{Legendre symbol} is $\left(\frac ap\right)=1$ if $a$ is a quadratic residue, $-1$ if it is a non-residue, and $0$ if $p\mid a$.
\end{definition}

\begin{think}
List the squares modulo $11$: how many distinct non-zero classes do you get? Then compute $a^5\bmod11$ for $a=1,\dots,10$. Which values occur, and which $a$ give which value? Make a conjecture before reading the theorem.
\end{think}

\begin{theorem}[Euler's criterion]\label{thm:eulercrit}
For an odd prime $p$ and integer $a$,
$\left(\dfrac ap\right)\equiv a^{(p-1)/2}\pmod p$. Consequently the symbol is completely multiplicative in $a$, among the nonzero classes there are exactly $\frac{p-1}2$ quadratic residues and $\frac{p-1}2$ non-residues, and
\[
\left(\frac{-1}p\right)=(-1)^{(p-1)/2}:
\]
$-1$ is a square modulo $p$ if and only if $p\equiv1\pmod4$.
\end{theorem}
\begin{proof}
Assume first that $p\nmid a$.
Let $g$ be a primitive root modulo $p$,
whose existence was proved in
Chapter~\ref{ch:orders}. Since $g$ generates
all nonzero classes, write
$a\equiv g^i\pmod p$ with $0\le i<p-1$.

A class $g^i$ is a square precisely when
$i$ is even. If $i=2j$, then $g^j$
is a square root. Conversely, if
$g^i=(g^j)^2$, the exponents agree
modulo the even integer $p-1$, so
$i$ must be even. Exactly half of the
exponents $0,\ldots,p-2$ are even,
giving $(p-1)/2$ nonzero squares
and the same number of non-squares.

Now put $h=g^{(p-1)/2}$.
Its square is $g^{p-1}=1$, but $h\ne1$
because $g$ has order $p-1$.
Over the field $\Z/p\Z$, the equation
$X^2=1$ has only the roots $1$ and $-1$,
so $h=-1$. Consequently
\[
a^{(p-1)/2}\equiv h^i=(-1)^i\pmod p.
\]
This is $1$ when $a$ is a square and
$-1$ otherwise: Euler's criterion.
If $p\mid a$, both sides are $0$,
since $(p-1)/2$ is positive.

For any integers $a,b$, apply the criterion
to the product $ab$:
\[
\left(\frac{ab}{p}\right)
\equiv
\left(\frac ap\right)\left(\frac bp\right)
\pmod p.
\]
When neither symbol vanishes,
both sides are among $\{-1,1\}$.
These have distinct residue classes
because $p$ is odd, so the congruence
is an equality of the displayed integers.
If a symbol is zero, both sides are zero.
Thus the Legendre symbol is completely
multiplicative. Taking $a=-1$ in Euler's
criterion gives the stated supplementary
law and the condition $p\equiv1\pmod4$.
\end{proof}

% t1-pass2 why
\paragraph{Why this works.}
Every nonzero class modulo $p$ is a power of a primitive root $g$. Squaring doubles the exponent, so the squares are exactly the even powers. The power $a^{(p-1)/2}$ is $1$ on those classes and $-1$ on the others. That is Euler's criterion. Setting $a=-1$ gives the extra sign test. You can see all the pieces from the cycle of powers; the proof makes the cycle argument work for every odd prime.

\paragraph{Why exactly two roots?}
If $x^2\equiv y^2\pmod p$, then $p\mid(x-y)(x+y)$, so $x\equiv y$ or
$x\equiv-y$. Thus each non-zero square has exactly two roots, a pair
$\{x,-x\}$. There is no overlap inside such a pair because $p$ is odd and
$x\ne0$. The $p-1$ units therefore produce $(p-1)/2$ squares. This also
explains why zero is excluded from the word ``residue'' here: it has only one
root and the Legendre symbol treats it separately.

Modulo $11$, squaring $1,2,3,4,5$ gives $1,4,9,5,3$. The five non-zero
residues are therefore $1,3,4,5,9$. A compact experiment already displays the
criterion: $3^5\equiv1$, but $2^5=32\equiv-1$ modulo $11$.
Multiplying two non-residues gives a residue, since $(-1)(-1)=1$ at the level
of symbols. Addition has no such rule: $1$ and $3$ are residues but their sum
$4$ is too, while $1+1=2$ is a non-residue. The symbol records multiplication; these examples show why it gives no rule for addition.

\subsection*{A first character, and its cancellation}
The Legendre symbol already behaves like a little numerical signal: it is periodic modulo $p$, it is zero exactly on multiples of $p$, and it multiplies when its arguments multiply. These properties mean we can sum it over a complete residue system and expect cancellation. Try the sum for $p=7$: among the six nonzero classes there are three squares and three non-squares, so the signs add to zero. The characters chapter will turn this example into a general way to detect residue classes.

Write $\chi(a)=\left(\frac ap\right)$. Its sum over a full residue system is zero. One proof counts the equally
numerous signs. Another exposes a useful mechanism: choose a non-residue $b$.
Multiplication by $b$ permutes the residues, so
\[
S:=\sum_{a=0}^{p-1}\chi(a)
=\sum_{a=0}^{p-1}\chi(ba)=\chi(b)S=-S,
\]
whence $S=0$. The cancellation is exact although the individual signs may
look irregular. It will let us calculate an expectation in
Exercise~\ref{ex:t1-residue-chance} without assuming independent signs.

The squares of $0,1,2,3,4,5$ modulo $11$ are $0,1,4,9,5,3$.
The nonzero residues are therefore $1,3,4,5,9$, and the non-residues are $2,6,7,8,10$.
Figure~\ref{fig:t1-residues} is that list as a strip. In particular $\bigl(\frac{2}{11}\bigr)=-1$, and $11\equiv 3\pmod 8$.
\end{examplex}

Here $(p-1)/2=6$. Modulo $13$, $3^2=9$, $3^6=729$. Since $13\cdot 56=728$, one has $3^6\equiv 1$, so $3$ is a residue (indeed $4^2=16\equiv 3$). On the other hand $2^6=64\equiv 12\equiv -1$, so $2$ is a non-residue. The criterion sees the answer without listing every square.
\end{examplex}

\section{Gauss' lemma}

% t1-pass2 motive 92c448dd
A large modular power can answer a yes-or-no question, but it does not explain the answer very well. Gauss replaces the power by a count. Multiply $1,2,\ldots,(p-1)/2$ by a chosen residue $a$ and reduce each product to a signed representative between $-(p-1)/2$ and $(p-1)/2$. The parity of the negative representatives is the Legendre symbol. The proof is a carefully organised product in which every unwanted factor cancels legally.

\begin{theorem}[Gauss' lemma]\label{thm:gausslemma}
Let $p$ be an odd prime and $a\in\Z$ with $p\nmid a$, and for $1\le k\le\frac{p-1}2$ let $r_k$ be the residue of $ka$ in $\left]-\frac p2,\frac p2\right[$. If $\mu$ is the number of negative $r_k$, then $\left(\frac ap\right)=(-1)^\mu$.
\end{theorem}
\begin{proof}
The $|r_k|$ lie in $\{1,\dots,\frac{p-1}2\}$ and are distinct: $ka\equiv\pm la$ implies $k\equiv\pm l$, so $k=l$ in this range. So they are a permutation of $1,\dots,\frac{p-1}2$. Multiplying all the $ka$:
$a^{(p-1)/2}\left(\frac{p-1}2\right)!\equiv\prod_kr_k=(-1)^\mu\left(\frac{p-1}2\right)!\pmod p$. Cancel the factorial and apply Euler's criterion.
\end{proof}

% t1-pass2 why
\paragraph{Why this works.}
Take the numbers $a,2a,\ldots,\frac{p-1}{2}a$ and reduce them to signed representatives of small absolute value. Ignoring signs, each absolute value occurs exactly once, so their product is the same as the original product $1\cdot2\cdots\frac{p-1}{2}$. Every negative representative contributes a minus sign. Because the factorial is invertible modulo $p$, we may cancel it. The remaining sign is the Legendre symbol.

\paragraph{A signed permutation, seen explicitly.}
Take $p=11$ and $a=3$. Reduce $3,6,9,12,15$ to the symmetric interval
$(-11/2,11/2)$; the representatives are
\[
 3,-5,-2,1,4.
\]
Their absolute values are a permutation of $1,2,3,4,5$, and there are two
minus signs. Hence $\left(\frac3{11}\right)=1$, agreeing with
$5^2\equiv3\pmod{11}$. For $a=2$, the representatives
$2,4,-5,-3,-1$ have three minus signs, so
$\left(\frac2{11}\right)=-1$.

The key cancellation in the proof is legal because none of
$1,\dots,(p-1)/2$ is divisible by $p$; the factorial is a unit.
To justify the distinctness carefully, $k\equiv-l\pmod p$ would require
$k+l=p$, impossible since $2\le k+l\le p-1$.
Gauss has turned a question about a square root into the parity of a count.
We count signs, not the size of the representatives.

\begin{corollary}\label{cor:two}
For every odd prime $p$,
$\left(\dfrac2p\right)=(-1)^{(p^2-1)/8}$: $2$ is a square modulo $p$ if and only if $p\equiv\pm1\pmod8$.
\end{corollary}
\begin{proof}
For $a=2$, the numbers $2k$ with $1\le k\le\frac{p-1}2$ lie in $[2,p-1]$, and $r_k<0$ exactly when $2k>\frac p2$. So $\mu=\frac{p-1}2-\left\lfloor\frac p4\right\rfloor$. Checking $p=8m+1,3,5,7$ gives $\mu=2m,2m+1,2m+1,2m+2$, whose parity is that of $\frac{p^2-1}8$.
\end{proof}

% t1-pass2 why
\paragraph{Why this works.}
For the symbol of $2$, Gauss's lemma turns the problem into counting which of $2,4,\ldots,p-1$ are represented with a minus sign. Their location relative to $p/2$ makes the count elementary. The answer depends only on the odd prime's residue modulo $8$, producing the exponent $(p^2-1)/8$. This is a parity statement, so we need the count only modulo $2$, not its full numerical value.

% t1-pass2 examples 92c448dd
\begin{examplex}[Gauss's count for $a=3$, $p=13$]
The products $3,6,9,12,15,18$ reduced into $(-13/2,13/2)$ are $3,6,-4,-1,2,5$.
Exactly two are negative, so $\bigl(\frac{3}{13}\bigr)=(-1)^2=1$.
And $6^2=36\equiv 10$, while $4^2=16\equiv 3$, which confirms the plus sign.
\end{examplex}

\begin{examplex}[the supplementary law at $p=17$ and $p=13$]
For $p=17\equiv 1\pmod 8$, $(p^2-1)/8=36$ is even, so $\bigl(\frac{2}{17}\bigr)=1$. Indeed $6^2=36\equiv 2$.
For $p=13\equiv 5\pmod 8$, $(169-1)/8=21$ is odd, so the symbol is $-1$, in agreement with $2^6\equiv -1$ above.
\end{examplex}

\section{The law of quadratic reciprocity}

% t1-pass2 motive ae6152e8
For distinct odd primes $p$ and $q$, compare the question whether $p$ is a square modulo $q$ with the question whether $q$ is a square modulo $p$. Their answers agree unless both primes are $3$ modulo $4$, in which case they disagree. This simple sentence hides the book's central surprise. The proof draws a rectangle of lattice points and counts it twice. Neither count alone gives reciprocity; matching them exposes the sign.

\begin{think}
Make a table: for the primes $p,q\in\{3,5,7,11,13\}$, $p\ne q$, record whether $p$ is a square modulo $q$. Now compare the entry for $(p,q)$ with the entry for $(q,p)$. When are they equal, and when do they differ? Look at $p$ and $q$ modulo $4$.
\end{think}

\begin{theorem}[quadratic reciprocity; Gauss, 1796]\label{thm:qr}
For distinct odd primes $p$ and $q$,
\[
\left(\frac pq\right)\left(\frac qp\right)=(-1)^{\frac{p-1}2\cdot\frac{q-1}2}.
\]
That is, $\left(\frac pq\right)=\left(\frac qp\right)$ unless $p\equiv q\equiv3\pmod4$, in which case $\left(\frac pq\right)=-\left(\frac qp\right)$.
\end{theorem}

\centering
\fig{ch06-reciprocity-table}
\caption{Each cell records $\left(\frac pq\right)$: row prime $p$, column
prime $q$. A plus means a non-zero square, a minus a non-square, and $0$
on the diagonal records divisibility. Compare cells reflected across the
diagonal: they disagree exactly when both primes are $3$ modulo $4$.
Signs carry the information even in black-and-white print.}
\label{fig:reciprocitytable}
\end{figure}

We give Eisenstein's proof, which counts lattice points. A second proof, with Gauss sums, is Exercise~\ref{ex:gausssum}.

\begin{lemma}[Eisenstein]\label{lem:eisenstein}
For an odd prime $p$ and an odd integer $a$ with $p\nmid a$, $\left(\dfrac ap\right)=(-1)^{T(a,p)}$ where $T(a,p)=\displaystyle\sum_{k=1}^{(p-1)/2}\left\lfloor\frac{ka}p\right\rfloor$.
\end{lemma}
\begin{proof}
Write $ka=p\left\lfloor\frac{ka}p\right\rfloor+s_k$ with $0<s_k<p$. Let $A$ be the sum of the $s_k<\frac p2$ and $B$ the sum of the $\mu$ values $s_k>\frac p2$. In the proof of Gauss' lemma, the numbers $s_k$ ($s_k<\frac p2$) and $p-s_k$ ($s_k>\frac p2$) are $1,\dots,\frac{p-1}2$ in some order. Let $S=\sum_{k=1}^{(p-1)/2}k=\frac{p^2-1}8$. Then
\[
aS=p\,T(a,p)+A+B,\qquad S=A+\mu p-B.
\]
Subtracting, $(a-1)S=p\left(T(a,p)-\mu\right)+2B$. Modulo $2$, with $a$ and $p$ odd: $0\equiv T(a,p)-\mu$. Conclude with Gauss' lemma.
\end{proof}

% t1-pass2 why
\paragraph{Why this works.}
Eisenstein's floor-sum version of Gauss's lemma needs an odd multiplier $a$. Under that hypothesis, the number of minus signs and the floor sum differ by an even integer, so raising $-1$ to either count gives the same result. That is why the floor formula can replace the sign count without changing the Legendre symbol. Try $a=2$ before forgetting the hypothesis: the convenient formula can give the wrong sign there.

The $3\times5=15$ lattice points of the rectangle are split by the diagonal $y=\frac{11}7x$, which passes through none of them, into $T(11,7)=8$ and $T(7,11)=7$. So $\left(\frac{11}7\right)\left(\frac7{11}\right)=(-1)^{15}=-1$: indeed $11\equiv2^2$ is a square modulo $7$, but $7$ is not a square modulo $11$.}

\begin{think}
Before reading the proof, look at Figure~\ref{fig:eisenstein}. Count the points below the diagonal column by column, and those above it row by row. What do you get, and why does Eisenstein's lemma turn this picture into reciprocity?
\end{think}

\begin{proof}[Proof of Theorem~\ref{thm:qr}]
Count the points $(x,y)\in\Z^2$ with $1\le x\le\frac{p-1}2$ and $1\le y\le\frac{q-1}2$: there are $\frac{p-1}2\cdot\frac{q-1}2$. None lies on the line $qx=py$ (it would force $p\mid x$). Below the line ($y<\frac{qx}p$; note $\frac{qx}p<\frac q2$, so the bound $y\le\frac{q-1}2$ is automatic there) there are $\sum_x\left\lfloor\frac{qx}p\right\rfloor=T(q,p)$ points, and above it, symmetrically, $T(p,q)$. So $T(q,p)+T(p,q)=\frac{p-1}2\cdot\frac{q-1}2$, and Eisenstein's lemma gives the theorem.
\end{proof}

% t1-pass2 why
\paragraph{Why this works.}
The rectangle contains $(p-1)(q-1)/4$ lattice points with positive integer coordinates. A point cannot lie on the dividing diagonal, because that would force a nonzero multiple of one distinct prime to equal a suitable multiple of the other inside their allowed ranges. So every point lies on exactly one side. Count the two sides using the floor sums from Eisenstein's lemma. Their total is the rectangle's area in lattice-point units, and their parities give the reciprocity sign.

\paragraph{Why Eisenstein assumes that $a$ is odd.}
His proof ends by discarding $(a-1)S$ modulo $2$; this is even when $a$ is
odd. That assumption cannot simply be dropped. For $a=2,p=3$, the floor sum
is $\lfloor2/3\rfloor=0$, predicting a plus sign, whereas $2$ is not a square
modulo $3$. We handle factors of $2$ with the supplementary law, then apply
reciprocity only to odd numbers. Every hypothesis is doing a job.

\begin{example}
$383$ is prime and $219=3\cdot73$. Since $383\equiv3\pmod4$ and $3\equiv3\pmod4$: $\left(\frac3{383}\right)=-\left(\frac{383}3\right)=-\left(\frac23\right)=1$. Since $73\equiv1\pmod4$: $\left(\frac{73}{383}\right)=\left(\frac{383}{73}\right)=\left(\frac{18}{73}\right)=\left(\frac2{73}\right)\left(\frac9{73}\right)=1$ as $73\equiv1\pmod8$. So $\left(\frac{219}{383}\right)=1$.
\end{example}

\paragraph{A complete calculation, including the root.}
The previous example gives an existence decision. As a short alternative,
$18=2\cdot3^2$ modulo $73$, and $73\equiv1\pmod8$, so the only non-trivial
signs are already resolved by small remainders. What about producing a square
root of $219$ modulo $383$?

For a prime $p\equiv3\pmod4$ and a non-zero residue $a$, set
$r=a^{(p+1)/4}$. Then Euler's criterion gives
\[
 r^2=a^{(p+1)/2}=a\,a^{(p-1)/2}\equiv a\pmod p.
\]
Here $(383+1)/4=96$. Repeated squaring gives
\[
\begin{gathered}
219^2\equiv86,\quad219^4\equiv119,\quad219^8\equiv373,\\
219^{16}\equiv100,\quad219^{32}\equiv42,\quad219^{64}\equiv232
\pmod{383}.
\end{gathered}
\]
Thus $219^{96}\equiv232\cdot42\equiv169$ and the two roots are $169$ and
$383-169=214$. A final check is pleasantly short:
$169^2=28561=383\cdot74+219$. Existence, construction, verification:
each step has its own proof. The exponent formula is specific to
$p\equiv3\pmod4$; other primes require different methods.

% t1-pass2 examples ae6152e8


\begin{examplex}[the sign really flips]
Take $p=3$ and $q=7$, both $3$ modulo $4$. Then $\bigl(\frac{3}{7}\bigr)$ should be $-\bigl(\frac{7}{3}\bigr)$.
Squares modulo $7$ are $0,1,2,4$, so $3$ is a non-residue and the symbol is $-1$.
Modulo $3$, $7\equiv 1=1^2$, so $\bigl(\frac{7}{3}\bigr)=1$. The product of the symbols is $-1$, as the exponent $(3-1)/2\cdot(7-1)/2=3$ predicts.
\end{examplex}

\section{The Jacobi symbol}

% t1-pass2 motive d5918262
Reciprocity is most useful when it becomes a calculation. The Jacobi symbol extends the Legendre symbol's multiplication rules to odd composite denominators. This lets us reduce arguments by Euclid's algorithm without first factoring every large numerator. But the price is a new warning: Jacobi symbol $1$ does \emph{not} guarantee that a square root exists. We will compute an example where the test gives $1$ and the original congruence still has no solution.

For a positive odd integer $n=p_1\cdots p_r$ (primes with repetition), the \emph{Jacobi symbol} is $\left(\frac an\right)=\prod_i\left(\frac a{p_i}\right)$. It is multiplicative in $a$ (as each Legendre symbol is) and in $n$ (by definition). For $n=1$ the product is empty and the symbol is $1$, for every $a$.

\begin{proposition}\label{prop:jacobi}
For odd coprime $m,n>0$:
\[
\begin{gathered}\left(\frac{-1}n\right)=(-1)^{\frac{n-1}2},\qquad\left(\frac2n\right)=(-1)^{\frac{n^2-1}8},\qq\left(\frac mn\right)\left(\frac nm\right)=(-1)^{\frac{m-1}2\cdot\frac{n-1}2}.\end{gathered}
\]
\end{proposition}
\begin{proof}
For odd $a,b$: $\frac{ab-1}2-\frac{a-1}2-\frac{b-1}2=\frac{(a-1)(b-1)}2$ is even, and $\frac{a^2b^2-1}8-\frac{a^2-1}8-\frac{b^2-1}8=\frac{(a^2-1)(b^2-1)}8$ is even (each factor is divisible by $8$). So $u(n)=\frac{n-1}2$ and $v(n)=\frac{n^2-1}8$ are additive modulo $2$ over products of odd numbers. The first two formulas hold for primes (Theorem~\ref{thm:eulercrit}, Corollary~\ref{cor:two}), and both sides are multiplicative in $n$. For the third, with $m=\prod_iq_i$ and $n=\prod_jp_j$ (all distinct primes across the two lists, since $\gcd(m,n)=1$),
$\left(\frac mn\right)\left(\frac nm\right)=\prod_{i,j}\left(\frac{q_i}{p_j}\right)\left(\frac{p_j}{q_i}\right)=(-1)^{\sum_{i,j}u(q_i)u(p_j)}=(-1)^{u(m)u(n)}$, using Theorem~\ref{thm:qr} and additivity of $u$.
\end{proof}

% t1-pass2 why
\paragraph{Why this works.}
The Jacobi symbol is built by multiplying Legendre symbols over the prime factors of an odd denominator. The reciprocity signs multiply too, and their exponents obey simple parity identities. That is why the familiar formulas continue to hold for composite denominators. But do not carry over a conclusion the formulas no longer support: Jacobi symbol $1$ can result from two minus signs and does not certify a square root.

This gives a Euclid-like algorithm computing $\left(\frac an\right)$ \emph{without factoring}. Beware: $\left(\frac an\right)=1$ does not imply that $a$ is a square modulo a composite $n$ (e.g.\ $\left(\frac2{15}\right)=1$, but $2$ is not a square modulo $3$).

\paragraph{Computing a Jacobi symbol without factoring.}
Here is the algorithm behind the claim. Start with a positive odd denominator
$n$ and a sign $s=1$. At each stage reduce $a$ modulo $n$. If $a=0$, stop:
the answer is $0$ when $n>1$, and $s$ when $n=1$. If $a=1$, stop with
answer $s$. Otherwise remove every factor of $2$ from $a$, multiplying $s$
each time by $(-1)^{(n^2-1)/8}$. If this leaves $a=1$, stop with answer
$s$. The remaining $a>1$ is odd: swap $a$ and $n$, flipping $s$ when both
are $3$ modulo $4$, then repeat. After the reduction, the new denominator
is the old $a<n$, so the process terminates. The rule at $n=1$ is the
empty-product convention. The same reductions are Euclid's algorithm with
a few signs attached.
For non-coprime inputs, reciprocity still gives the required equality with
both symbols equal to $0$: an odd prime divides both numerator and denominator.
Removing factors of $2$ and taking Euclidean remainders preserve their gcd,
so this case ends at the zero rule with denominator greater than $1$.
This explains why the algorithm does not need a separate coprimality test.

For example, every swap in the following chain has positive sign because
at least one of its two odd numbers is $1$ modulo $4$:
\[
\begin{aligned}
\left(\frac{1001}{9907}\right)
 &=\left(\frac{898}{1001}\right)
 =\left(\frac{449}{1001}\right)\\
 &=\left(\frac{103}{449}\right)
 =\left(\frac{37}{103}\right)
 =\left(\frac{29}{37}\right)
 =\left(\frac8{29}\right)=-1.
\end{aligned}
\]
Here $\left(\frac2{1001}\right)=1$ because $1001\equiv1\pmod8$,
and $\left(\frac2{29}\right)=-1$ because $29\equiv5\pmod8$.
No factorisation of $9907$ was needed. A negative answer rules out a square;
a positive answer for a composite denominator need not certify one. The two
non-residues $2$ modulo $3$ and $2$ modulo $5$ give
$\left(\frac2{15}\right)=(-1)(-1)=1$, while $x^2\equiv2\pmod{15}$ has
no solution. A Jacobi symbol has forgotten some local information.

% t1-pass2 examples d5918262
\begin{examplex}[a composite denominator]
Compute $\bigl(\frac{2}{15}\bigr)=\bigl(\frac{2}{3}\bigr)\bigl(\frac{2}{5}\bigr)=(-1)\cdot(-1)=1$, since $3$ and $5$ are both $\pm 3$ modulo $8$.
Nevertheless $2$ is not a square modulo $15$: squares modulo $3$ are $0,1$, and $2\equiv -1$ is not among them. The Jacobi symbol has answered a different question.
\end{examplex}

\begin{examplex}[one Euclidean swap]
To compute $\bigl(\frac{19}{35}\bigr)$, reduce nothing yet: $19$ is already smaller than $35$, and both are $3$ modulo $4$, so the symbol equals $-\bigl(\frac{35}{19}\bigr)=-\bigl(\frac{16}{19}\bigr)$.
But $16=4^2$, so $\bigl(\frac{16}{19}\bigr)=1$ and the original symbol is $-1$.
No prime factor of $35$ was required.
\end{examplex}

\begin{beauty}
Where this leads. The Legendre symbol is the Dirichlet character Volume~6 uses for the primes in an arithmetic progression, and the supplementary laws are the characters modulo $4$ and $8$. Quadratic reciprocity is the abelian reciprocity law in its smallest case; Volume~13 rebuilds it as the splitting law in cyclotomic fields and then as class field theory. The algorithm that computes a Jacobi symbol without factoring is also the algorithm that evaluates those characters at a prime.
\end{beauty}

\subsection*{Proof workshop: let the small primes test the sign}

Compute $\left(\frac{43}{91}\right)$ without factoring $91$.
Both odd numbers are $3$ modulo $4$, so reciprocity first introduces a minus sign:
\[
\left(\frac{43}{91}\right)
=-\left(\frac{91}{43}\right)
=-\left(\frac5{43}\right)
=-\left(\frac{43}{5}\right)
=-\left(\frac35\right)=1.
\]
The second swap has positive sign because $5\equiv1\pmod4$.
The squares modulo $5$ are $0,1,4$, so the final symbol is $-1$.
Every reduction preserves the symbol with its accumulated sign.
The positive Jacobi value alone does not certify a root modulo the
composite denominator; the earlier $2/15$ example explains that distinction.

For comparison,
$\left(\frac{83}{101}\right)=\left(\frac{18}{83}\right)
=\left(\frac2{83}\right)=-1$:
the swap has positive sign, $18=2\cdot3^2$, and $83\equiv3\pmod8$.
This negative value rules out a square root modulo $101$.

\section{Exercises}

\begin{exercise}[$\star$]\label{ex:minus3}
Show that for a prime $p>3$, $-3$ is a square modulo $p$ if and only if $p\equiv1\pmod3$.
\end{exercise}

\begin{exercise}[$\star$]\label{ex:onemod4}
Show that every odd prime factor of $n^2+1$ is $\equiv1\pmod4$, and deduce that there are infinitely many primes $p\equiv1\pmod4$.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:minus2}
For an odd prime $p$, show that $\left(\frac{-2}p\right)=1$ if and only if $p\equiv1$ or $3\pmod8$. Deduce that a prime of the form $x^2+2y^2$, with integers $x,y$, is $2$ or $\equiv1,3\pmod8$.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:mersfactor}
Let $p\equiv3\pmod4$ be prime with $q=2p+1$ also prime. Show that $q\mid2^p-1$. Deduce that $2^{11}-1$, $2^{23}-1$ and $2^{251}-1$ are composite.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:consecutive}
Let $p$ be an odd prime. Show that $\displaystyle\sum_{a=1}^{p-1}\left(\frac{a(a+1)}p\right)=-1$. Deduce the number of $a\in\{1,\dots,p-2\}$ such that $a$ and $a+1$ are both quadratic residues.
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:pepin}
\emph{P\'epin's test.} Let $\mathcal F_n=2^{2^n}+1$ with $n\ge1$. Show that $\mathcal F_n$ is prime if and only if $3^{(\mathcal F_n-1)/2}\equiv-1\pmod{\mathcal F_n}$.
\end{exercise}

\begin{exercise}[$\star\star\star$]\label{ex:gausssum}
\emph{Advanced bridge: reciprocity through Gauss sums.} This second proof works in the ring $\Z[\zeta]$ and uses the prime-cyclotomic irreducibility exercise from Volume~1. It is optional; the reciprocity theorem has already been proved without these tools. Let $\zeta=e^{2i\pi/p}$, $p^*=\left(\frac{-1}p\right)p$, and $g=\sum_{a=1}^{p-1}\left(\frac ap\right)\zeta^a$.
\begin{enumerate}[label=(\alph*)]
\item Show that $g^2=p^*$. \emph{Hint: substitute $b=ac$ in $g^2=\sum_{a,b}\left(\frac{ab}p\right)\zeta^{a+b}$.}
\item Let $q\ne p$ be an odd prime. In the ring $\Z[\zeta]$, show that $g^q\equiv\left(\frac qp\right)g\pmod{q\Z[\zeta]}$.
\item Show that $q\Z[\zeta]\cap\Z=q\Z$, using that $\Phi_p$ is irreducible over $\Q$ (Volume~1, the polynomial exercise on prime cyclotomic irreducibility). Deduce $\left(\frac{p^*}q\right)=\left(\frac qp\right)$, and then Theorem~\ref{thm:qr}.
\item Show that $g=\sum_{x=0}^{p-1}\zeta^{x^2}$, the sum $G$ of Volume~1, the complex-number exercise on quadratic Gauss sums. What does (a) say about $G$?
\end{enumerate}
\end{exercise}

\begin{exercise}[$\star\star$]\label{ex:t1-residue-chance}
\emph{Residue signs and chance.} Choose $U$ uniformly from
$\{0,\dots,p-1\}$ for an odd prime $p$, and put
$X=\left(\frac Up\right)$, $Y=\left(\frac{U+1}p\right)$.
Find the distributions, expectations and variances of $X,Y$.
Using Exercise~\ref{ex:consecutive}, prove
$\operatorname{Cov}(X,Y)=-1/p$. Are the two signs independent?
\end{exercise}

\begin{exercise}[$\star$]\label{ex:t1-res11}
List the quadratic residues modulo $11$. Decide $\bigl(\frac{6}{13}\bigr)$ and $\bigl(\frac{6}{17}\bigr)$ by the supplementary laws and reciprocity, and check one of them by listing squares.
\end{exercise}

\begin{beauty}
Quadratic reciprocity links two questions that have no visible connection: whether $p$ is a square modulo $q$, and whether $q$ is a square modulo $p$. Many proofs are known, each exposing a different structure. Its generalisations (cubic and biquadratic reciprocity, which live in the rings of Chapter~\ref{ch:gaussian}, Artin reciprocity, and the Langlands program) have driven number theory for two centuries. It also powers the Solovay--Strassen primality test and the computation of square roots modulo $p$.
\end{beauty}

\begin{exercise}[$\star\star$]\label{pb:primsum}
Let $p$ be an odd prime.
\begin{enumerate}[label=(\alph*)]
\item Show that the sum of the primitive roots modulo $p$ in $\{1,\dots,p-1\}$ is congruent to $\mu(p-1)$ modulo $p$.
\item Show that their product is congruent to $1$ modulo $p$ when $p>3$.
\item More generally, for an integer $k\ge0$, show that the sum of the $k$-th powers of the primitive roots is congruent modulo $p$ to the
Ramanujan sum $c_{p-1}(k)$ of Problem~\ref{pb:ramsum}.
\end{enumerate}
\end{exercise}

\begin{exercise}[$\star\star$]\label{pb:phimodp}
\emph{Cyclotomic polynomials, reduced modulo a prime.}
In Chapter~\ref{ch:orders}, we met the cyclotomic polynomial
$\Phi_n$ through $X^n-1=\prod_{d\mid n}\Phi_d(X)$.
We can understand its factors modulo a prime with no theory
of field extensions borrowed from another volume.
\begin{enumerate}[label=(\alph*)]
\item Let $n\ge2$, let $p$ be a prime with $p\nmid n$,
and put $f=\operatorname{ord}_n(p)$.
For a monic irreducible $h\in\mathbb F_p[X]$ of degree $d$,
consider the polynomial remainders of degree less than $d$.
Add and multiply them, taking the remainder modulo $h$ each time.
Explain, using polynomial B\'ezout from Volume~1, why these
$p^d$ classes form a field: every nonzero class has an inverse.
Use this small field to show that $\Phi_n$ modulo $p$ is
a product of $\varphi(n)/f$ distinct irreducible factors,
each of degree $f$.
\item Show that $X^4+1$ is irreducible over $\Q$
but is reducible modulo \emph{every} prime.
\item Let $n=p^am$, where $a\ge1$ and $p\nmid m$.
Show that
$\Phi_n(X)\equiv\Phi_m(X)^{\varphi(p^a)}\pmod p$.
\end{enumerate}
\end{exercise}

\begin{exercise}[$\star\star$]\label{pb:fermatnum}
Let $F_n=2^{2^n}+1$ be the Fermat numbers.
\begin{enumerate}[label=(\alph*)]
\item Show that every prime factor of $F_n$, $n\ge2$, is congruent to $1$ modulo $2^{n+2}$.
\item Show that $641$ divides $F_5$, without dividing, using $641=5\cdot2^7+1=5^4+2^4$.
\item Show that two distinct Fermat numbers are coprime, and deduce that there are infinitely many primes.
\end{enumerate}
\end{exercise}

\begin{exercise}[$\star\star$]\label{pb:carmichael}
A composite $n$ is a \emph{Carmichael number} if $a^{n-1}\equiv1\pmod n$ for every $a$ prime to $n$.
\begin{enumerate}[label=(\alph*)]
\item Show that a Carmichael number is odd, squarefree, and that $p-1\mid n-1$ for every prime $p\mid n$.
\item Show that a Carmichael number has at least three prime factors.
\item For a positive integer $k$, show that if $6k+1$, $12k+1$ and $18k+1$ are all prime, their product is a Carmichael number. Find the smallest
example in this family.
\end{enumerate}
\end{exercise}

\begin{exercise}[$\star\star$]\label{pb:pratt}
\begin{enumerate}[label=(\alph*)]
\item Show that $n\ge3$ is prime if and only if there is an $a$ with $a^{n-1}\equiv1\pmod n$ and $a^{(n-1)/q}\not\equiv1\pmod n$
for every prime $q\mid n-1$.
\item A \emph{certificate} for an odd prime $p$ is such an $a$, the factorisation of $p-1$, and a certificate for each odd
prime factor of $p-1$, and so on down. Let $f(p)$ be the number of primes in the whole tree, with $f(2)=1$ and
$f(p)=1+\sum_{q\mid p-1}f(q)$, the sum over the distinct primes $q$. Show that $f(p)\le2\log_2p-1$ for every odd prime $p$.
\item Deduce that a prime of $k$ binary digits has a certificate that can be checked with a number of operations on
$k$-digit numbers bounded by a polynomial in $k$.
\end{enumerate}
\end{exercise}

\begin{exercise}[Journey]\label{pb:rabin}
\emph{Optional advanced journey.} This exact strong-liar count uses the
cyclic group structures proved in Chapter~\ref{ch:orders} and a lengthy
Chinese-remainder argument. It is not needed for the reciprocity proofs.
\emph{The Miller--Rabin test lies at most one time in four.} Let $n$ be an odd composite number, $n-1=2^sd$ with $d$ odd.
An $a$ prime to $n$ is a \emph{strong liar} if $a^d\equiv1\pmod n$ or $a^{2^jd}\equiv-1\pmod n$ for some $0\le j<s$. Write
$n=\prod_{i=1}^rp_i^{e_i}$ and $p_i-1=2^{\nu_i}m_i$ with $m_i$ odd, and let $\nu=\min_i\nu_i$.
\begin{enumerate}[label=(\alph*)]
\item In a cyclic group $C$ of even order $m$, with $-1$ its element of order $2$, show that $x^t=1$ has $\gcd(t,m)$
solutions and $x^t=-1$ has $\gcd(2t,m)-\gcd(t,m)$ solutions.
\item (Monier) Show that the number of strong liars is
\[
\prod_{i=1}^r\gcd(d,m_i)\cdot\Bigl(1+\frac{2^{r\nu}-1}{2^r-1}\Bigr).
\]
\item Deduce that at most $\frac14\varphi(n)$ of the units are strong liars, unless $n=9$. Check that $15$ attains $\frac14$.
\end{enumerate}
\end{exercise}



\begin{exercise}[$\star\star$]\label{pb:squaresmodpk}
\emph{Optional advanced return.} Parts (a)--(b) use the classification
of unit groups modulo prime powers from Chapter~\ref{ch:orders}.
The local--global question in part (c) goes beyond the first route
and foreshadows the later $p$-adic study in Volume~13.
\emph{Squares modulo $p^k$.} For integers $k\ge1$ and $m\ge1$, let $S(m)$ be the number of squares in $\Z/m\Z$ ($0$ included).
\begin{enumerate}[label=(\alph*)]
\item For an odd prime $p$, show that $S(p^k)=1+\sum_{0\le j<k/2}\frac{p-1}2p^{k-2j-1}$, and that $S(p^k)/p^k\to\frac p{2(p+1)}$.
\item Show that $S(2^k)/2^k\to\frac16$.
\item Show that $S$ is multiplicative, and deduce that the proportion of squares modulo $m$ can be made as small as we like.
What does this say about an integer that is a square modulo every $m$?
\end{enumerate}
\end{exercise}

\begin{exercise}[Journey]\label{pb:eisensine}
\emph{Eisenstein's trigonometric proof of quadratic reciprocity.}
We proved reciprocity by counting lattice points. Now try a different
route: the sine function and Gauss's lemma.
\begin{enumerate}[label=(\alph*)]
\item Let $q\ge1$ be an odd integer. Show that for every real $x$ that is not a multiple of $\pi$,
\[
\frac{\sin qx}{\sin x}=(-4)^{(q-1)/2}\prod_{k=1}^{(q-1)/2}\Bigl(\sin^2x-\sin^2\frac{2\pi k}q\Bigr).
\]
\item Let $p$ be an odd prime and $q$ an integer prime to $p$. Show that
\[
\Bigl(\frac qp\Bigr)=\prod_{j=1}^{(p-1)/2}\frac{\sin(2\pi qj/p)}{\sin(2\pi j/p)}.
\]
\item Deduce the law of quadratic reciprocity: for distinct odd primes $p$ and $q$,
$\bigl(\frac qp\bigr)\bigl(\frac pq\bigr)=(-1)^{\frac{p-1}2\frac{q-1}2}$.
\end{enumerate}
\end{exercise}

\begin{exercise}[$\star\star$]\label{pb:euler}
\emph{The Euler--Jacobi primality test.}
Compare the Jacobi-symbol test below with the Fermat test in
Problem~\ref{pb:carmichael}.
Let $n\ge3$ be an odd integer. Call $a$ an \emph{Euler liar} for $n$ if $\gcd(a,n)=1$ and $a^{(n-1)/2}\equiv\bigl(\frac an\bigr)\pmod n$, where
$\bigl(\frac an\bigr)$ is the Jacobi symbol.
\begin{enumerate}[label=(\alph*)]
\item Show that the Euler liars form a subgroup of $(\Z/n\Z)^*$.
\item Show that if $n$ is composite, this subgroup is proper, so that at most half of the units are Euler liars. In
particular, no odd composite number fools this test for all bases, unlike Problem~\ref{pb:carmichael}.
\end{enumerate}
\end{exercise}

\begin{exercise}[$\star\star$]\label{pb:sumsquares}
\emph{How evenly are sums of squares distributed?}
Let $p$ be an odd prime. In $\mathbb F_p$ (the residue classes modulo $p$),
write $\eta(t)=\left(\frac tp\right)$, with $\eta(0)=0$.
For $n\ge1$, let $N_n(c)$ be the number of
$(x_1,\ldots,x_n)\in\mathbb F_p^n$ such that
$x_1^2+\cdots+x_n^2=c$.
\begin{enumerate}[label=(\alph*)]
\item Show that, for $c\ne0$,
\[
N_n(c)=\begin{cases}
p^{n-1}-p^{n/2-1}\eta((-1)^{n/2}),&n\text{ even},\\[2pt]
p^{n-1}+p^{(n-1)/2}\eta((-1)^{(n-1)/2}c),&n\text{ odd}.
\end{cases}
\]
Find $N_n(0)$ too.
\item Pick the $x_i$ independently and uniformly from $\mathbb F_p$.
Define the \emph{total-variation distance} of the sum
$S=x_1^2+\cdots+x_n^2$ from the uniform distribution by
\[
d=\frac12\sum_{c\in\mathbb F_p}
\left|\Pr(S=c)-\frac1p\right|.
\]
Prove that
\[
d=\begin{cases}
(1-1/p)p^{-n/2},&n\text{ even},\\[2pt]
\frac{p-1}{2}p^{-(n+1)/2},&n\text{ odd}.
\end{cases}
\]
\end{enumerate}
\end{exercise}

\begin{solution}{ex:minus3}
\idea Separate the number $-3$ into $(-1)\cdot3$. Multiplicativity turns its Legendre symbol into two simpler symbols. Euler's criterion handles $-1$; quadratic reciprocity handles $3$. Keep the signs written out instead of trying to memorise the answer. They cancel, leaving a symbol modulo $3$, where there are only two possible nonzero classes to examine.
\writeup For an odd prime $p\ne3$, multiplicativity gives
\[
\left(\frac{-3}p\right)=\left(\frac{-1}p\right)\left(\frac3p\right).
\]
The supplementary law makes the first factor $(-1)^{(p-1)/2}$. Quadratic reciprocity with $3$ makes the second $(-1)^{(p-1)/2}\bigl(\frac p3\bigr)$. The two signs cancel, so
$\bigl(\frac{-3}p\bigr)=\bigl(\frac p3\bigr)$. The only nonzero square modulo $3$ is $1$. Therefore $-3$ is a quadratic residue modulo $p$ precisely when $p\equiv1\pmod3$.

There is also a direct link to Chapter~\ref{ch:orders}. Because $2$ is invertible modulo $p$, a square root $r$ of $-3$ gives a root $t=(r-1)/2$ of $t^2+t+1=0$, and conversely $(2t+1)^2=-3$ for any such root. Since $p>3$, this root is not $1$, while $(t-1)(t^2+t+1)=t^3-1$; it has order $3$. Such an element exists exactly when $3\mid p-1$, by the cyclicity of $(\Z/p\Z)^\times$.
\end{solution}

\begin{solution}{ex:onemod4}
\idea The statement $p\mid n^2+1$ says that $n^2\equiv-1\pmod p$. For an odd prime, Euler's criterion tells us when that is possible: $p$ must be $1$ modulo $4$. For infinitude, adapt Euclid's method. Suppose you have listed every prime in that class; choose an even multiple $n$ of their product and factor $n^2+1$. The number is odd, and every odd prime factor lies in the desired class. None can be on the list because every listed prime divides $n$ but not $n^2+1$.
\writeup If an odd prime $p$ divides $n^2+1$, then $n^2\equiv-1\pmod p$, so $-1$ is a square modulo $p$. Euler's criterion forces $p\equiv1\pmod4$.

Suppose only finitely many primes have this form, say $p_1,\ldots,p_k$. Put $m=2p_1\cdots p_k$ and $N=m^2+1$. This is an odd integer greater than $1$ and has an odd prime divisor $q$. The first paragraph gives $q\equiv1\pmod4$. But for every listed $p_i$, $N\equiv1\pmod{p_i}$, so none divides $N$. The new prime $q$ contradicts the supposedly complete list. Infinitely many primes are congruent to $1$ modulo $4$.
\end{solution}

\begin{solution}{ex:minus2}
\idea The supplementary laws already tell us the values of the symbols for $-1$ and $2$. Multiply them and make a table of the four odd residue classes modulo $8$. That table answers when $-2$ is a square modulo $p$. For the representation claim, start with $p=x^2+2y^2$. You must show $y$ is invertible modulo $p$ before dividing by $y^2$; otherwise the square-root conclusion has a gap.
\writeup Use multiplicativity and the supplementary laws:
\[
\left(\frac{-2}p\right)
=(-1)^{(p-1)/2}(-1)^{(p^2-1)/8}.
\]
For odd primes congruent to $1,3,5,7$ modulo $8$, the sign pairs are $(+,+),(-,-),(+,-),(-,+)$. Their products are positive only for $p\equiv1,3\pmod8$.

\begin{solution}{ex:consecutive}
\idea Sums of Legendre symbols often simplify after you change variables. For a nonzero $a$, write $\chi(a(a+1))=\chi(1+a^{-1})$, since the factor $a^2$ is a square. The inversion map permutes the nonzero classes, so the sum becomes one you can count directly. For the pair count, use the indicator $(1+\chi(a))/2$ for a nonzero square and expand its product with the neighbouring indicator. Check boundary values where a factor vanishes.
\writeup Write $\chi(a)=\bigl(\frac ap\bigr)$. For nonzero $a$, the square factor $a^2$ does not change the symbol:
\[
\chi(a(a+1))=\chi(a^2(1+a^{-1}))=\chi(1+a^{-1}).
\]
As $a$ runs through the nonzero classes, $1+a^{-1}$ runs through all classes except $1$. The complete sum of $\chi$ is zero, hence
$\sum_{a=1}^{p-1}\chi(a(a+1))=-\chi(1)=-1$.

Now count pairs of consecutive nonzero squares. For $1\le a\le p-2$, their indicator is
$\frac14(1+\chi(a))(1+\chi(a+1))$. Expand and sum. The constant contribution is $p-2$, the two linear character sums contribute $-\chi(-1)$ and $-1$, and the quadratic product sum contributes $-1$. Thus
\[
N=\frac{p-4-\chi(-1)}4
=\begin{cases}
(p-5)/4,&p\equiv1\pmod4,\\
(p-3)/4,&p\equiv3\pmod4.
\end{cases}
\]
We restricted to nonzero pairs so the indicator formula has no exceptional endpoints.
\end{solution}

\begin{solution}{ex:pepin}
\idea If $\mathcal F_n$ is prime, Euler's criterion says $3^{(\mathcal F_n-1)/2}\equiv\left(\frac3{\mathcal F_n}\right)$, and reciprocity computes this symbol from $\mathcal F_n\bmod3$. For the converse, the congruence gives the exact order of $3$ (a power of $2$ whose half fails), and an element of order $\mathcal F_n-1$ forces $\varphi(\mathcal F_n)=\mathcal F_n-1$, i.e.\ primality. This is the template of Lucas-type primality proofs.
\writeup Assume $n\ge1$ and write $F_n=2^{2^n}+1$. If $F_n$ is prime, then $F_n\equiv1\pmod4$ and $F_n\equiv2\pmod3$. Reciprocity gives
\[
\left(\frac3{F_n}\right)=\left(\frac{F_n}3\right)=\left(\frac23\right)=-1.
\]
Euler's criterion therefore gives
$3^{(F_n-1)/2}\equiv-1\pmod{F_n}$.

Conversely suppose that congruence holds. The congruence $F_n\equiv2\pmod3$, valid for every $n\ge1$, makes $3$ a unit modulo $F_n$. Squaring gives $3^{F_n-1}\equiv1$, and the preceding power was not $1$. Since $F_n-1$ is a power of $2$, the order of $3$ modulo $F_n$ must be exactly $F_n-1$. But an element's order divides the number of units, so
\[
F_n-1\le\varphi(F_n)\le F_n-1.
\]
Equality holds. Every positive integer smaller than $F_n$ is therefore coprime to $F_n$, which means $F_n$ is prime. This is Pepin's exact primality criterion.
Equivalently, any prime factor $q$ of $F_n$ would inherit an element of order $F_n-1$ modulo $q$, forcing $F_n-1\mid q-1$. Thus $q\ge F_n$, so a proper prime factor cannot exist.
\end{solution}

\begin{solution}{ex:gausssum}
\idea The Gauss sum $g$ is an algebraic number whose square is $\pm p$, so it ``is'' $\sqrt{p^*}$ inside $\Z[\zeta]$. Then $\left(\frac{p^*}q\right)$, which by Euler's criterion is $(p^*)^{(q-1)/2}=g^{q-1}$ modulo $q$, can be computed in a second way: raising to the power $q$ modulo $q$ is additive (the Frobenius), and it permutes the $\zeta^a$, producing $\left(\frac qp\right)$. Comparing the two computations gives reciprocity. The only subtle point is to come back from congruences in $\Z[\zeta]$ to congruences in $\Z$, which needs the linear independence of the powers of $\zeta$.
\writeup
A Gauss sum turns a quadratic character into an exponential sum. The point of the calculation is not the expansion itself, but the one residue class that survives orthogonality. Once we know its square, the Frobenius congruence recovers the sign in quadratic reciprocity.

 (a) With $\chi=\left(\frac\cdot p\right)$,
\[
g^2=\sum_{a,b\ne0}\chi(ab)\zeta^{a+b}.
\] Put $b=ac$ ($c$ runs over non-zero residues for fixed $a$): $\chi(ab)=\chi(a^2c)=\chi(c)$, so
\[g^2=\sum_{c\ne0}\chi(c)\sum_{a\ne0}\zeta^{a(1+c)}.\]
The inner sum is $p-1$ if $c\equiv-1$ and $-1$ otherwise (Volume~1, the roots-of-unity orthogonality proposition). Hence
\[\begin{aligned}g^2&=\chi(-1)(p-1)-\sum_{c\ne0,-1}\chi(c)\eqbr=\chi(-1)(p-1)+\chi(-1)=\chi(-1)p=p^*,\end{aligned}\]
using $\sum_{c\ne0}\chi(c)=0$.

(b) In any commutative ring, $(x+y)^q\equiv x^q+y^q$ modulo $q$ (the binomial coefficients $\binom qj$, $0<j<q$, are multiples of $q$), and by induction for sums of several terms. So $g^q\equiv\sum_a\chi(a)^q\zeta^{aq}=\sum_a\chi(a)\zeta^{aq}$, as $\chi(a)^q=\chi(a)$ ($q$ odd). Substituting $b=aq$: $\chi(a)=\chi(bq^{-1})=\chi(q)\chi(b)$ (as $\chi(q^{-1})=\chi(q)$), so the sum is $\chi(q)g$.

(c) First, $q\Z[\zeta]\cap\Z=q\Z$. The numbers $1,\zeta,\dots,\zeta^{p-2}$ are linearly independent over $\Q$: a relation would give a non-zero $R\in\Q[X]$ of degree $\le p-2$ with $R(\zeta)=0$; then $\gcd(R,\Phi_p)$, which is a $\Q[X]$-combination of $R$ and $\Phi_p$ (B\'ezout in $\Q[X]$), also vanishes at $\zeta$, so it is a non-constant proper divisor of $\Phi_p$, contradicting the irreducibility of $\Phi_p$ (Volume~1, the polynomial exercise on prime cyclotomic irreducibility). Every element of $\Z[\zeta]$ is $\sum_{i\le p-2}c_i\zeta^i$ with $c_i\in\Z$ (reduce higher powers with $\zeta^{p-1}=-1-\zeta-\dots-\zeta^{p-2}$). If an integer $n$ equals $q\sum c_i\zeta^i$, uniqueness of coordinates gives $n=qc_0$.

Now multiply (b) by $g$: $g^{q+1}\equiv\chi(q)g^2$, that is $(p^*)^{(q+1)/2}\equiv\chi(q)p^*$ modulo $q\Z[\zeta]$. Both sides are integers, so the congruence holds modulo $q$ in $\Z$. As $p^*$ is invertible modulo $q$: $(p^*)^{(q-1)/2}\equiv\chi(q)\pmod q$, and by Euler's criterion the left side is $\left(\frac{p^*}q\right)$; both are $\pm1$ and $q>2$, so they are equal. Finally $\left(\frac{p^*}q\right)=\left(\frac{-1}q\right)^{\frac{p-1}2}\left(\frac pq\right)=(-1)^{\frac{q-1}2\cdot\frac{p-1}2}\left(\frac pq\right)$, which is Theorem~\ref{thm:qr}.

(d) The number of $x$ with $x^2\equiv a$ is $1+\chi(a)$ (two roots for a residue, none for a non-residue, one for $0$), so $\sum_x\zeta^{x^2}=\sum_a(1+\chi(a))\zeta^a=\sum_a\zeta^a+g=g$. So $G^2=p^*$: $G=\pm\sqrt p$ if $p\equiv1\pmod4$ and $\pm i\sqrt p$ if $p\equiv3\pmod4$, consistent with $|G|^2=p$. A numerical calculation suggests that the sign is always $+$; this is a much harder theorem of Gauss, proved in Volume~5 with Fourier analysis.
\end{solution}

\begin{solution}{ex:t1-residue-chance}
\idea Uniform sampling converts an exact finite character sum into an
expectation. Marginal balance does not imply independence: examine the
product, rather than guessing from a picture of the signs.
\writeup Let $\chi$ be the quadratic character. It vanishes only at the zero class, and takes each of the values $1$ and $-1$ at exactly $(p-1)/2$ nonzero classes. For uniform $a\in\mathbb F_p$, the random variables $X=\chi(a)$ and $Y=\chi(a+1)$ both have mean zero and variance $(p-1)/p$, because translating the input by $1$ permutes the sample space.

Their product is $\chi(a(a+1))$, so the character-sum identity in Exercise~\ref{ex:consecutive} gives
\[
\mathbb E[XY]=\frac1p\sum_{a\in\mathbb F_p}\chi(a(a+1))=-\frac1p.
\]
Since both means are zero, this is the covariance. Independent random variables with these means would have $\mathbb E[XY]=0$. The nonzero covariance therefore proves that consecutive Legendre symbols are not independent, despite their individually balanced signs.
\end{solution}

\begin{solution}{pb:primsum}
\idea Inside $\mathbb F_p$, a primitive root $\gamma$ plays the role of $e^{2i\pi/(p-1)}$: it has order exactly $p-1$, its
powers are all of $\mathbb F_p^*$, and the primitive roots are the $\gamma^a$ with $a$ prime to $p-1$. So the sum of their
$k$-th powers is a Ramanujan sum computed in $\mathbb F_p$, and the proof of Problem~\ref{pb:ramsum}(a) works word for word,
because it only used the geometric sum.

\writeup
A primitive root is a generator, not an arbitrary nonzero element. Label generators by exponents coprime to $p-1$, then replace the resulting restricted sum with a divisor sum by Möbius inversion. The same calculation gives the sum and every higher power sum.

 Put $m=p-1$ and choose a primitive root $\gamma$. Every primitive root is $\gamma^a$ for one exponent class $a$ coprime to $m$. Thus the $k$th-power sum over primitive roots is
\[
C_m(k)=\sum_{\substack{1\le a\le m\\(a,m)=1}}\gamma^{ak}.
\]
For each divisor $d$ of $m$, put $\gamma_d=\gamma^{m/d}$, of order $d$, and define $C_d(k)$ by the same formula. The complete geometric sum of the powers of $\gamma_d^k$ is $d$ if $d\mid k$ and zero otherwise. Partitioning its exponents by their gcd with $d$ gives
\[
\sum_{e\mid d}C_e(k)=d\,\mathbf1_{d\mid k}.
\]
Möbius inversion on the divisor lattice now yields
\[
C_m(k)=\sum_{d\mid\gcd(m,k)}d\,\mu(m/d)=c_m(k),
\]
which proves part (c).

Take $k=1$. Since $\gcd(m,1)=1$, the formula reduces to $\mu(m)$, proving part (a). For part (b), the inverse of a primitive root is again primitive. If $p>3$, every generator has order $m>2$, so no generator equals its own inverse. The primitive roots split into inverse pairs, each with product $1$. Their total product is therefore $1$.

\tools Volume~2 (primitive roots, Möbius inversion and Ramanujan sums).
\leads The first power sum is the Möbius function, while all higher powers recover the Ramanujan sums.
\end{solution}

\begin{solution}{pb:phimodp}
\idea We need roots of polynomials modulo $p$, but there is
no reason to import a whole chapter about finite fields.
We can build exactly the field we need out of polynomial
remainders, just as we built integers modulo a prime.
Once that is done, a simple count of roots tells us
how big each irreducible factor must be.

\writeup
\emph{(a) First build the field.}
Let $h\in\mathbb F_p[X]$ be monic and irreducible
of degree $d$. Every polynomial has a unique remainder
of degree less than $d$ on division by $h$.
We make these remainders into a number system by
adding and multiplying, then reducing modulo $h$.
There are exactly $p^d$ of them, one for every choice
of their $d$ coefficients.

Why may we divide by a nonzero remainder $A$?
Because $h$ is irreducible, $\gcd(A,h)=1$.
The polynomial B\'ezout identity, proved in Volume~1,
supplies polynomials $U,V$ with $UA+Vh=1$.
Reducing modulo $h$ gives $UA=1$, so $U$ is
an inverse for $A$. The usual arithmetic rules
survive reduction modulo $h$. This is a field
built directly from earlier polynomial arithmetic.
Write $K$ for it, and let $\alpha$ be the
remainder class of $X$.

Now take $h$ to be an irreducible factor of
$\Phi_n$ modulo $p$, with $n\ge2$ and $p\nmid n$.
The factorisation
$X^n-1=\prod_{e\mid n}\Phi_e(X)$ survives modulo $p$.
Its derivative is $nX^{n-1}$, which has no common
factor with $X^n-1$: $n$ is nonzero modulo $p$,
and $X$ does not divide $X^n-1$.
Hence $X^n-1$ has no repeated irreducible factor:
a repeated factor would divide the derivative as well.

In $K$ we have $\Phi_n(\alpha)=0$, hence
$\alpha^n=1$.
In fact $\alpha$ has order \emph{exactly} $n$.
If its order were a proper divisor $e$ of $n$,
then $h$ would divide $X^e-1$ and also $\Phi_n$.
But $X^e-1$ is a product of the earlier
$\Phi_r$ with $r\mid e$, and so $h$ would
occur twice in $X^n-1$, contradicting
the absence of repeated factors.

Put $d=\deg h$ and $f=\operatorname{ord}_n(p)$.
Every nonzero $\beta\in K$ satisfies
\[
\beta^{p^d-1}=1.                                      \tag{1}
\]
To see this without a group theorem, multiply
all $p^d-1$ nonzero classes. Multiplication by
$\beta$ permutes them; cancelling the product
gives (1). In particular $\alpha^{p^d}=\alpha$.
As $\alpha$ has order $n$, this says
$n\mid p^d-1$, so $f\mid d$.

For the reverse inequality, the definition of $f$
gives $n\mid p^f-1$, and therefore
$\alpha^{p^f}=\alpha$.
For elements of characteristic $p$, the binomial
theorem gives $(a+b)^p=a^p+b^p$: every middle
binomial coefficient is divisible by $p$.
Repeat this $f$ times. Since every element of
$K$ is a polynomial in $\alpha$ with coefficients
in $\mathbb F_p$, and each such coefficient
satisfies $a^{p^f}=a$, we obtain
\[
\beta^{p^f}=\beta\qquad\text{for every }\beta\in K.
\]
Thus the polynomial $T^{p^f}-T$ has all $p^d$
elements of $K$ as roots. A nonzero polynomial
of degree $p^f$ has at most $p^f$ roots
(Volume~1's root-count theorem). Hence $d\le f$.
Together with $f\mid d$, this proves $d=f$.

We have proved that every irreducible factor
of $\Phi_n$ modulo $p$ has degree $f$.
The factors are distinct because $X^n-1$
has no repeated factor. Finally $\Phi_n$ has
degree $\varphi(n)$, by its definition as the
product over the primitive $n$-th roots of unity.
There are therefore exactly $\varphi(n)/f$
irreducible factors.

\emph{(b) A polynomial that always splits on reduction.}
Here $\Phi_8(X)=X^4+1$. To prove irreducibility over $\Q$,
translate the variable:
\[
(X+1)^4+1=X^4+4X^3+6X^2+4X+2.
\]
Eisenstein's criterion from Volume~1 applies with the prime $2$:
all coefficients except the leading one are even, and the constant
term is not divisible by $4$. Substitution by $X+1$ is reversible
over $\Q$, so $X^4+1$ is irreducible too.

Modulo $2$ it equals $(X+1)^4$.
For any odd prime $p$, we have
$p^2\equiv1\pmod8$, since every odd square
is $1$ modulo $8$.
Thus $\operatorname{ord}_8(p)\le2$.
Part (a) says that all irreducible factors
of $\Phi_8$ modulo $p$ have degree $1$ or $2$.
Since $\Phi_8$ has degree $4$, it is
reducible modulo every odd prime too.

\emph{(c) What if $p$ divides the index?}
Assume $p\nmid m$. Over the complex numbers,
the roots of $\Phi_m(X^p)$ are precisely the
primitive roots of orders $m$ and $pm$.
They are all simple, and the polynomials
are monic. Hence
\[
\Phi_m(X^p)=\Phi_m(X)\Phi_{pm}(X).
\]
Reduce modulo $p$. The binomial theorem,
applied to the integer-coefficient
polynomial $\Phi_m$, gives
$\Phi_m(X^p)\equiv\Phi_m(X)^p$.
We can cancel the nonzero factor $\Phi_m(X)$
in the polynomial ring over $\mathbb F_p$,
obtaining
\[
\Phi_{pm}(X)\equiv\Phi_m(X)^{p-1}\pmod p.
\]
For $a\ge2$, comparing primitive-root
orders gives
$\Phi_{p^am}(X)=\Phi_{pm}(X^{p^{a-1}})$.
Substitute this into the preceding congruence
and use the binomial theorem again:
\[
\Phi_{p^am}(X)
 \equiv \Phi_m(X)^{(p-1)p^{a-1}}
 =\Phi_m(X)^{\varphi(p^a)}\pmod p.
\]
The argument also covers $m=1$ and $p=2$.

\tools Volume~1, Polynomials (division, irreducibility,
polynomial B\'ezout, formal derivative and root count);
Volume~2, Chapter~\ref{ch:orders} (cyclotomic polynomials
and multiplicative order). The small field and its
power-counting facts were established from scratch above.
\leads Finite fields will receive a systematic
treatment in Volume~3. Here we have already seen
why their size controls how a cyclotomic polynomial
breaks into factors modulo a prime.
\end{solution}

\begin{solution}{pb:fermatnum}
\idea A prime factor $p$ of $F_n$ makes $2$ have a large order, a power of $2$, which must divide $p-1$. That already gives
$2^{n+1}\mid p-1$; the extra factor $2$ comes from knowing that $2$ is a square. For $641$, the two expressions of $641$ say
that $5\cdot2^7\equiv-1$ and $2^4\equiv-5^4$, and multiplying the right powers gives $2^{32}\equiv-1$.

\writeup
The order of $2$ modulo a prime factor of a Fermat number is a power of $2$ that we can identify exactly. That order gives an arithmetic progression for possible factors. The next step strengthens the progression and explains Euler's factor of $F_5$.

 (a) Let $p\mid F_n$. Then $2^{2^n}\equiv-1$, so $2^{2^{n+1}}\equiv1$ and the order of $2$ modulo $p$ divides $2^{n+1}$ but
not $2^n$: it is $2^{n+1}$, and it divides $p-1$ (Volume~2, Chapter~\ref{ch:orders}). For $n\ge2$ this gives $p\equiv1\pmod8$, so
$\bigl(\frac2p\bigr)=1$ (Volume~2, Chapter~\ref{ch:reciprocity}) and, by Euler's criterion, $2^{(p-1)/2}\equiv1$. So $2^{n+1}\mid\frac{p-1}2$, and
$p\equiv1\pmod{2^{n+2}}$.

(b) Modulo $641$: $5\cdot2^7\equiv-1$, so $5^4\cdot2^{28}\equiv1$; and $2^4\equiv-5^4$. Hence
$2^{32}=2^4\cdot2^{28}\equiv-5^4\cdot2^{28}\equiv-1$, and $641\mid F_5$. In accordance with (a), $641=5\cdot2^7+1\equiv1\pmod{2^7}$: Euler
needed only a few trials.

(c) $F_0F_1\cdots F_{n-1}=F_n-2$, by induction: $(F_n-2)F_n=(2^{2^n}-1)(2^{2^n}+1)=2^{2^{n+1}}-1=F_{n+1}-2$. So a common divisor
of $F_m$ and $F_n$, $m<n$, divides $2$; the $F_n$ are odd, so they are coprime. Each $F_n$ has a prime factor, and these are
all different: there are infinitely many primes.
\tools Volume~2, Chapters~\ref{ch:orders} and~\ref{ch:reciprocity} (orders, the value of $(\frac2p)$, Euler's criterion).
\leads Fermat conjectured that all $F_n$ are prime; Euler found $641$ in 1732. Only $F_0,\dots,F_4$ are known to be prime,
and $F_5,\dots,F_{32}$ are known to be composite. Landry found $F_6=274177\cdot67280421310721$ in 1880, and indeed
$274177\equiv1\pmod{2^8}$. Gauss proved that the regular $n$-gon is constructible when $n$ is a power of $2$ times distinct Fermat
primes (Volume~3, Chapter~10).
\end{solution}

\begin{solution}{pb:carmichael}
\idea To show that $n$ fails, find one base $a$ that breaks $a^{n-1}\equiv1$. The Chinese remainder theorem lets us choose
$a$ freely modulo each prime power factor, so we can take it of maximal order there. Then $a^{n-1}\equiv1$ forces that order
to divide $n-1$. With two prime factors, the divisibilities $p-1\mid n-1$ and $q-1\mid n-1$ cannot both hold.

\writeup
Fermat's congruence is obeyed by all primes, but some composites fool every coprime base. Work modulo an unknown prime-power factor, use a primitive root to exclude repeated prime factors, and then recover Korselt's criterion from the divisibility of group orders.

 (a) $n$ is odd: otherwise $(-1)^{n-1}=-1\not\equiv1\pmod n$, as $n>2$. Let $p\mid n$ and write $n=p^vm$ with $p\nmid m$.
If $v\ge2$, let $g$ have order $p(p-1)$ modulo $p^2$ ($(\Z/p^2\Z)^*$ is cyclic, Volume~2, Chapter~\ref{ch:orders}), and by the Chinese
remainder theorem choose $a\equiv g\pmod{p^2}$, $a\equiv1\pmod m$, and $a$ prime to $p$; then $a$ is prime to $n$. From
$a^{n-1}\equiv1\pmod{p^2}$, $p(p-1)\mid n-1$, so $p\mid n-1$, absurd since $p\mid n$. So $n$ is squarefree. Now take $a\equiv g$
modulo $p$ with $g$ a primitive root, and $a\equiv1\pmod m$: $a^{n-1}\equiv1\pmod p$ gives $p-1\mid n-1$.

(b) $n$ is squarefree and composite, so it has at least two prime factors. If $n=pq$ with $p<q$, then
$n-1=p(q-1)+(p-1)\equiv p-1\pmod{q-1}$, and $q-1\mid n-1$ would give $q-1\mid p-1$, impossible as $0<p-1<q-1$.

(c) $n=(6k+1)(12k+1)(18k+1)=1296k^3+396k^2+36k+1$, so $n-1=36k(36k^2+11k+1)$ is divisible by $6k$, $12k$ and $18k$. By
Korselt's criterion (Volume~2, Chapter~3), $n$ is a Carmichael number. For $k=1$: $7\cdot13\cdot19=1729$.
\tools Volume~2, Chapters~\ref{ch:congruences} and~\ref{ch:orders} (Chinese remainder theorem, Korselt's criterion, primitive roots modulo $p^2$).
\leads $1729=1^3+12^3=9^3+10^3$ is the Hardy--Ramanujan taxi-cab number: the smallest positive integer expressible as a sum of two positive cubes in two different ways, ignoring the order of the summands.
Chernick (1939) gave (c). That criterion alone does not prove infinitude; Alford, Granville and Pomerance proved
in 1994 that there are infinitely many Carmichael numbers.
\end{solution}

\begin{solution}{pb:pratt}
\idea (a) An element whose order is exactly $n-1$ forces the group $(\Z/n\Z)^*$ to have $n-1$ elements, which only happens
for primes; and checking that the order is $n-1$ needs only the prime factors of $n-1$. (b) The tree branches at the prime
factors of $p-1$, whose product is less than $p$: induction on $p$ with a logarithmic bound, because logarithms add.

\writeup
A primality certificate needs a small list of equations that somebody else can check. Here the decisive information is the exact order of an element, obtained by checking one exponent for each distinct prime factor of $n-1$. After proving the criterion, we count how large a recursive certificate can become.

 (a) If $n$ is prime, a primitive root works (Volume~2, Chapter~\ref{ch:orders}). Conversely, the order $e$ of $a$ in $(\Z/n\Z)^*$ ($a$ is a
unit since $a\cdot a^{n-2}\equiv1$) divides $n-1$. If $e<n-1$, some prime $q$ divides $\frac{n-1}e$, and then $e\mid\frac{n-1}q$ and
$a^{(n-1)/q}\equiv1$, excluded. So $e=n-1$, hence $n-1\le\varphi(n)$, and $n$ is prime.

(b) Induction on $p$. As $p$ is odd, $2\mid p-1$. Let $q_1,\dots,q_k$ be the distinct odd primes dividing $p-1$; their product is at
most $\frac{p-1}2$. If $k=0$, $f(p)=1+f(2)=2\le2\log_2p-1$, because $p\ge3$. If $k\ge1$, by induction
\[
f(p)=1+f(2)+\sum_{i=1}^kf(q_i)\le2+\sum_i(2\log_2q_i-1)\le2+2\log_2\frac{p-1}2-k=2\log_2(p-1)-k,
\]
which is at most $2\log_2p-1$.

(c) A prime $p$ with $k$ binary digits has at most $2k$ primes in its tree, each with at most $k$ digits. At each one, say $\ell$, the
checker multiplies the claimed factorisation of $\ell-1$ (at most $k$ factors with multiplicity) and computes $a^{\ell-1}$ and the
$a^{(\ell-1)/q}$ modulo $\ell$, at most $k+1$ modular powers, each by $O(k)$ squarings and multiplications (Volume~2, Chapter~3). In
total $O(k^3)$ operations on numbers of at most $k$ binary digits.
\tools Volume~2, Chapters~\ref{ch:congruences} and~\ref{ch:orders} (fast exponentiation, orders, primitive roots).
\leads Pratt (1975) showed that primes have short certificates that can be checked in polynomial time. Finding the certificate requires factoring
$p-1$, which is hard in general; but primes of special shape (Proth primes, Problem~\ref{pb:pocklington}) carry their own
factorisation, and elliptic curve methods replace $p-1$ by the order of a random group (Goldwasser--Kilian, Atkin--Morain).
\end{solution}

\begin{solution}{pb:rabin}
\idea A strong liar is described componentwise by the Chinese remainder theorem, and in each cyclic group $(\Z/p_i^{e_i}\Z)^*$
the equations $x^t=\pm1$ have explicit numbers of solutions. So the liars can be counted exactly, and the count is then
compared with $\varphi(n)$ factor by factor. The prime powers lose a factor $p^{e-1}$; several primes lose a factor
$2^{r-1}$ from the powers of $2$; and the only delicate case, two primes with the same $2$-part, is saved by a
divisibility argument.

\writeup
The strong probable-prime test tests several possible square roots of $1$. First count roots in one cyclic group. Then use the Chinese remainder theorem to count the bases that escape detection across all prime-power factors, and finally bound their proportion.

 (a) Let $g$ generate $C$, of order $m$. $x=g^u$ satisfies $x^t=1$ iff $m\mid tu$, iff $\frac m{\gcd(t,m)}\mid u$: there are
$\gcd(t,m)$ such $u$ modulo $m$. If $x^t=-1$, then $x^{2t}=1$ and $x^t\ne1$. Conversely if $x^{2t}=1\ne x^t$, then $x^t$ has order $2$,
so it is $-1$, the unique element of order $2$ in a cyclic group of even order. So the count is $\gcd(2t,m)-\gcd(t,m)$.

(b) Let $\varphi_i=p_i^{e_i-1}2^{\nu_i}m_i$, the order of the cyclic group $C_i=(\Z/p_i^{e_i}\Z)^*$ (Volume~2, Chapter~\ref{ch:orders}; $p_i$ is odd).
By the Chinese remainder theorem, $a$ is a liar iff either $a^d=1$ in every $C_i$, or for some $0\le j<s$, $a^{2^jd}=-1$ in every
$C_i$. These cases are disjoint: if $a^{2^jd}\equiv-1$, then $a^{2^{j'}d}\equiv1$ for $j'>j$, and $\pm1$ are distinct modulo $n$. Since
$p_i\mid n$, $p_i\nmid n-1$, so $p_i\nmid d$, and $\gcd(2^jd,\varphi_i)=g_i\,2^{\min(j,\nu_i)}$ with $g_i=\gcd(d,m_i)$ ($d$ is odd). By (a):
\begin{itemize}
\item $a^d=1$ in $C_i$ for $g_i$ elements;
\item $a^{2^jd}=-1$ in $C_i$ for $g_i\bigl(2^{\min(j+1,\nu_i)}-2^{\min(j,\nu_i)}\bigr)$ elements, which is $g_i2^j$ if $j<\nu_i$ and $0$ if
$j\ge\nu_i$.
\end{itemize}
Multiplying over $i$, the number of $a$ with $a^{2^jd}\equiv-1\pmod n$ is $\bigl(\prod_ig_i\bigr)2^{jr}$ if $j<\nu$ and $0$ otherwise.
Each $p_i\equiv1\pmod{2^\nu}$, so $n\equiv1\pmod{2^\nu}$ and $\nu\le s$. Summing over $0\le j<\nu$ and adding the first case, the
number of liars is $\prod_ig_i\cdot\bigl(1+\sum_{j<\nu}2^{jr}\bigr)$, which is Monier's formula.

(c) Write $T_r(\nu)=\frac{1+\frac{2^{r\nu}-1}{2^r-1}}{2^{r\nu}}=2^{-r\nu}\Bigl(1-\frac1{2^r-1}\Bigr)+\frac1{2^r-1}$. Then the proportion of liars is
\[
R=\frac{L}{\varphi(n)}=\prod_{i=1}^r\frac{g_i}{m_ip_i^{e_i-1}}\cdot T_r(\nu)\cdot2^{r\nu-(\nu_1+\dots+\nu_r)}.
\]
All three factors are at most $1$, and $T_r$ decreases in $\nu\ge1$, so $T_r(\nu)\le T_r(1)=2^{-r}+2^{-r}=2^{1-r}$ (for $r=1$,
$T_1(\nu)=1$).

\emph{$r=1$}, $n=p^e$ with $e\ge2$: $R\le p^{1-e}$, which is $\frac13$ for $n=9$ and at most $\frac15$ otherwise ($p^{e-1}\ge5$).

\emph{$r\ge3$}: $R\le2^{1-r}\le\frac14$.

\emph{$r=2$}: $R\le\frac12\cdot\frac{g_1g_2}{m_1m_2p_1^{e_1-1}p_2^{e_2-1}}\cdot2^{2\nu-\nu_1-\nu_2}$. If $\nu_1\ne\nu_2$, the last factor is at most
$\frac12$. If some $e_i\ge2$, the middle factor is at most $\frac13$. There remains $n=p_1p_2$ with $\nu_1=\nu_2=\nu$. If
$g_1=m_1$ and $g_2=m_2$, then $m_i\mid d$, so $p_i-1=2^\nu m_i$ divides $2^sd=n-1$. But $n-1=p_1(p_2-1)+(p_1-1)$, so $p_2-1\mid p_1-1$,
and symmetrically $p_1-1\mid p_2-1$, so $p_1=p_2$: absurd. So some $g_i$ is a proper divisor of the odd $m_i$, $\frac{g_i}{m_i}\le\frac13$,
and $R\le\frac16$.

In all cases $R\le\frac14$, except $n=9$. For $n=15$: $14=2\cdot7$, $s=1$, $d=7$; $r=2$, $p_1-1=2$, $p_2-1=4$, $\nu=1$, $g_1=g_2=1$. Monier
gives $1\cdot(1+1)=2$ liars ($\pm1$) out of $\varphi(15)=8$: exactly $\frac14$.
\tools Volume~2, Chapters~\ref{ch:congruences} and~\ref{ch:orders}
(Chinese remainder theorem, cyclic groups $(\Z/p^e\Z)^*$).
The broader abstract group theory in Volume~3 is an outlook, not a
prerequisite to this proof.
For the probability bound, choose each base independently and uniformly from $1,\ldots,n-1$, and reject immediately when it is not a unit. For $n\ne9$ the number of strong liars is at most $\varphi(n)/4\le(n-1)/4$. For $n=9$ it is $2$, again $(n-1)/4$. Thus a fixed composite passes $k$ independent trials with probability at most $4^{-k}$. Sampling only units would instead give probability $1/3$ per trial at $n=9$.
\leads Miller (1976) gave a deterministic polynomial-time test assuming the extended Riemann hypothesis. Bach (1990) supplied the explicit sufficient witness bound $2(\log n)^2$ under that hypothesis. Rabin (1980) obtained the randomised test; the elementary count above gives its error guarantee for the stated sampling model. Figure~\ref{fig:liars} compares the exact fractions of unit liars in a finite range.
\end{solution}



\begin{solution}{pb:squaresmodpk}
\idea A non-zero square modulo $p^k$ has an even valuation $2j<k$ and a unit part that is a square modulo $p^{k-2j}$. For odd $p$, the cyclic unit group has exactly two elements in the kernel of squaring, namely $\pm1$. The powers of $2$ require their separate structure theorem.

\writeup
A square modulo a prime power has an even valuation, unless it is zero. Strip off that valuation and count square units at the smaller modulus. For powers of two, the unit classes behave differently; treating that case separately matters.

 (a) Let $p$ be odd. If $x=y^2\not\equiv0\pmod{p^k}$, then $v_p(x)=2v_p(y)=2j<k$ and $x=p^{2j}u$ with $u$ a unit modulo $p^{k-2j}$ which is a
square modulo $p^{k-2j}$. Conversely every such $p^{2j}u$ is a square. The residue $x$ modulo $p^k$ determines $j$ and $u$ modulo $p^{k-2j}$,
and the units modulo $p^m$ form a cyclic group of even order $\varphi(p^m)$ (Volume~2, Chapter~\ref{ch:orders}), in which the squares are a subgroup of
index $2$. So there are $\frac12\varphi(p^{k-2j})=\frac{p-1}2p^{k-2j-1}$ non-zero squares of valuation $2j$, and adding $0$ gives the formula.
Dividing by $p^k$, $\frac{S(p^k)}{p^k}=p^{-k}+\frac{p-1}{2p}\sum_{0\le j<k/2}p^{-2j}\to\frac{p-1}{2p}\cdot\frac1{1-p^{-2}}=\frac p{2(p+1)}$.

(b) For $k\ge3$, the odd squares modulo $2^k$ are precisely the classes $1\pmod8$, so there are $2^{k-3}$ of them. Every even square is divisible by $4$, and multiplication by $4$ gives a bijection from the square classes modulo $2^{k-2}$ to the even square classes modulo $2^k$. Hence
\[
S(2^k)=2^{k-3}+S(2^{k-2}).
\]
Put $u_k=S(2^k)/2^k$. Dividing by $2^k$ gives $u_k=\frac18+\frac14u_{k-2}$, or
\[
u_k-\frac16=\frac14\left(u_{k-2}-\frac16\right).
\]
Starting from $S(2)=S(4)=2$, the difference tends to zero along both the odd and even indices. Thus $S(2^k)/2^k\to\frac16$.

(c) By the Chinese remainder theorem, $x$ is a square modulo $mn$ (coprime) if and only if it is a square modulo $m$ and modulo $n$,
so $S(mn)=S(m)S(n)$. For $m=\prod_{p\le y}p$, the proportion of squares is $\prod_{p\le y}\frac{p+1}{2p}\le\prod_{3\le p\le y}\frac23\to0$. Now suppose an integer $a$ is a square modulo every positive modulus $m$.
If $a=0$, it is already a square. Otherwise, suppose some prime $p$
occurs to an odd exponent $r=v_p(|a|)$. Choose $m=p^{r+1}$.
If $x^2\equiv a\pmod m$, then $v_p(x^2)=r$: indeed,
$a$ is divisible by $p^r$ but not by $p^{r+1}$, and the congruence
forces the same divisibility on $x^2$. But $v_p(x^2)$ is even,
whereas $r$ is odd, a contradiction.
Thus every exponent in $|a|$ is even, so $|a|=b^2$ with $b>0$.
If $a>0$ we are done. If $a=-b^2$, choose $m=4b^2$.
The congruence $x^2\equiv-b^2\pmod{4b^2}$ implies $b^2\mid x^2$,
hence $b\mid x$ by prime-factor uniqueness. Writing $x=bt$
would give $t^2\equiv-1\pmod4$, impossible because squares
modulo $4$ are $0$ or $1$. Hence $a$ must be a square.
This final local--global conclusion is elementary and uses no
unproved prime-distribution theorem.

\tools Volume~2, Chapters~\ref{ch:divisibility}, \ref{ch:congruences},
\ref{ch:orders} and~\ref{ch:reciprocity} (valuations, CRT,
cyclic unit groups, squares). No Volume~3 or Volume~13 theorem is used.
\leads In $p$-adic language, the squares of $\Z_p$ have Haar measure $\frac p{2(p+1)}$ ($\frac16$ for $p=2$). The last statement of (c)
is the simplest case of a \emph{local--global principle}: a property that holds modulo every $m$ is forced
to hold over $\Z$. Such principles are a recurring theme of Part~III.
\end{solution}

\begin{solution}{pb:eisensine}
\idea Gauss's lemma counts the sign changes in $j\mapsto qj\bmod p$; the odd function $\sin\frac{2\pi x}p$ records the
signs as a product of sines. The polynomial identity (a) then turns each ratio $\frac{\sin qx}{\sin x}$ into a product of
differences $\sin^2\frac{2\pi j}p-\sin^2\frac{2\pi k}q$. The double product is symmetric in $p$ and $q$ except for the sign
of each factor, and counting the factors gives reciprocity.

\writeup (a) We want to turn the trigonometric ratio $\sin(qx)/\sin x$ into a polynomial in $\sin^2x$. De Moivre's formula is the bridge:
\[
\sin(qx)=\operatorname{Im}(\cos x+i\sin x)^q
=\sum_{\substack{j\le q\\j\text{ odd}}}
\binom qj(-1)^{(j-1)/2}\cos^{q-j}x\,\sin^jx.
\]
Because $q$ and $j$ are odd, $q-j$ is even, and we can replace the even power of cosine by $(1-\sin^2x)^{(q-j)/2}$. After dividing by $\sin x$, every term is a polynomial in $y=\sin^2x$, of degree at most $(q-1)/2$. The leading coefficients add to
\[
(-1)^{(q-1)/2}
\sum_{j\text{ odd}}\binom qj
=(-1)^{(q-1)/2}2^{q-1}
=(-4)^{(q-1)/2}.
\]
Call this polynomial $F(y)$.

For $1\le k\le(q-1)/2$, the angle $x_k=2\pi k/q$ lies in $(0,\pi)$, has $\sin(qx_k)=0$ and $\sin x_k\ne0$. So $F(\sin^2x_k)=0$. These roots are distinct: equality of two squared sines in $(0,\pi)$ would mean $x_k=x_l$ or $x_k=\pi-x_l$; the second would give $2(k+l)=q$, impossible because $q$ is odd. We have found all $(q-1)/2$ roots and the leading coefficient, hence
\[
F(y)=(-4)^{(q-1)/2}
\prod_{k=1}^{(q-1)/2}(y-\sin^2(2\pi k/q)).
\]

(b) Let $H=\{1,\ldots,(p-1)/2\}$. Multiplication by $q$ modulo $p$, followed by choosing a representative of least absolute value, gives
$qj\equiv\varepsilon_jr_j\pmod p$ with $r_j\in H$ and $\varepsilon_j\in\{-1,1\}$. The map $j\mapsto r_j$ is a permutation of $H$: if two positive representatives were equal, the original indices would agree up to sign modulo $p$, and the allowed range excludes the negative possibility unless they coincide.

Multiply these congruences and cancel the nonzero factorial $((p-1)/2)!$ modulo $p$. Euler's criterion gives
\[
\left(\frac qp\right)=\prod_{j\in H}\varepsilon_j.
\]
Meanwhile $\sin(2\pi x/p)$ is odd and periodic modulo $p$, so
\[
\prod_{j\in H}
\frac{\sin(2\pi qj/p)}{\sin(2\pi j/p)}
=\prod_{j\in H}\varepsilon_j.
\]
The unsigned sine factors cancel because the $r_j$ form a permutation. This identifies the trigonometric product with the Legendre symbol.

(c) Put
$u_j=\sin^2(2\pi j/p)$ and $v_k=\sin^2(2\pi k/q)$ in their respective half-ranges. Apply (a) to the product from (b):
\[
\left(\frac qp\right)
=(-4)^{(p-1)(q-1)/4}\prod_{j,k}(u_j-v_k).
\]
Exchanging $p$ and $q$ gives
\[
\left(\frac pq\right)
=(-4)^{(p-1)(q-1)/4}\prod_{j,k}(v_k-u_j).
\]
No factor is zero: $u_j=v_k$ would force either $qj=pk$, contradicting the allowed indices and distinct primes, or $2(qj+pk)=pq$, impossible because $pq$ is odd. The two products therefore differ by exactly one minus sign for each of their $(p-1)(q-1)/4$ factors. Divide the identities and use that Legendre symbols are $\pm1$:
\[
\left(\frac qp\right)\left(\frac pq\right)
=(-1)^{(p-1)(q-1)/4}.
\]
That is quadratic reciprocity, obtained by comparing the same polynomial factorisation in two orders.

\tools Volume~1 (de Moivre, polynomials and roots); Volume~2 (Euler's criterion and Gauss's lemma).
\leads Eisenstein's 1845 argument replaces lattice-point counting by trigonometric factorisation. Closely related constructions with elliptic functions led to higher reciprocity laws; here the elementary sine identity already contains the sign of quadratic reciprocity.
\end{solution}

\begin{solution}{pb:euler}
\idea Both sides of the congruence are multiplicative in $a$, so the liars form a subgroup; a proper subgroup has index at
least $2$. To show it is proper, we need one unit that is not a liar, and as for Carmichael numbers we build it with the
Chinese remainder theorem. The Jacobi symbol sees each prime factor separately, so one can make it $-1$ while $a^{(n-1)/2}$
stays $1$ modulo a part of $n$.

\writeup (a) Let $L$ be the set of units modulo the odd integer $n\ge3$ satisfying the Euler--Jacobi congruence in the question. The identity belongs to $L$, and if $a,b\in L$, then
\[
(ab)^{(n-1)/2}\equiv
\left(\frac an\right)\left(\frac bn\right)
=\left(\frac{ab}n\right)\pmod n,
\]
because the Jacobi symbol is multiplicative. So $L$ is closed under products. Since it is a nonempty subset of the finite unit group closed under products, powers provide inverses as well; $L$ is a subgroup.

(b) We must show that this subgroup is proper. First suppose $p^2\mid n$ for an odd prime $p$. Choose a primitive root $g$ modulo $p^2$, which has order $p(p-1)$ by the theorem already proved in Chapter~\ref{ch:orders}. If $p^e$ is the exact power of $p$ in $n$, choose any unit modulo $p^e$ congruent to $g$ modulo $p^2$. Use the Chinese remainder theorem to choose residue $1$ at every other prime-power factor of $n$. The resulting unit still has order $p(p-1)$ when reduced modulo $p^2$. Any Euler liar satisfies $a^{n-1}\equiv1\pmod n$, since squaring the displayed Euler--Jacobi congruence yields that relation. But our chosen unit would force $p(p-1)\mid n-1$. This is impossible because $p\mid n$ but $p\nmid n-1$.

Now suppose $n$ is squarefree, say $n=pm$ with $p$ an odd prime and $m>1$ coprime to $p$. Choose a quadratic nonresidue $b$ modulo $p$. By the Chinese remainder theorem, take $a\equiv b\pmod p$ and $a\equiv1\pmod m$. Its Jacobi symbol equals $-1$. If $a$ were a liar, we would have $a^{(n-1)/2}\equiv-1\pmod n$, hence also modulo $m$. But $a\equiv1\pmod m$ makes the left side $1$. This would imply $m\mid2$, impossible because $m>1$ is odd.

Thus $L$ is a proper subgroup in either case. To justify the
half-size bound without assuming Lagrange's theorem from Volume~3,
choose a unit $u\notin L$. Multiplication by $u$ is a bijection
$L\to uL$; the two sets are disjoint, because if $u\ell=\ell'$
with $\ell,\ell'\in L$, then $u=\ell'\ell^{-1}\in L$, a
contradiction. So the full unit group contains two disjoint sets
of size $|L|$, and $2|L|\le\varphi(n)$.

\tools Volume~2, Chapters~\ref{ch:congruences}, \ref{ch:orders}
and~\ref{ch:reciprocity} (CRT, primitive roots, Jacobi symbols).
The subgroup-size estimate is established directly above.
\leads This bound is the mathematical guarantee behind the Solovay--Strassen randomised primality test. Testing independent random unit bases makes the probability of repeatedly accepting a composite at most $2^{-k}$ after $k$ trials. The related Miller--Rabin test is treated in Problem~\ref{pb:rabin}.
\end{solution}

\begin{solution}{pb:sumsquares}
\idea We can avoid Gauss sums entirely. Count pairs of squares first;
adding two more squares then obeys a simple recurrence.
That recurrence gives every case, including zero, and also
makes the probability calculation almost automatic.

\writeup Let $\chi(u)=\left(\frac up\right)$ and
$\varepsilon=\chi(-1)\in\{-1,1\}$.
There are $1+\chi(u)$ solutions of $y^2=u$ modulo $p$.

\emph{Count two squares.}
By fixing $x$ and counting $y$, we obtain
\[
N_2(c)=p+\sum_x\chi(c-x^2)
     =p+\varepsilon\sum_x\chi(x^2-c).
\]
To evaluate the last sum, count the pairs
$(x,y)$ with $y^2=x^2-c$. Since $p$ is odd,
the substitution $u=x-y$, $v=x+y$ is reversible:
$x=(u+v)/2$ and $y=(v-u)/2$. It turns the equation
into $uv=c$. For $c\ne0$, there are $p-1$ pairs;
for $c=0$, there are $2p-1$, because we count the
two axes once each and subtract their common point.
The number is also $p+\sum_x\chi(x^2-c)$.
Consequently
\[
N_2(c)=p+\varepsilon(p\mathbf1_{\{c=0\}}-1).
\tag{1}
\]

\emph{Add two more squares.}
If the first $n$ squares sum to $u$, the last
two must sum to $c-u$. As $\sum_uN_n(u)=p^n$,
equation (1) gives
\[
\begin{aligned}
N_{n+2}(c)
 &=\sum_uN_n(u)N_2(c-u)\\
 &=(p-\varepsilon)p^n+\varepsilon pN_n(c)\\
 &=p^{n+1}+\varepsilon p(N_n(c)-p^{n-1}).
\end{aligned}
\]
Put $D_n(c)=N_n(c)-p^{n-1}$. Then
$D_{n+2}(c)=\varepsilon pD_n(c)$.
Our two starting values are
$D_1(c)=\chi(c)$, since $N_1(c)=1+\chi(c)$,
and $D_2(c)=\varepsilon(p\mathbf1_{\{c=0\}}-1)$.
Iterating separately from each starting value gives
\[
\begin{aligned}
D_{2m+1}(c)&=\varepsilon^mp^m\chi(c)&& (m\ge0),\\
D_{2m}(c)&=\varepsilon^mp^{m-1}
       (p\mathbf1_{\{c=0\}}-1)&& (m\ge1).
\end{aligned}
\]
Since $\chi((-1)^mc)=\varepsilon^m\chi(c)$,
these are the formulas in (a) for $c\ne0$.
They also tell us exactly what happens at zero:
\[
N_n(0)=\begin{cases}
p^{n-1}+(p-1)p^{n/2-1}\eta((-1)^{n/2}),
  &n\text{ even},\\[2pt]
p^{n-1},&n\text{ odd}.
\end{cases}
\]

\emph{Now the probability.}
Every tuple is equally likely, so
$\Pr(S=c)=N_n(c)/p^n$. By the definition in
the question,
\[
d=\frac1{2p^n}\sum_c|D_n(c)|.
\]
For $n=2m$, the absolute error is
$(p-1)p^{m-1}$ at zero and $p^{m-1}$
at each of the other $p-1$ classes. Thus
$d=(1-1/p)p^{-m}$.
For $n=2m+1$, the error is zero at zero
and $p^m$ at each of the other $p-1$ classes.
Thus $d=\frac{p-1}2p^{-m-1}$.
This proves (b) without borrowing the definition
or a theorem from any later volume.

\tools Chapter~\ref{ch:reciprocity} (Legendre symbol).
We established the two-square count and its recurrence here;
total variation was defined in the question.
\leads The Gauss sum in Exercise~\ref{ex:gausssum}
offers an independent route to the same formulas.
For $n=4$, each nonzero residue has exactly $p^3-p$
representations, an echo of Jacobi's four-square identity.
\end{solution}

\item D.~A.~Cox, \emph{Primes of the Form $x^2+ny^2$}, 3rd ed., AMS Chelsea, 2022, \S1. How reciprocity answers Fermat's questions, the theme of Chapters~7 and~10.

\item A.~Granville, It is easy to determine whether a given integer is prime, \emph{Bulletin of the American Mathematical Society} 42 (2005), 3--38. A survey of where primality testing went next, up to the AKS algorithm.
\item E.~Bach, Explicit bounds for primality testing and related problems, \emph{Mathematics of Computation} 55 (1990), 355--380. The explicit witness bound under the extended Riemann hypothesis mentioned after Problem~\ref{pb:rabin}.
\item J.~J.~Gray, \emph{A commentary on Gauss's mathematical diary, 1796--1814, with an English translation}, Expositiones Mathematicae 2 (1984), 97--130. For the history of quadratic reciprocity, see also Lemmermeyer's book above.
