# Description

Why is the number of partitions of 4, 9, 14, 19, … always a multiple of 5? Which strange pair of dice rolls every total with exactly the same odds as an ordinary pair? Why does a random fraction, reduced to lowest terms, have an odd numerator and an odd denominator exactly one time in three? And how large can a set of SET cards be when no three of them form a set?

This book gathers about three hundred problems that live where number theory, algebra, probability and analysis meet. Each one needs ideas from at least two volumes of the first part of the series, and none of them tells you which tool to use: finding it is the game. Roots of unity count subsets, finite fields build designs and pseudo-random sequences, group actions count necklaces and dice, Fourier analysis proves that a random walk mixes, and probability explains why two integers are coprime with probability 6/π².

Each chapter opens with a true story, checked against its sources: Ramanujan reading Major MacMahon's hand-computed table of partitions, Gauss asking Laplace in 1812 how fast the digits of a continued fraction forget where they started, a geneticist inventing a card game that hid a problem solved only in 2016. Then come the problems, graded from approachable to hard, with long Journeys that walk step by step to famous theorems: the Lucas–Lehmer test, the cap set bound, the Gauss–Kuzmin theorem, Ramanujan's congruence through Jacobi's triple product.

Every problem has a hint, kept apart so that you can try first, and a complete solution that begins with the idea, how one might find it, before writing the proof in full. Each solution names the tools it used and ends with where the problem leads, often to current research. Figures show what the formulas mean, and every chapter closes with a map of its problems and references for further reading.

Every chapter has a companion Python notebook that checks each number in the text and turns the problems into experiments, from counting points on curves to simulating random integers.

Written for readers who have learned the theorems and now want the pleasure of using them.
