| `thm:rwreflect` | For a path whose first hit of a>0 occurs at τ and whose terminal b≤a, leave first τ steps and set S'_k=2a−S_k afterward. This reverses every later increment and moves endpoint to 2a−b. Any path to 2a−b≥a must hit a, so reflecting from its first hit is the inverse. Count equality is exact, with parity and unreachable endpoints handled by zero path counts. **Independent exhaustive enumeration n=1..11 across 447 admissible (n,a,b) triples** found every count equal. ## All eight exercises, hints and full worked solutions

1. `ex:ballotwalk`: compulsory initial +1, shift height `Y_j=1−S_(j+1)`, forbidden barrier 1, reflection bijection of bad paths; count difference `binom(n−1,a−1)−binom(n−1,a)=(a−b)/n·binom(n,a)`. Boundary b=0 checked.
2. `ex:maxlaw`: sum reflection identity over endpoints b≤a, add b>a separately. Explicit intermediate identity `P(M≥a,S_n≤a)=P(S_n≥a)`.
3. `ex:timepositive`: first return 2m positive/negative excursions; using ballot count gives `u_(2m)/(2m−1)`. m=1 gives 1/2; m=2 gives 1/8.
4. `ex:unfair`: p=2/3,q=1/3,N=3 gives h1=4/7, h2=6/7; verified both closed form and one-step equations.
5. `ex:meet`: two independent fair walks start 0,2; difference increments 0 w.p.1/2 and ±2 w.p.1/4. Infinitely many nonzero moves almost surely. The embedded walk after dividing by 2 is fair starting −1; each new nonzero move is fresh by finite-record argument. **Rewrote original informal recurrence/conditional-on-random-returns argument to an elementary finite-ruin bound**: for every N≥2, chance embedded walk hits 0 before −N is (N−1)/N, so chance ever meeting ≥(N−1)/N→1.
6. `ex:escape`: first-return asymptotic f_(2m)~(2sqrtπ)^(−1)m^(−3/2), so weighted expected duration diverges like Σm^(−1/2).
7. `ex:exittime`: finite exit from [−R,R], solve g(k)=R²−k², g(k)=1+weighted neighbour average. Truncated finite-time conditioning bounds Eτ≤R², then uniqueness of harmonic solution and E_0τ=R².
8. `ex:electric`: finite connected graph voltage h, interior Kirchhoff current=0, total current out of b=total into a, probability from a hit b before returning a is 1/(deg(a)R). Series length m resistance m; two branches of lengths m,k parallel resistance mk/(m+k).
