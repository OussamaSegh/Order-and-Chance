# Order and Chance

*Discover the patterns. Understand the proofs.* By SEGHAIER Oussama.

A series of books of beautiful mathematics, written for pleasure. Every chapter has graded exercises with complete solutions and a Python
notebook for mathematical experiments.

## The series

| Tome | Title | Theme | Status |
| --- | --- | --- | --- |
| 0 | Mathematical Maturity | The core toolkit, relearned through problems | Complete draft (8 chapters) |
| 1 | The Integers | Elementary and algebraic number theory | Complete draft (12 chapters) |
| 2 | Structures | Groups, rings, fields, Galois, representations | Complete draft (12 chapters + 13 appendices) |
| 3 | Chance | Probability and combinatorial foundations | Complete draft (12 chapters + 2 appendices) |
| 4 | The Art of Calculation | Series, integrals, special functions, asymptotics | Complete draft (12 chapters) |
| 5 | Where It All Meets | Analytic and probabilistic number theory | Complete draft (12 chapters) |
| 6 | Spaces | Sets, topology, measure and integration | Complete (11 chapters) |
| 7 | Analysis in Depth | Functional, harmonic and complex analysis | Complete (10 chapters) |
| 8 | Shapes | Manifolds, algebraic topology, Lie groups and geometry | Complete (10 chapters + 12 appendices) |
| 9 | Higher Structures | Categories, commutative and homological algebra, representations | Complete (11 chapters) |
| 10 | Chance II | Graduate probability: limit theorems, large deviations, concentration, ergodic theory | Complete (12 chapters) |
| 11 | Random Motion | Brownian motion, stochastic calculus, random walks, random matrices | Complete (12 chapters + 2 appendices) |
| 12 | Arithmetic | Algebraic number theory, elliptic curves, modular forms | Complete (14 chapters) |
| 13 | Primes in Depth | Analytic and additive number theory | Complete (14 chapters) |
| 14 | Random Arithmetic | Probabilistic number theory and arithmetic statistics | Planned |
| 15 | The Research Workshop | Reading papers, experimenting, conjecturing, writing | Complete (12 chapters + 12 appendices) |
| P1 | Crossroads | 300 harder problems across Tomes 0–5, by meeting points, with full solutions | Complete (14 chapters, 300 problems) |
| P2 | Machinery | 300 harder problems across Tomes 6–9 | In progress (2 of 14 chapters) |
| P3 | Frontiers | 300 harder problems across Tomes 10–15 | In progress (1 of 14 chapters) |

Tomes 0–15 tell one mathematical story:

**Mathematical Maturity** → **Integers · Structures · Chance · Calculation** →
**Where It All Meets** → **Spaces · Analysis · Shapes · Higher Structures** →
**Advanced Probability · Random Motion** → **Arithmetic · Primes · Random Arithmetic** →
**The Research Workshop**.

The roadmap uses short subject names; the table above gives each book's full title.
Linear algebra is part of Structures (appendices A–M), geometry is part of Shapes
(appendices A–L), and open problems are case studies in The Research Workshop
(appendices A–L). Chance includes the combinatorial foundations in appendices A–B;
Random Motion contains its spectral graph and random-matrix prerequisites in
appendices A–B. The three problem books P1–P3 provide additional exercises for the
three stages of the main sequence.

## Design and future sessions

The author-approved visual identity follows the [balanced black/gold reference](docs/reference/approved-balanced-volume-0.png):
black textured paper, warm gold serif lettering, a fine border, one substantial
mathematical illustration and a smaller supporting construction per volume.
Each of the 19 illustrations is generated from its own mathematics as crisp vector
art. The slogan is **Discover the patterns. Understand the proofs.** Paperback
wraps, ebook covers, interior accents and online light/dark themes share this identity.
Read [the current design guide](docs/DESIGN.md) and [AGENTS.md](AGENTS.md) before
changing design or publishing templates. Earlier proposals are archived separately.

## Layout

```
common/                 shared LaTeX preamble (PDF) and EPUB preamble
tome0-mathematical-maturity/    main.tex + chapters/*.tex (solutions at the end of each chapter)
tome1-integers/         same layout, one folder per tome
python/tomeN/           one Jupyter notebook per chapter
tools/                  EPUB conversion helpers (pandoc filter, CSS)
build.sh                builds dist/<tome>.pdf, -kindle.pdf and .epub
```

## Building

Requires `pdflatex` (TeX Live with `latex-extra` and `fonts-recommended`), `pandoc` 3 and Python 3.

```
./build.sh                       # every tome
./build.sh tome0-mathematical-maturity   # one tome
pip install -r requirements.txt  # for the notebooks
```

Every push builds the PDF and EPUB on GitHub Actions (the run's **books** artifact); pushes to `main` also publish them
to the download page and the `books` release. Figures are TikZ files in `<tome>/figures/`, converted to SVG for the EPUB. Each tome has a cover (`tools/cover.tex`, with the central picture written by `tools/cover_motifs.py` into `<tome>/cover-motif.tex`); it is the first page of the PDF and the EPUB cover image shown by e-readers. A new tome needs a picture in `tools/cover_motifs.py`.

## Writing conventions

- Exercises: `\begin{exercise}[$\star$]\label{ex:name} ... \end{exercise}`, graded $\star$ to $\star\star\star$.
- Solutions: `\begin{solution}{ex:name} ... \end{solution}` in the chapter's last section.
- Boxes: `reminder` (optional title), `beauty` (links to other tomes).

## Testing notebooks

Notebook execution is separate from the book build and publication pipeline.
Run **Test notebooks on demand** manually from GitHub Actions to test all folders,
or test a folder locally after installing `requirements.txt`:

```sh
for nb in python/tome0/*.ipynb; do
  jupyter nbconvert --to notebook --execute --ExecutePreprocessor.timeout=600 "$nb" --output-dir build/notebooks || exit
done
```

## Incremental book builds

The **Build books** workflow keeps book compilation in one workflow, with a
parallel matrix containing only books whose publishing inputs changed.

| Change | Automatic compilation |
|---|---|
| One tome's manuscript, figures, photographs or listing | That tome and the generated S4 companion |
| Shared preambles, covers, EPUB/reader helpers, or `build.sh` | All books |
| Website generator or template | No book compilation; regenerate Pages |
| Notebook sources | No automatic notebook execution or book compilation |
| Missing/evicted library cache | Rebuild missing outputs; a cold cache rebuilds all books |

A validated library snapshot retains unchanged PDFs, EPUBs, online readers and
cover thumbnails. Changed books replace their previous outputs; removed chapters
and books are cleared before assembly. Pages and the rolling release still contain
the complete library. A failed required build prevents publication. Website-only
updates deploy Pages without uploading the book release again.

Use **Actions → Build books → Run workflow → Rebuild every book** to force a full
refresh. The first successful run seeds the output cache; warm runs benefit from
incremental compilation. Cache availability is an optimisation, not a correctness
requirement, and end-to-end speed depends on cache transfer and GitHub runner queues.
The existing TeX package cache remains in use. Notebook execution remains a separate
manual workflow, as described above.

Selection/assembly logic lives in `tools/build_plan.py`; its regression tests run
before planning. Publishing-toolchain changes should bump the output fingerprint
version (`book-output-v1`) so previously compiled books are regenerated.
