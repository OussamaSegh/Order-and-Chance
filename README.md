# Order and Chance

*The Hidden Architecture of Mathematics.* By SEGHAIER Oussama.

A series of books of beautiful mathematics, written for pleasure. Every chapter has graded exercises with complete solutions and a Python
notebook for mathematical experiments.

Each volume has **two distinct 7 × 10 inch PDFs and one reflowable EPUB**.
The reading download includes the approved front cover. The print PDF starts with
the half-title and is the paperback manuscript; its cover wrap is uploaded
separately. Both PDFs have matching full-colour content and visible pagination. The print PDF
is normalized for KDP (PDF 1.3, no interactions/live transparency); the reading PDF
retains original vector text, Unicode mathematics, links and bookmarks. Typography uses
bundled STIX Two Text/Math with Inter headings. Paperback files target Premium
color ink on white paper; the wrap uses its actual page count and colour-paper spine.
There are no A4, fixed-page Kindle or phone PDF editions.

Separate publishing assets include the full paperback cover with its actual-page-derived
spine, the eBook cover, listing and print metadata (see [tools/PUBLISHING.md](tools/PUBLISHING.md)).
The print PDF starts with the book's half-title; the reading PDF and EPUB include their front cover.

Pushes to `main` rebuild changed books and republish the complete validated library
on the download page and the [`books` release](https://github.com/OussamaSegh/Order-and-Chance/releases/tag/books).

## The series

Fifteen volumes, in six parts. There is no separate problem book. The problems that used to form a problem book are exercises in Volumes 1–6.

| Volume | Title | Subtitle |
| --- | --- | --- |
| **Part I. Foundations** | | |
| 1 | First Principles | Proof, Problem Solving and Mathematical Thinking |
| 2 | The Integers | Primes, Patterns and Proofs |
| 3 | Symmetry | Groups, Rings and Fields |
| 4 | Chance | The Logic of Uncertainty |
| **Part II. Bridges** | | |
| 5 | Calculation | From Formula to Insight |
| 6 | Crossroads | Arithmetic Meets Analysis |
| **Part III. Analysis and Geometry** | | |
| 7 | Spaces | Topology, Measure and Limits |
| 8 | Analysis | Operators, Spectra and Transforms |
| 9 | Shapes | The Geometry of Connection |
| 10 | Abstraction | Categories, Algebra and Homology |
| **Part IV. Randomness** | | |
| 11 | Randomness | Martingales, Limits and Ergodicity |
| 12 | Random Motion | The Geometry of Random Paths |
| **Part V. Number** | | |
| 13 | Arithmetic | From Equations to Hidden Worlds |
| 14 | The Primes | Their Hidden Rhythm |
| **Part VI. Synthesis** | | |
| 15 | Order and Chance | The Meeting of Structure and Randomness |

**First Principles** → **The Integers · Symmetry · Chance** →
**Calculation · Crossroads** → **Spaces · Analysis · Shapes · Abstraction** →
**Randomness · Random Motion** → **Arithmetic · The Primes** → **Order and Chance**.

Linear algebra is part of Symmetry, geometry is part of Shapes, and open problems are case studies in Order and Chance. Chance includes its combinatorial appendices. Random Motion contains its spectral graph and random-matrix appendices. Spaces, Analysis and Randomness each end with a chapter of harder problems.

Volume 2 closes with Dirichlet characters, Euler products and Legendre’s sieve. Volumes 1 and 3–14 include the corrected arguments from the 2026 errata. Volume 15, *Order and Chance: The Meeting of Structure and Randomness*, proves Buchstab, Maier and the Erdős–Rankin gap bound, the Kubilius model and Selberg–Delange, random multiplicative functions, Cohen–Lenstra, moments, Bohr–Jessen, Selberg’s central limit theorem, and Chebyshev’s bias. Five chapters remain openings: primes in short intervals, sieves, ranks of elliptic curves, random matrices and the zeros, and pseudorandomness. Downloads are named `Volume N - Title`.

## Design and future sessions

The author-approved visual identity follows the [charcoal/coral editorial reference](docs/reference/approved-charcoal-coral-volume-0.png):
matte charcoal, ivory sans-serif lettering, left-aligned titles, a fine double coral
frame, and one substantial mathematical illustration per book. All fifteen fronts use one locked Volume-0 master: the same common frame/header/footer, fixed bold title type, subtitles directly below each title and one softly glowing 3D coral illustration per book. The slogan
is **Discover the patterns. Understand the proofs.** Paperback wraps, EPUB covers,
interior accents and online light/dark themes share this identity. Light pages use
charcoal Inter headings, coral chapter accents and pale teaching boxes with one
thin left rule: blue exercises/problems, coral reminders/challenges, teal beauty
notes and plum thinking prompts.
Both PDFs share the full-colour interior, typeset in STIX Two Text and Math
with the cover’s Inter headings. Paperbacks use premium colour on white paper. EPUB and
web images preserve the approved 7:10 proportions.
The earlier approval PNGs remain unchanged as archival references. All live formats render the common master. Paperback covers use vector type/artwork, native paper grain at approximately 360 ppi, and an enforced 300 ppi print preflight.
Read [the current design guide](docs/DESIGN.md) and [AGENTS.md](AGENTS.md) before
changing design or publishing templates. Earlier designs are archived separately.

## Layout

```
common/                 shared LaTeX preamble (PDF) and EPUB preamble
volume1-first-principles/  main.tex + chapters/*.tex (solutions at the end of each chapter)
volume2-integers/           same layout, one folder per volume, through volume15-order-and-chance
python/volumeN/             one Jupyter notebook per chapter
tools/                      EPUB conversion helpers (pandoc filter, CSS)
build.sh                    builds readable Volume filenames for reading PDF, print PDF and EPUB
```

## Building

Requires `xelatex` (TeX Live with `latex-extra` and `fonts-recommended`), Ghostscript, `pandoc` 3, Python 3 and poppler-utils. Install the publishing helpers with `python3 -m pip install -r tools/requirements-build.txt`.

```
./build.sh                       # every volume
./build.sh volume1-first-principles   # one volume
./build.sh --pdf-only volume1-first-principles  # both PDFs and publishing assets
pip install -r requirements.txt  # for the notebooks
```

Every push builds the PDF and EPUB on GitHub Actions (the run's **books** artifact); pushes to `main` also publish them
to the download page and the `books` release. Figures are TikZ files in `<volume>/figures/`, converted to SVG for the EPUB. Each volume has a separate front cover (`tools/cover.tex`, with mathematical artwork generated by `tools/cover_plates.py` into `<volume>/cover-motif.tex`). It supplies the reading PDF front, EPUB cover image and library thumbnail; the print PDF starts with its half-title. Paperback wraps use the same artwork and the actual interior page count.

## Writing conventions

- Exercises: `\begin{exercise}[$\star$]\label{ex:name} ... \end{exercise}`, graded $\star$ to $\star\star\star$.
- Solutions: `\begin{solution}{ex:name} ... \end{solution}` in the chapter's last section.
- Boxes: `reminder` (optional title), `beauty` (links to other volumes).

## Testing notebooks

Notebook execution is separate from the book build and publication pipeline.
Run **Test notebooks on demand** manually from GitHub Actions to test all folders,
or test a folder locally after installing `requirements.txt`:

```sh
for nb in python/volume1/*.ipynb; do
  jupyter nbconvert --to notebook --execute --ExecutePreprocessor.timeout=600 "$nb" --output-dir build/notebooks || exit
done
```

## Incremental book builds

The **Build books** workflow keeps book compilation in one workflow, with a
parallel matrix containing only books whose publishing inputs changed.

| Change | Automatic compilation |
|---|---|
| One volume's manuscript, figures, photographs or listing | That volume |
| Shared preambles, covers, EPUB/reader helpers, or `build.sh` | All books |
| Website generator or template | No book compilation; regenerate Pages |
| Notebook sources | No automatic notebook execution or book compilation |
| Missing/evicted library cache | Rebuild missing outputs; a cold cache rebuilds all books |

A validated library snapshot retains unchanged PDFs, EPUBs, online readers and
cover thumbnails. Changed books replace their previous outputs; removed chapters
and books are cleared before assembly. Pages and the rolling release still contain
the complete library. A failed required build prevents publication. Website-only
updates deploy Pages without uploading the book release again.

Use **Actions → Build books → Run workflow → Rebuild every book** to force a full
refresh. The first successful run seeds the output cache; warm runs benefit from
incremental compilation. Cache availability is an optimisation, not a correctness
requirement, and end-to-end speed depends on cache transfer and GitHub runner queues.
The existing TeX package cache remains in use. Notebook execution remains a separate
manual workflow, as described above.

Selection/assembly logic lives in `tools/build_plan.py`; its regression tests run
before planning. Publishing-toolchain changes should bump the output fingerprint
version (`book-output-v8`) so previously compiled books are regenerated.

## KDP export rules

The approved print preparation is mandatory for all fifteen books. Interiors use
clean PDF 1.3; covers use opaque PDF 1.5 with vector lettering and 600 ppi composites
only where artwork uses transparency. Cover source/artwork is retained. Reports,
visual comparison, original reading navigation and actual-page-derived geometry
are checked in the build and again in library assembly. See
[the KDP export workflow](docs/KDP-EXPORT.md) and [AGENTS.md](AGENTS.md).
